# `app/` 的闸子

`app/` 里每个工具各有一道**对照原生实现的闸子**，都在这里。它们是 node 脚本而不是
pytest 用例，因为被测的东西在浏览器里：多数用 Playwright 打开页面、拖控件、导出会话
文件，再把文件里的数字交给 `python/fylite` 的同一道计算去判。

〔站点形状〕★**2026-08-23 起：`app/` 是十个页面，三种形态。** 三个**散文页**
（`index` / `features` / `credits`）各有中英两份（`index.en.html` 一类），由
`tools/make-app-pages.mjs` 从 `tools/app-pages/` 的模板加词条**生成**——文本在 markup
里、不加载 i18n 与 `site.js`、语言在文件名里、页面加载时把自己的语言写进 `localStorage`；
三个**场景页**仍是运行时切换。★第三种是**工具页**（现只有 `data`，装置数据）：一份文件、
语言就地切换、导航与页脚同样由 `site.js` 注入——像场景页，但它**不算东西**，故没有
部件、没有 worker、没有计算键，`SCENARIOS` 那一套（`ln.<id>.lead`、入口卡片、
「一个 `section.tool` 一个工具条一个控制器」）对它一条也不适用；它挂在 `site.js` 的
**`TOOLS`** 表上。★**2026-08-31 起它与场景页同住 `app/pages/`**（原名 `app/mdsplus.html`，
在站点根下）：一份、链接不带 `.en` 后缀，但相对路径与场景页一样带 `../`——
`validate-site.mjs` 的 `up` 规则因此不再为工具页开一个「在站点根」的例外。页眉的导航与**整条页脚**（徽标 ·
其余散文页 · 语言 · 版权 · 本页二维码）**只有一份规格两个发射器**：场景页与工具页由
`site.js` 的 `installFoot()` 注入（其 markup 里必须是空的 `<footer></footer>`），
散文页由生成器写出。`validate-site.mjs` 按 `data-page` 分这三支来判。另有
`validate-typography.mjs` 只读两份样式表，断言文档面的字号只取自级数
`{13,14,16,19,23}`、字重只取 400/500/600/700、`.doc` 的单元格不右对齐、行宽用 `rem`
不用 `ch`、浅色调色板过 WCAG AA。

〔mdsip 那条链〕**编解码与参数面守卫不在这里**，在 `cargo test`：
`rust/fylite/src/mdsip.rs` 13 项（请求头逐字节、dtype 表、定宽字符串数组、**维序**、
分片重组、畸形帧，以及守卫那一条「**一个字节都没发出去**」——守卫在写出之后才拒等于没拒，
从外面只有这一种办法分辨）、`bin/app/api.rs` 6 项（端点在开套接字之前就拒）。

★2026-09-01 之前这一段是 `validate-mds.mjs`，测的是仓里那台 **Node 网关**
（`app/server/gateway.mjs` + `mdsip.mjs`）。网关退役，那道门随之删除——它测的实现不在了。

〔`validate-app-mdsip.mjs`〕端到端那一层：**发布出去的那个宿主，对着真机录下来的帧**。
`_mdsip-replay.mjs` 回放 `fixtures/mdsip-east.json`（`tools/mds-record.mjs` 架在客户端与
EAST 之间录的请求→应答对），宿主指向它。★★**那份夹具不在本仓**：它是 EAST 内网的实验
数据，随私有的 `fydata` 走（`corpus/experiment/east/mdsip-137985.json`）。拷回原位、或
`FYLITE_MDS_FIXTURE=<路径>`，这一组门就照跑；两条都落空时它们**跳过**，不退回假服务器。
同理 `validate-east-catalog.mjs` 要的 `app/facts/device/east-signals.json`（`fydata`
`corpus/device/east/east_signals.json`，或 `FYLITE_SIGNAL_CATALOGUE=<路径>`）。★判据是**命中**：宿主拼错一个字就命不中任何一条
记录，门会红并把那句表达式印出来。另钉三条只有真服务器才暴露的解码规则（空载荷、
`TIME_INSERTED` 的 u64、定宽文本的填充是分隔符），以及每个端点答多少个键。

```bash
node app/tests/validate-app-mdsip.mjs        # 离线，不需要服务器
FYLITE_MDSIP_SERVER=<主机:端口> node app/tests/validate-jmds.mjs           # 独立实现对照（要真服务器）
```

〔`validate-jmds.mjs`〕**独立实现的对照**：`tools/jmds` 那个纯 Java 客户端与宿主逐字段比、
两条数组**逐位**比。要一台真服务器（Java 客户端的握手与本仓的不同形，回放答不了它——
那正是不拿夹具糊弄它的理由）。实测 #165704 `\PCRL01` 1376 点全同。

〔`validate-mds-page.mjs`〕**装置数据页自己**（`pages/data.html`）的闸子（浏览器），而且它**自带一个站点**
（`_site.mjs`）：磁盘上的 `app/` + **发布出去的那个宿主** + 回放的 mdsip——不需要静态服务器、
不需要隧道、不需要所内网络，而页面到套接字之间的每一层（端点、会话池、编解码）都是要发的
那份代码。

★★2026-09-01 之前，这一层是一台**解析式假服务器**（`_mdsip-fake.mjs`），按解析式波形现算
答案。换成录制帧的当天，它编出来的两处机器事实就露了：假站点「**两炮之间空着一号**
（#137983）」——真机上 #137982…#137985 全都开得开；`BCENTR` 在假站点有数有单位——真机上
那条全路径**每一炮都是 NODATA**（页面读错了节点，见 `changelog`）。**判据立在编出来的数据上，
红不了。** 现在踩的是机器真有的那一处：计数器停在 **#165704**，**#165705 打不开**。

★回放器答的每个字节都是录来的，只有两处例外并写在它文件头上：消息序号那一位改成来访者的
（应答本来就回声它），以及**窗口切片本地切**（拖着放大的窗口是像素算出来的，穷举录不完；
底稿每路 ≤ 2000 点，`data` 与 `dim_of` 用同一套下标，所以每个 (t, y) 仍是真服务器给过的
那一对）。判的是（**77 项**）：六路信号自适应排两列且
**版面在一屏之内**（1440x900 实测 701 px）、选几列就是几列、**窄屏不论选了几列都退回
单列**、「最新」落到 `current_shot` 那一炮且状态行说得出这个数是哪里来的、空号**报出来而
不是静默停住**（树说打不开、每一路信号带着服务器自己的话、炮号停在原地，再按一次就跨过
去）、**换炮之后上一炮的曲线不会留在屏幕上冒充这一炮**；再加 T-S 那一批：状态行三格有值
并各自点名节点、**日期那一格是空的并说明为什么空**、B_t 不冒充 UDAClient 的 `It`；
**悬停给读数且一次请求也不发**、框选放大与 Shift 平移各自恰一轮重取；两炮同图（图注、
读数表、导出的 `shot` 三处都分得开，且**两炮的数确实是两份**）；★**缩放时钉住的那一炮
跟着重取**（T-S8）——同一幅图上两炮的**步长相同**、钉住那一条的图注**写出自己的窗口**
（没有重取就没有这一行，这一项是二值的，而步长在两炮样点数相同时本来就会相等）、两炮的
步长**都塌下去**、一次缩放的往返数在界内、状态行**说出替钉住那一炮花掉的往返**、把**采样
调高**之后两炮仍同口径（窗口不是唯一能把两炮拉开的控件）、双击回整炮时两炮一起回来；存出来的确实是 PNG 且
文件名带树·节点·炮号、打印时控件不在而**图注还在**；工作区**文件里没有一个样点**、读回来
落在文件里那一炮并把那一份对比整个恢复出来。

```bash
node app/tests/validate-mds-page.mjs --playwright <playwright 目录> [--chrome <可执行文件>]
```

〔历史〕`app/` 曾是**五个文件**：首页加四个场景，一个场景一页
（当时的 `scenario/design` / `scenario/control` / `scenario/model` / `scenario/analysis`；
那一目录 2026-08-31 改称 `pages/`）。

★**2026-08-22 起：三个场景（设计 → 建模 → 反演），一页一个部件、若干条功能栏。**
`design` = `zerod` + `discharge`（0D 由建模页迁入；`breakdown` / `feasible` 撤下），
`model` = `transport` + `evolve`（`coupled` 与 `tglf` 撤下），
`analysis` = **`profile` + `reconstruction`**（剖面拟合栏在前——运行顺序即注册顺序：
先由测量点拟出剖面，再把平衡拟合到它上面）。★反演页因此有了两条栏，导出菜单项随之
带栏名：`#analysis-iofmt-reconstruction-json` / `-magnetics` / `-kinetic` / `-gfile` /
`-profile` 与 `#analysis-iofmt-profile-points` / `-profile`；计算键是
`#analysis-profile-run` 与 `#analysis-reconstruction-run`。
**控制仿真整页撤下**（`vstab` 及其闸子、词条、worker 命令全删；内核入口未动）。
另一个文件是 `credits.html`（版权 / 致谢 / 参考文献），它没有部件、没有计算，
`validate-site.mjs` 只查它在、它自报 `data-page`、每页都通得到它。于是：

- 元件 id 带**页面**前缀，只有两条栏都会用到的名字才写成 `<页面>-<栏>-<名>`
  （设计页的 0D 栏整栏都带栏前缀 `design-zerod-*`：设计栏已经占了 `discharge-r0` 一类名字）
  （`scalars`、`kappa`、`v-kappa`、`prof`、`verdict`、`closure`）。闸子取控件仍是
  「先阶段、后页面」地回退，和页面自己的 `$` 一样。
- ★**2026-08-22 起：计算键在每条栏自己的标题条右端**（`#<页面>-<栏>-run`，如
  `#model-transport-run`、`#analysis-reconstruction-run`），**一按只跑那一条栏**；
  页面工具条上不再有计算键。一条栏若声明了 `needs`，其计算键在上游栏**跑完之前**是
  禁用的（上游还没跑过就算没跑完），栏上的「待 …」牌说在等谁。跑整页仍可以，但那不再
  是一个按钮：`FyScenario.pages.<页面>.runBars()` 按拓扑序跑所有栏，闸子要端到端时用它。
  一道只针对某条栏的闸子要么改该栏自己的一个控件（`change` 即开算），要么直接按**那条
  栏的**计算键——`validate-evolve.mjs` 就是后者。
  ★**没有开关了**：每条栏曾有一个 `#<页面>-use-<栏>` 复选框，配合页面级的单一计算键说
  「这一栏参不参与」；计算键进了每条栏之后它不再回答任何问题，已移除，闸子不必再摆它。
- ★**整页运行时上游产物会下传**（总线是**页面内**的：0D 与 1.5D 分处两页之后，
  两者之间只剩「导出工况 → 导入」这条路，`validate-handoff.mjs` 就是这么驱动的）。
  闸子要看某页总线里有什么，不必存文件：
  `FyScenario.pages.<页面>.bus.<栏>`（发布的是构造函数，调用即得当前的那份），
  `FyScenario.pages.<页面>.bars` 是栏的登记表。
- ★**跨场景交接有两条路，装的是同一份文档**：①文件（导出→导入，闸子驱动的就是这条，见
  `validate-handoff.mjs`）；②同源直传——`localStorage` 的 `fylite:handoff` 单槽，产出页按
  「交给建模场景」写入，建模页提示后由读者按「取用」应用。闸子若要走第二条，直接
  `localStorage.setItem('fylite:handoff', JSON.stringify({kind:'gfile'|'op', from, bar, name,
  when, text}))` 再点 `#model-transport-handoff-take` 即可——**应用走的是格式自己的
  `apply`**，与文件路径同一段代码。
- ★**建模页的 1.5D 栏还能读 g 文件**（`#model-ioimport` 直接喂 EQDSK）：形状/q95/B 来自
  文件，n<sub>e</sub>(0) 与边界温度**按约定不设**。
- ★**折叠不影响可及性**：栏与面板折起来只是 `display:none`，元件仍在文档里、id 不变，
  闸子照常 `getElementById`；折叠状态存在 `localStorage`，闸子每次都是新 profile，不受影响。
- 导出菜单项 id **没有变**（`#model-iofmt-zerod-json` 等），会话文件与 `fylite:page`
  也没有变：格式键仍带阶段名。

★**一页就是一个场景：一个 worker、一条工具栏、一个计算键。**页面由若干**部件**拼成
（`<div class="part" id="part-<部件>">`；控制器是**一个场景一个文件**`assets/scenario-<场景>.js`，文件内一段一个部件），部件**没有**自己的
工具栏、计算键或 worker——那三样归页面。于是闸子的入口是这样两层：

```
BASE + 'pages/model.html?device=east#part-zerod'
   页面级： #model-run / #model-status / #model-ioexport / #model-iofmt-<部件>-<格式>
   部件级： #zerod-slice / #transport-edge …（元件 id 带 `<部件>-` 前缀）
   共用件： #model-ip / #model-chi0 …（两个部件用的是同一个量，只有一个控件，
            带**页面**前缀；闸子取控件要「先部件、后页面」地回退，和页面自己的
            `$` 一样）
```

**会话文件里仍是裸 id**——文件格式是与闸子、与已经存盘的文件之间的契约，不因为 markup
加了前缀就跟着动；文件里的 `fylite:page` 也仍是**部件**名（`zerod`/`breakdown`/…），
不是页面名。

★**按页面的计算键 = 跑整页**（按注册顺序逐个部件跑完）。一道只针对某个部件的闸子因此
不按它，改用读者本来就有的那条路：**改该部件自己的一个控件**（`change` 事件即开算）。

```js
await page.waitForFunction(() => !document.getElementById('<页面>-run')
  .classList.contains('stop'), null, { timeout: 300000 });
await page.evaluate(() => document.getElementById('<部件>-<控件>')
  .dispatchEvent(new Event('change')));
```

需要整页跑完（自洽平衡—输运、动理学反演）的那几道仍按 `#<页面>-run`；计算键同时是终止
键，运行中按下是<strong>停止</strong>不是排队，所以按之前先等它空闲（上面第一句）。

★**导出菜单按阶段分格**：物理建模页的菜单项 id 是 `#model-iofmt-<阶段>-<格式>`，按下
导出键先出菜单、再点条目；只有一件事的页面（design / control / analysis）是
`#<页面>-iofmt-<格式>`。

跑法（先起一个静态服务，页面要能被 `fetch` 到 wasm）：

```
python3 -m http.server 8767 --bind 127.0.0.1     # 在仓根
node app/tests/validate-vstab.mjs --playwright <playwright 的 node_modules 目录>
```

`--url` 可改站点根（缺省 `http://127.0.0.1:8767/app/`）；`--playwright` 也可以用
环境变量 `$PLAYWRIGHT_PATH` 给。不需要浏览器的三道（`validate-geqdsk`、
`validate-q`、`validate-limits`）直接 `node` 跑即可。★playwright 按版本钉一份
chromium；装的那份是别的版本时，用 `--chrome <可执行文件>`（或 `$CHROME_PATH`）
指过去，不必再下一份浏览器。

| --- | --- |
| `validate-q.mjs` | 页面算的 q 剖面 vs EFIT g 文件自带的 q |
| `validate-geqdsk.mjs` | g 文件读写往返，以及与 Python 侧读数一致 |
| `validate-device.mjs` | 装置描述符的读写往返，以及坏描述符必须被拒 |
| `validate-zerod.mjs` | 0D **参数映射**（手写十标量 vs `kernel_params()`）逐项——★原为「转写」闸，numpy 0-D 退役后改指（FYL-DESIGN-08 N-1） |
| `validate-zerod-app.mjs` | 0D 页面整条波形 vs 原生 |
| `validate-pulse-sim.mjs` | 脉冲设计与交互仿真两页（浏览器）：校验片是否落在三个相位、逐通道峰值是否是有限数、**已解片 / 插值片**是否分得清（读 `data-slice`，不读散文）；仿真侧的开关相位机、**推滑块只改未来**（逐点比对发布的历史）、平衡节拍的年龄、未声明摆幅报未知、结束后不可续开 |

〔共同的纪律 · 闸子必须先等 busy 再等完成〕**按下计算键之后，先等页面进入运行态，
再等它报完成。**状态行是**上一次**运行留下的，「完成」两个字在按键那一刻就已经在屏幕
上——只等「完成」的闸子会立刻满足条件，然后把**上一次**的表、上一次的标量、上一次的
χ² 当作这一次的答案读走。本会话因此一度得出「噪声与基阶数不影响结果」的假结论：两组
设定读到的是同一次运行。写法是三步，缺一不可：

```js
const key = '#analysis-reconstruction-run';
// ① 键必须先空闲（它同时是终止键，运行中按下是停止不是排队）
await page.waitForFunction((k) => !document.querySelector(k)
  .classList.contains('stop'), key, { timeout: 300000 });
await page.click(key);
// ② 等它真的进了运行态——这一步就是那条纪律
await page.waitForFunction((k) => document.querySelector(k)
  .classList.contains('stop'), key, { timeout: 60000 }).catch(() => {});
// ③ 再等完成
await page.waitForFunction((re) => new RegExp(re).test(
  document.getElementById('analysis-status').textContent), '重构完成|失败',
  { timeout: 600000 });
```

同一条纪律的两个推论：

- **「没有跑」不能事后读状态行**。跑完一次又停下来的页面，状态行与没跑过时一模一样。
  要断言某个操作**不开算**（例如按预设），得在操作**之前**架一个 `MutationObserver` 盯着
  计算键的 class，事后问它有没有见过运行态——`validate-analysis.mjs` 第十节就是这么写的。
- **`doneRe` 里必须容得下「失败」，否则闸子会挂死；也正因如此，凡是随后要读屏幕上数字
  的地方都得再断言这一次确实**算成了**。失败不改 `last`，屏幕上留着的是上一次的答案，
  读它等于给一次没发生的运行打分。

〔共同的纪律〕**每道闸子都必须有一个不经被测路径的 oracle**，而且不许在退化情形上
通过——若两边同时为零，相对比较恒成立，那等于什么也没测。所以多数闸子除了比数值，
还各带一条非退化检查（区制必须不止一种、谱必须真的不平、拟合必须比自己的数据更准）。
容差也一律写明**误差来源**（会话文件的 7 位有效截断 / 二分收敛 / 插值 / 后端浮点
自由度），而不是挑一个能过的数。

★**「有几条失败」这类判据尤其容易退化**，因为**全都失败**同样满足它。
`validate-analysis.mjs` 第七节栽过：它断言「null 的片数 = 写明原因的片数」，而当时那条
孪生扫描 4 片全败——这一行于是在一次什么都没解出来的运行上恒真。规矩是：凡是比较
「成功的那些」与「失败的那些」的判据，必须先断言**两边都非空**，再断言各自的性质。
★而查这一条的时候翻出了更重的一件：同一条扫描在干净页面上 4 片全"解出"，其中两片
`a` = 0.036 m、q95 = 0.013、拟合电流 215 MA——求解器返回了，返回的却不是等离子体，
而闸子只数了失败的片数，没有问过成功的那几片长什么样。所以第二条规矩：**断言失败被
报出来，同时要断言成功的那些确实是它们自称的东西。**

〔`validate-form.mjs`〕**表单闸**（`FYL-DESIGN-18` U-1 / U-2，分期 U0）：`pages/model.html` 的
参数控件不再手写——页面只带 `data-form` 挂点，`assets/vocab-model.js` 是控制词表，
`assets/form.js` 在加载时按词表画出控件（同 id、同 i18n 键、同读数）。闸子**双向**查：
页面里没有 `<input>` / `<select>`，每个挂点有且仅有一条词表条目、反之亦然；`page_model.html`
带同一组挂点且 `vocab-model.js → form.js` 排在 `scenario.js` 之前；有 Playwright 时再开浏览器
逐条比对元素的 tag / min / max / step / value / 读数，并断言 `FySession.collect` 读回的是
词表的默认值。★它不需要 `fy` 可执行体——控件在任何 worker 回答之前就已存在，静态伺服
`app/` 即可。词表由 `tools/transcribe-form-vocab.mjs` **一次性**誊录而来，此后词表是源，
不再改页面。

〔`validate-fig.mjs`〕**规格闸的页面半边**（`FYL-DESIGN-18` U-12 · U-16 · U-17 · U-21 · U-22）：
`assets/fig.js` 把一份 `spo:PresentationSpecification` 画到功能页的画布上，解析（哪条序列绑哪个量、
一维量对哪个坐标）一律走 `casereport.js` 导出的 `index` / `resolve` / `coordinateOf`——**页面与报告
用同一份解析器**，闸子静态断言 `fig.js` 里没有第二份。浏览器一节喂一份**合成记录**（不需要 wasm，
也不需要 `fy`：被测的是投影，不是内核的算术），并把 `FyPlot` 换成**记录器**——判据是「被要求画的是
什么」而不是像素，否则一条残差画成折线（U-21 唯一禁止的事）只要颜色对就能过。十项：五种视图各画对、
茎的横轴是通道序号且带零线、baseline 与 computed 在非颜色通道上分得开、`fylite:domain` 被采用、
三种画不了的各出一句**指名道姓**的拒绝且不计入「已画」。

★**`validate-report.mjs` 今天跑不动**（`FYL-DESIGN-18` G-13）：它调 `python3 -m fylite cases --report`，
而 2026-09-04 的裁定撤掉了 Python 侧的命令行。于是「两端推出同一份规格」这条判据目前没有门在断言——
`validate-fig.mjs` 只管页面这一边。

〔`validate-checkpoint.mjs`〕**断点闸**（`FYL-DESIGN-18` U-8..U-11 · U-19）：`assets/run.js` 把一次
多步运行做成一串门调用（预算分片 · 进度按步实测 · 取消 = 切预算），`assets/checkpoint.js` 把断点
存进 IndexedDB——**断点就是那份记录**，存取逐字节相同。闸子的核心判据是设计里那一条：**N 步一次
调用 ≡ k 步 + 恢复(N−k) 步**；这里用一个**确定性的假步进器**（状态是依赖入参的累加），所以不需要
内核也能断言「行军把状态带过了接缝、并且只要还差的那些步」。取消一节读的是**兑现值**：取消不是
异常、不是 terminate，已算的步必须还在。★首跑逮到两处真缺陷（恢复后步号从头、分片跨过断点间隔），
都记在 `FYL-DESIGN-18` §十三 的 U0 第三步行里。

〔`validate-workbench.mjs`〕**工作台闸**（`FYL-DESIGN-18` U-14 · U-16 · U-17）：`assets/workbench.js`
把规格的视图做成 12 列栅格上的瓦片，改动一律落回**规格**（`fylite:layout` · `fylite:domain` ·
`fylite:visible`），不进 `localStorage`——闸子静态断言这一条。浏览器一节喂一份合成记录与一份手写规格，
断言四件设计里的话：移动**同时**写布局与把 `has_view` 按先行后列重排（不认识布局词的渲染器读的是
次序）；缩放是**瞬态**且带「未钉住」标记，钉住才进规格（只查钉住会放过一个把每次缩放都偷偷导出的
工作台）；缩放与光标**按坐标族**共享（时序动、剖面不动）；图层开关**立刻**入规格。★首跑逮到一处真
缺陷：栅格钳位只在拖拽处理器里，程序化的 `move()` 能把瓦片放出栅格。

〔`validate-bundle.mjs`〕**往返闸**（`FYL-DESIGN-18` U-18 · U-19，设计点名的第四道）：`assets/bundle.js`
把一次工作打成一个**存储法 zip**（计划 · 输入 · 记录 · 规格 · environment · 报告），读回时按 `@type`
分类、不问文件名。判据就是设计里那句：**导出 → 清空 → 导入 → 再导出**，`plan.jsonld` 与
`presentation.jsonld` 逐字节相同。★最要紧的一条是**外部读者**：浏览器写出的字节交给 **Python 的
`zipfile`**（校验中央目录、本地头与每一个 CRC）与 **`unzip -t`**——自己写的读者认自己写的 zip
什么也证明不了，而「移步」成不成立取决于**别人的**读者认不认。zip 不写时间戳，否则同一份文档集每次
导出都是不同的字节，这道闸就无从比起。
