# 评估：用本应用复现 Wei et al. 2026（EAST 关键剖面快速处理），实现 EAST 数据快速分析

> 文献：D. Wei, F. Wen, G. Li *et al.*, “Rapid processing of experimental data for key plasma profiles on EAST
> tokamak”, *AIP Advances* **16**, 085007 (2026), doi:[10.1063/5.0324803](https://doi.org/10.1063/5.0324803)（CC BY 4.0）。
> 评估日期 2026-09-18；本页里凡写「实测」的，都是这一天在本应用（`kinetic_recon.py`，只依赖 `libfylite.so`）
> 与 EAST 数据服务器上跑出来的。

## 一句话结论

**文献那条链的六步里，fylite 已经有四步的「核」，本应用已经通了其中的取数与平衡两步；缺的是数据绑定
（反射计 · XCS · ECE · 加热功率）、剖面拟合的台基形（mtanh 分段）、加热沉积接进功率平衡，以及批处理。**
复现文献的**剖面与输运结果**是可行的，预计三个阶段；复现它的 **「35 片 ≈ 20 s」** 这一指标，需要先说清楚一件事：
文献的 20 s 里**没有平衡反演**（它直接读 P-EFIT 的答案），而本应用的平衡是自己反演出来的——按 fylite 2026-09-15 的裁定，
efit_east 树只能作对拍，不能作建模输入。所以同一指标要换一种说法比：见〈四〉。

## 一 · 文献做了什么

| 步 | 文献的做法 | 数 |
| :--- | :--- | :--- |
| 1 取数 | 只给炮号：MDSplus 取 TS（T_e · n_e）、微波反射计（n_e 主源）、XCS（T_i）、ECE（TS 缺时顶 T_e）；以 TS 时刻为基准、其余诊断在 50 ms 窗内配 | — |
| 2 坐标 | P-EFIT（MDSplus 上的平衡答案）→ ρ_tor | — |
| 3 清洗 | 迭代加权样条作全局参照 + 邻域 MAD 的局部稳健尺度；上下两侧各一对阈值（偏离全局 **且** 偏离邻点线性趋势才算离群）；**一次只剔最坏的一个**，重算后再判；边界点不剔；阈值由 50 片人工标注集按 0.5 F1 + 0.3 recall + 0.2 precision 定 | — |
| 4 拟合 | 按 H98 分 L / H 模；L 模全段样条；H 模芯部样条 + 台基 mtanh（台基顶先加权平均再非线性最小二乘）+ ρ ∈ [0.8, ρ_e] 按斜率积分平滑过渡；轴上导数为零；T_e,sep 固定 50 eV；T_i 台基取 T_i = T_e | NRMSE：n_e ≈ 0.015，T_e 0.03–0.09（#63948，4–8 s） |
| 5 加热 | LHW：METIS 的快速模块；ECW：TORAY（接在 ONETWO 里） | #81481 @ 5.3 s：LH 驱动电流 METIS 181.3 kA 对 GENRAY+CQL3D ≈ 176 kA |
| 6 输运 | ONETWO 功率平衡反解 χ_e · χ_i（含辐射、电子–离子交换） | — |
| — | 批处理 | #63948 35 片 19.95 s（ECW+ONETWO 5.15 · LHW 7.07 · 清洗+拟合+I/O 7.72） |

## 二 · 逐步对照：本应用与 fylite 今天到哪

| 步 | fylite / 本应用今天 | 缺什么 | 活儿在哪 |
| :--- | :--- | :--- | :--- |
| **1 取数** | **通**（实测）：本应用 `pull` 经 `libfylite.so` 的 mdsip 客户端取 `east` 树磁测量 · PF · Ip · TF · POINT 11 弦与 `ts_east` Thomson、`analysis` 的 TXCS T_i0；#137985 @ 4.041 s 与 B-06 离线归约件逐道相差 ≤ 4×10⁻¹³ | ① **反射计 n_e 剖面、XCS T_i 剖面、ECE 没有 MDSplus 绑定**（装置事实里只有静态描述：`reflectometer_profile` · `spectrometer_x_ray_crystal` · `ece`）；② 只取**最近一个** TS 脉冲，没有「以 TS 时刻为基准、其余诊断 50 ms 窗内配」；③ **旧炮 TS 时刻列不是秒**：#63948 的 `\TE_CORETS` 第 0 列是 76.9…128.3（35 个脉冲），按「最近时刻」取会取错 | ① fydoc A-Box 补绑定（装置数据，内部）→ 重生装置文档 → 重建库；② ③ 本应用 |
| **2 坐标** | 本应用用**自己反演的平衡**（档 M，拟合自己剔坏道）给 ψ_N；档 P 的外环把测点逐遍重映 | ρ_tor 要环向磁通：`code/ladder` 描迹出每个面的量，本应用还没接；**不读 P-EFIT**（裁定：efit_east 树只作对拍） | 本应用接 `code/ladder` |
| **3 清洗** | 档 P：对 p(ψ_N) 做 GCV 多项式光滑拟合，**一次剔最坏的一个**、超过 4σ 才剔——与文献同一个骨架 | 文献的判据更细：**局部** MAD 尺度 + 邻点线性趋势的双条件、上下侧分开的阈值、边界点不剔；而且逐诊断（T_e、n_e、T_i 各自）做，不只是压强 | 本应用（纯数值，标准库即可） |
| **4 拟合** | `code/profile_fit`：移位勒让德多项式 + GCV 定阶（无台基形）；`code/separatrix_align` 能按 T_e,sep 平移标签 | **mtanh 台基 + 芯部样条 + 平滑过渡**没有；L / H 判别要 H98（`code/zerod` 有 0-D 账，未接） | 新增拟合：本应用内实现（非线性最小二乘，标准库可写），或内核加一扇门 |
| **5 加热** | `code/wave`：LH 快速沉积与驱动（n∥ 上移、驱动效率参数化）；`code/rf_ray`：EC 射线追踪（ECCD 部分落地）与 LH 射线；装置文档带 LH1 / LH2 频率 · n∥ 带 · 额定功率，EC 四路 140 GHz · 模式 | ① **注入功率的时序没有绑定**（装置文档里 LH / EC 没有 MDSplus 节点）；② EC 的发射位置与指向在 fylite 里记为未知，要每炮给；③ 没有与 GENRAY+CQL3D / METIS 的对拍记录 | A-Box 补功率节点；本应用接 `code/wave` · `code/rf_ray`；对拍 #81481 @ 5.3 s（文献给了 181 kA / 176 kA 两个答案） |
| **6 输运** | `code/interpretive`：给剖面反解 χ_e · χ_i，含辐射（ADAS）· α · 由环电压给的欧姆项 · 能量账；**有记录**（校验册 `tr-coupling-interpretive-inversion`：往返按 h² 收敛到 3.8×10⁻⁵；返回的是 χ₀/gm7，约定照实记） | ① **源项只收参数化的高斯沉积**（`dep_centre` · `dep_width`），接不进 `wave` / `rf_ray` 算出来的沉积剖面——这是链上**唯一要动内核的一处**；② 电子–离子交换项、环电压的来源要核 | 内核：`code/interpretive` 加「给定源剖面」的输入；本应用接它 |
| — 批处理 | 本应用一次一片：档 M 每片约 90–100 s（16 个竖直设定点 × 3–4 轮剔道，每轮 13–30 s），三档合计 125–145 s，`pull` 每片约 120 s（每片把约 170 个节点的全时序重读一遍） | 见〈四〉 | 本应用 |

另两处实测到的、做批处理前必须先修的：

- **旧炮的磁测量排布不同，本应用的起步规则在那里失效。**#63948 与 #81481 解析到的是 35 环 · 38 探针
  （provider `base` / `pcs`），环全叫 `FL<n>A`——本应用「从 FL*B 组起步」的规则一个环都选不到，档 M 会在没有环的情况下起步。
  要加一条回退：没有 B 组时从全部环起步（或先只用探针、收敛后再按残差收回环）。
- **`east` 树不总开得了。**同一天上午服务器对 #137985 报 `cannot open east shot 137985`，下午恢复。批处理要把
  「这一炮取不到」当作一条正常的输出，而不是整批失败。

## 三 · 复现路线（三个阶段，每段有验收数）

| 阶段 | 做什么 | 验收（对文献） |
| :--- | :--- | :--- |
| **A · 剖面**（只动本应用 + 装置绑定） | 反射计 / XCS / ECE 的 MDSplus 绑定补进装置事实并重建库；本应用：TS 时刻列的单位判别、以 TS 为基准的 50 ms 配窗、文献的局部稳健清洗、芯部样条 + mtanh 台基 + 斜率积分过渡、T_e,sep = 50 eV、T_i 台基 = T_e；输出 NRMSE | #63948，4–8 s：n_e NRMSE 均值 ≈ 0.015、T_e 在 0.03–0.09 之内 |
| **B · 加热** | 注入功率节点补进装置事实；本应用接 `code/wave`（LH）与 `code/rf_ray`（EC），EC 发射几何由用户给 | #81481 @ 5.3 s：LH 驱动电流落在 176–181 kA 附近，沉积峰位与文献图 8 一致 |
| **C · 输运** | 内核：`code/interpretive` 收给定源剖面；本应用把 A 的剖面、B 的沉积、档 M 的平衡（经 `code/ladder` 给度规）交给它 | #81481 @ 5.3 s：χ_e · χ_i 的形与量级对文献图 9(c)；能量账的 W 对磁测量储能（文献自己列为下一步的那项核对） |

★三段都在 fylite 的包络里：单机、不要调度器、不引外部程序（ONETWO · TORAY · METIS 不进来，只用 fylite 自己的
`interpretive` · `rf_ray` · `wave`）。因此复现的是**文献的方法与结果**，不是它的代码；两者的差（快速 LH 模型不同、
EC 用射线追踪而非 TORAY）要在 B 段的对拍里量出来。

## 四 · 「快速」这件事

文献的 **35 片 ≈ 20 s** 是：取数 + 清洗 + 拟合 + LH + EC + ONETWO，平衡用 P-EFIT 的现成答案。本应用同一件事要多做一步
**自己的平衡反演**（这是它比文献多给的东西：平衡与剖面自洽，而且不依赖 P-EFIT）。按今天的实测，一片的账是：

| 环节 | 今天 | 能压到 | 怎么压 |
| :--- | ---: | ---: | :--- |
| 取数 | 约 120 s / **片** | 约 120 s / **炮** | 每个节点的全时序只读一次，在所有时刻上归约（归约本身是毫秒级） |
| 档 M | 90–100 s / 片 | 约 3–8 s / 片 | 第一片照今天做（扫设定点 + 剔道）；后面各片**继承**上一片的剔道结果与竖直设定点，只在它附近 2–3 个设定点上解 |
| 剖面清洗 + 拟合 | — | 亚秒 / 片 | 纯数值 |
| 加热 + 输运 | — | 待测 | `code/wave` 是快速模型；`code/rf_ray` 的射线数可调 |
| 并行 | 无 | × 核数 | 各片独立（标准库 `multiprocessing`），每个进程一份库 |

估算：35 片、8 核，**约 2–3 分钟一炮**（其中 2 分钟是取数）。这比文献的 20 s 慢一个量级，但换来的是一份**自己反演、
自洽、带逐道残差与外环证书**的平衡；若只要剖面与 χ（与文献同口径），可以让档 M 只在第一片全扫、其余片只做一次求解。
★这两个数都是估算，要在 A 段做完后在 #63948 上实测替换。

## 五 · 风险

- **数据绑定是装置数据**：反射计 · XCS · ECE · 加热功率的节点名属 EAST 装置描述（权利方 ASIPP、不公开），补在 fydoc 的
  A-Box 里、编进内部版的库，由本应用从库里解析——与磁测量 · PF · POINT 今天的做法相同。★本应用脚本里写死的节点名只有
  Thomson · TXCS · TF · PCS Ip 那几个（`\TE_CORETS` 一类），与 fylite 公开代码 `python/fylite/io/mds.py` · `raw.py`
  里的写法一致；新增的诊断不再往脚本里写。
- **旧炮的数据形态**：TS 时刻列单位、磁测量排布都随年代变；#63948 是文献的主算例，A 段要先把它跑通。
- **快速模型的偏差**：文献自己量到 METIS 与 GENRAY+CQL3D 的沉积形状有差；fylite 的 `code/wave` 是另一种快速模型，
  差多少只能在 B 段量。
- **本应用的依赖约束**：只依赖 `libfylite.so`、不要 numpy。mtanh 的非线性最小二乘与样条要用标准库写（量不大）；
  若性能不够，改为内核加一扇拟合门，仍不破坏这一约束。
