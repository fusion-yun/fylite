一 · 平衡与反演问题

托卡马克等离子体在一个时刻的宏观状态，用轴对称平衡描述。取柱坐标 (R, φ, Z)，磁场写成

B = ∇ψ × ∇φ + F(ψ) ∇φ (1)

ψ 是极向磁通，F = RBφ 是极向电流函数。力平衡 J × B = ∇p 要求压强 p 与 F 都只是 ψ 的函数， 于是环向电流密度只剩两个自由剖面：

Jφ(R, Z) = R p′(ψ) + F F′(ψ) / (μ0 R) (2)

ψ 由 Grad–Shafranov 方程与这个电流相连：

Δ*ψ ≡ R ∂R(R−1 ∂Rψ) + ∂Z2ψ = −μ0 R Jφ (3)

自由边界：ψ 是等离子体电流与外部线圈（EAST 的 12 路 PF 极向场电路）共同产生的，等离子体的边界是与限制器相切、或过 X 点的那一条闭合磁面，本身是解的一部分。 归一化磁通 ψN = (ψaxis − ψ) / (ψaxis − ψbnd)，磁轴上为 0、边界上为 1。

反演问的是：给定等离子体外面测到的量——磁通环读 ψ、磁探针读它所在处沿探针方向的极向场、罗氏线圈读总电流 Ip——找出使 (2)(3) 成立、 且把这些测量预测得最好的 p′、F F′。关键的一点是：在 ψ 的几何固定时，每一个磁测量都是 Jφ 的线性泛函（经格林函数）， 而 Jφ 又对 p′、F F′ 线性——反演因此能写成一串线性最小二乘。

二 · 数值：带约束的 Picard 迭代（fylite code/reconstruction）

基函数

两个剖面各用一组多项式展开，边缘值为零（x = ψN）：

p′(x) = Σk=0np−1 αk (xk − xnp) ， F F′(x) = Σk=0nf−1 βk (xk − xnf) (4)

本应用缺省 np = 1、nf = 2（与离线 EFIT 交付的基同：p′ ∝ 1 − ψN，FF′ 为边缘为零的二次式），即 3 个系数 c = (α0, β0, β1)（2026-09-22 之前缺省 2 / 2）。 基函数的阶数是输入：它决定解能表示什么。阶数高了，磁测量定不住的方向会自由漂移（校验册 eq-reconstruct-curvature-prior：(1,1) 抬到 (2,2)，孪生上 q₀ 偏差 −0.12 % → −31.5 %）。

一次外迭代

  1. 在当前 ψ 上定出等离子体区域（限制器 / X 点决定的最外闭合面）与每个网格点的 ψN。
  2. 于是 Jφ = Σj cj bj(R, Z)：每个系数对应一张电流分布 bj。把它们经格林函数投到每个测量上，得设计矩阵 Aij（第 i 个测量对第 j 个系数的响应）；线圈电流的贡献是已知的一项，从读数里扣掉。
  3. 解带权线性最小二乘，Ip 作等式约束：
    minc Σi ((Ac − d)i / σi)2 　s.t.　∫ Jφ dA = Ip (5)
    矩阵先做列均衡，再按奇异值截断（弱方向丢掉，报 trunc_keep）——病态是常态，不是例外。
  4. 用新电流解 (3) 更新 ψ（松弛因子 0.3），回到 1。ψ 的相对变化低于 10−8 即收敛。

竖直位置

拉长的等离子体竖直不稳：磁测量对整体上下平移不敏感，迭代会滑走。求解器用一个电流质心的竖直设定点 Zc 作反馈锚；本应用对 Zc 在 −30…+30 mm 扫 16 个值，取收敛且 χ² 最小的那一个（KEFIT 用 fitdelz 拟合同一个自由度）。

后验

权重是 1/σ，所以 ATW2A 就是 Fisher 信息；它的截断伪逆（再投影掉 Ip 约束的方向）是系数的后验协方差。 页面「剖面 · p′」里档 M 的灰带就是由它传出来的 1σ。

三 · 为什么磁测量不够

磁测量都在等离子体外面。外面的场只认得电流分布的少数几个整体矩——总电流、电流质心、四极矩（与拉长、βp + li/2 相连）…… 内部 p′ 与 F F′ 怎么分、电流在芯部多尖，外面几乎看不出来。很不一样的内部剖面能给出几乎一样好的磁拟合。

这在结果里是可见的：档 M 的 p′ 后验带常是 p′ 自身值的一半上下；芯部的 q₀ 由芯部电流密度定，偏偏是磁测量最看不清的地方。 把内部定下来要内部约束：芯部的压强（Thomson、CER）、电流或它的方向（MSE、偏振干涉）。这就是「动理学平衡反演」（kinetic EFIT）。

约束阶梯：同一时刻按约束集分档——M 只磁、K 加 POINT、P 加 Thomson。档不同，能声称的东西不同：两个档的 q₀ 差百分之几十，可以只是约束集之差，不是代码之差； 拿三级约束的结果去和别人一级约束的结果比，比出来的是约束。

四 · 档 K：POINT 偏振干涉

EAST 的 POINT 有 11 条水平弦（Z = +0.425 … −0.425 m，自 R = 2.5 m 向内穿过等离子体），每条弦同时给两样：

干涉：NL = ∫ ne dl 　　偏振（法拉第旋转）：αF = C λ2 ∫ ne B∥ dl (6)

C = 2.62 × 10−13 rad·T−1，λ = 432.5 μm（KEFIT GUI 与装置牌同值；物理值 e3/(8π2ε0me2c3 = 2.631 × 10−13，差 0.43 %）。 水平弦上 B∥ = BR——法拉第角对内部极向场敏感，这正是磁测量缺的那一块。

  1. 密度形状：先用 11 个线密度拟一个 ne(ψN) = ne0 (1 − ψN2)α（code/chords，扫 α）。线密度只用来定这个形状，不进平衡拟合。
  2. 零假设：在档 M 的平衡上、用这个密度沿弦积分，前向算出 11 个法拉第读数，对实测。这一步不改平衡，只回答「不看 POINT 时，POINT 离数据多远」。 零假设残差超过 8σ 的行判为死道、关掉（B-06 实测过这种道：干涉死道 +22σ、法拉第死道 −10.9σ）。
  3. 拟合：ne 与 ψ 的几何固定时，(6) 右边对 Jφ 线性，于是每条弦成为设计矩阵里的一行（faraday_rows），权重 1/σF， 与磁测量一起进 (5)。几何随解变，所以逐轮在新平衡上重建这些行，直到 |Δq₀|/q₀ < 10−3。
B-06 用同一输入跑 KEFIT 与 fylite：拟合 POINT 后两者都留约 2.4σ 的法拉第残差、逐弦同号——这份残差属于数据（标定、零偏或随时间漂的系统差），不属于某个代码。 所以法拉第行进了拟合而残差降得不多，并不说明拟合没做对。

五 · 档 P：Thomson 压强与自洽外环

压强点

芯部 Thomson 在一条垂直弦（R = 1.9 m）上给出逐点的 Te、ne 与各自的误差；TXCS 给一个芯部 Ti0。组装成

p = e ne Te (1 + fdil Ti0 / Te0) (7)

这里有一个声明的假设：Ti(x) = Ti0 · Te(x) / Te0（离子温度只有芯部一个数）。可选地再扣掉一份声明的快离子压强—— 先按总压强算 σ，再扣：快离子是已知量，扣掉它改的是读数，不是读数的不确定度。

清洗

坏道先剔再进拟合。缺省（--thomson-clean local）用 Wei et al. 2026 §II.B 的局部稳健判据（wei_profiles.py，与 wei2026.py 同一份代码）， 分别作用在 Te(ρ) 与 ne(ρ) 上（ρ = √ψN）：残差对邻域 MAD 的标度分超阈、且偏离两邻点连线超过给定比例，才剔，一次剔一个； 任一量判为离群的道整道不用。旧法（smooth）对 p(ψN) 做全局光滑拟合、超过 4σ 的逐点剔——测点在边缘密、芯部疏，峰化剖面上拟合被边缘点主导， 芯部整段被当成离群剔光（实测过），只为复现旧读数而留。

清洗自检：剔掉的点超过候选点的 30 %，或芯部（ψN < 0.5）连续剔掉 3 个相邻点，结果里记 cleaning_suspect、本页标红—— 要么清洗错了，要么这一脉冲本身不可用；哪一种这一档的读数都不可信。

压强行

由 (4)，p(x) = Δψ ∫x1 p′ dx′（Δψ = ψaxis − ψbnd）对 α 线性：

p(x) = Δψ Σk αk [ (1 − xk+1)/(k+1) − (1 − xnp+1)/(np+1) ] (8)

于是每个 Thomson 点是一行：在它的 ψN 上取 (8)，对实测 p，权重 1/σp。

自洽外环

压强测在位置 (R, Z) 上，而行要的是 ψN——把位置变成 ψN 要一个平衡，而平衡正是待解的东西。 单遍反演是在别人的平衡给出的横坐标上拟合，且从不说明这一点。

外环（kinetic_passes）把这个圈闭上：解一次 → 在刚解出的 ψ 上把每个测点重映到 ψN → 再解。每一遍报两条迹，合称证书：

  • χ²/dof——这一遍对全部测量的拟合；
  • 映射移动 max|ΔψN|——测点的标签这一遍又挪了多少。它低于阈值（缺省 10−3），才叫「自洽」。

交替不保证单调，所以内核按 χ² 取最优遍收官，不取最后一遍。页面另把「收官那一遍的映射是否已经不动」单独判出来：按 χ² 最小取到的，可能恰是映射还在走的那一遍—— 那时的解对它自己的磁面并不自洽。

★这个外环只重映：不重算自举电流、不重算快离子。完整的 kinetic-EFIT 外环（新平衡 → 重映剖面 → 重算 jbs 与快离子 → 回到反演）本应用不做。

八 · 数据处理的每一步

取数（pull）

  • 装置（节点名、PF 通道、POINT 弦几何）由 libfylite.so 里编进去的 EAST 文档按炮号与测量链解析；原始节点的归约（与 fylite 的 reduce_series 同一规则）：|t − t0| ≤ 5 ms 窗口均值，−6.9 … −6.1 s 炮前线性漂移扣除；POINT 用它自己的窗、先减 t ≈ −0.9 s 附近的零偏，条纹闸剔跳变的弦。
  • BT 不读 B_T 节点（自 #97286 起单位是伏特），改读 TF 线圈电流：F = μ0N I/2π，N = 16 × 130。
  • Thomson 取离所要时刻最近的一个激光脉冲（#137985 全炮只有 6 个，每秒一个）。

档 M 的选道

  1. 名字重复的探针槽：树里只有一个节点、读的是第一处那一道；第一处照用，后几处起步即不用。
  2. 环从 FL*B 组起步——75 个环全进时 16 个设定点一个都不收敛；B 组起步则收敛。
  3. 每一轮：扫 16 个设定点 → 取收敛且 χ² 最小者 → 看逐道残差 → 超过 5σ 的里剔最坏的至多 4 道 → 重扫。剔完反而一个设定点都不收敛，就撤回这一批。
  4. 收敛后，把起步组之外、在这个解上预测得进 5σ 的环收回来，再走一遍 3。——最后用哪些道是数据选的，不是一张写死的表。

档 P 的离群点与 σ 续延

  • 只收挂在 ψN < 0.98 上的点。对 p(ψN) 做一次带 GCV 定阶的光滑拟合，离它最远且超过 4σ 的那一点剔掉，重拟，直到没有这样的点。
  • 先按实测 σ 进内核；拒了就把全部压强行的 σ 依次放宽 1.5、2、3、4、6、8 倍，取第一个收敛的。原因是求解器对紧的动理学行不稳：把档 M 自己的压强原样当行喂回去（数据与解完全自洽）， σ 取峰值 5 % 时仍会把等离子体拟丢，20 % 时一步收敛。放宽了多少，这一档就少说了多少——结果里标红。

九 · 怎么读结果 · 边界

  • 没有真值。真实放电上没人测过 q₀。能判的只有测量那一侧（逐道残差）与档差。efit_east 树与 KEFIT 的答案在 B-06 里，只作比较，本应用不读。
  • 先看档 M 站不站得住：收敛的设定点有几个、χ²/道是否在 1 附近、剔掉的道跨时刻是否一致（#137985 上三片独立剔出同样 5 个探针）。
  • 档 K 看两件事：零假设离数据多远（POINT 与磁测量是否一致），拟合后 q₀ 往哪走、走多少。
  • 档 P 先看证书：收官那一遍的映射是否已不动、σ 放宽了几倍、进拟合的点剩几个。这三样有一样不过关，这一档的 q₀ 就不该拿去用。
  • 没有 MSE。内核里没有 MSE 行；芯部电流在 EAST 上主要由模型约束，收敛不蕴含正确。
  • 剔道是本应用的规则。另一套规则（B-06 以 KEFIT 纯磁 χ² 份额剔 7 道）会给出另一个答案，两者之差是剔法之差。

物理校验

解出来、收敛了，不等于物理上成立。每一档解完逐条核：同尺储能 W > 0；0 < βp < 5；p(ψN) 在 [0, 1] 上不低于 −5 % 峰值；0.3 ≤ q0 ≤ 20、q95 > 1、q 处处 > 0；同尺 li(3) 在 [0.3, 3]；边界闭合、在限制器内（容 1 cm）、磁轴在边界内；ψ 由磁轴向外减（内核 COCOS 17，Ip > 0）且 LCFS 内 ψN ∈ [−0.02, 1.02]；拟合 Ip 与实测同号、差 ≤ 5 %（Ip 作带权测量时 ≤ 5 σ）；χ²/dof ≤ 20（这一条是统计校验，不是物理）。 任一条不过，这一档数照留，状态记 unphysical——有别于 error（没有解）与 skipped（没跑）。档 K / P 叠在哪一档上，那一档不物理，它们也记不物理（设定点与 ψN 映射都取自它）。界值与理由写在结果的 physics_check.bounds 里，--phys-bounds 可改，--no-physics-check 不做。 结果页的「物理校验」卡给每档一枚徽章，没过的条目连值与界一起列出。

十 · Wei 2026 剖面（wei2026.py profiles）

另一条管线，复现 Wei et al. 2026（AIP Advances 16, 085007）：不反演 q，而是把一炮里每个 Thomson 时刻的 Te(ρ) · ne(ρ) · Ti(ρ) 清洗、拟合出来，并给每一片记一个 H98 与 L / H 判定。 本页收它写出的 fylite:Wei2026Profiles，一片一片地看。

横坐标

ρ = ρtor,norm（归一化环向磁通半径），由 code/ladder 在本应用自己解的那一片档 M 平衡上给出——不是 P-EFIT、也不是树里的 EFIT。 换一个平衡，同一个测点会挂到另一个 ρ 上；所以每一片都把它的平衡事实（q0 · q95 · χ²/dof · Zc）一起写出来，页面照列。

清洗

文献 §II.B 的局部稳健判据（wei_profiles.clean_profile，与档 P 缺省的 Thomson 清洗同一份代码）：残差对邻域 MAD 的标度分超阈、且偏离两邻点连线超过给定比例，才剔，一次剔一个。 阈值文献没有公布，这里用的是本应用的缺省（结果的 method.cleaning 原样记着，页面「方法」卡里照印）。剔掉的点不是丢掉：它们在结果里留着 0 / 1 的记号，页面把它们画成叉。

拟合

L 模：全段一条带 GCV 定阶的光滑样条。H 模：芯部样条 + 台基 mtanh + 两者之间按文献 Eq. (11) 的斜率积分过渡；台基形

fped(ρ) = A · mtanh(2(ρsym − ρ)/w; α) + B ， mtanh(z; α) = ((1 + αz)ez − e−z) / (ez + e−z) (9)

先用外区数据定形状（w · ρsym · α），再只调幅度 A 与台基段起点 ρe；Te 在分界面上钉 50 eV。 L / H 由 H98 定：H98 ≥ 0.7 判 H（这个阈是本应用的口径，文献没给）。拟合得多好只报一个数：

NRMSE = √( Σk (yk − f(ρk))² / n ) / ( max y − min y ) (10)

只在留下的测点上算——剔掉的点既不进拟合，也不进 NRMSE。所以 NRMSE 小不等于剖面对：它只说「留下的点被这条线穿得多齐」。

H98 的账

H98 = τE / τIPB98(y,2)，τE = W / Ploss。W 优先取抗磁能，没有时用剖面积出来的动理学 Wth； Ploss = Pabs − dW/dt（缺省口径）。文献没有写它的 H98 口径，所以每一片都把数了哪几项、漏了哪几项写进 h98_inputs.account，页面逐项列出来—— 读 H98 先读这张账：NBI 只有离子源功率、辐射只记不减、没有 dW/dt 时都在这里说明。

这一视图怎么读

十一 · Wei 2026 输运（wei2026.py transport）

同一条管线的第二段：拿上面那一片剖面，加上 LH 与 EC 的沉积，做一次稳态功率平衡反解，得 χe(ρ) 与 χi(ρ)。 本页收它写出的 fylite:Wei2026Transport。

反解

稳态下，穿过 ρ 面的热流等于面内沉积的净功率；把热流写成扩散形式，就把 χ 解出来：

χe(ρ) = − ( ∫0ρ Se dV ) / ( V′ ⟨|∇ρ|²⟩ ne ∂Te/∂ρ ) ， Se = PLH + PEC + PΩ − Prad − Pei (11)

离子一侧同理，源只有电子–离子交换 Pei（本例 Si = Pei）。这是反解不是预测：χ 是被剖面与源反过来定出来的， 剖面拟合的任何毛病（清洗剔错、台基拟歪、Ti 是构造的形状）都直接进 χ。

(11) 的分母里有 ∂T/∂ρ：梯度太小的地方 χ 定不出来——芯部平顶与分界面附近，分母趋零，χ 冲到几百 m²/s；热流变号的点同样没有意义。 内核为此逐点给一个 valid_e / valid_i 标记，页面把判无效的那一段涂掉并写明从哪个 ρ 起，那一段的曲线不画。看见「ρ ≥ 0.83 判无效」，就是这个意思，不是那里输运特别好。

源从哪来

  • LH：code/wave，按天线的净功率与 n∥ 谱（带一个人给的上移范围）算沉积与 Fisch 模型的驱动电流；驱动效率 ηcd 是输入，不是算出来的。
  • EC：code/rf_ray 射线追踪 + 全相对论吸收，驱动电流用 Lin-Liu–Chan–Prater 的伴随响应。发射几何（镜位、逐炮镜角、束光学）取装置事实，没有公开镜角的束照实记为未算，页面把它连同理由列出来。
  • 欧姆：给定的环电压除以 Spitzer 电阻率，不是推进出来的 E∥；辐射只有轫致 + 线辐射的模型值。两条都在结果的 transport.notes 里，页面原样印。

这一视图怎么读

  • χe · χi 一张图（对数轴），无效段涂底色并标出起点；源 · 交换 · 辐射 · 欧姆一张图；驱动电流 jcd(ρ) 与 LH · EC 的沉积各一张。
  • 上面那一片的三条剖面照画（同一套记号），因为 χ 是它们的函数。
  • 事实卡里是内核给的积分量：⟨χe⟩ · ⟨χi⟩（各自平均了几个点、用了几个点）· τE · Wth · Icd · 各项功率；方法卡里是这次用的平衡、ρ 的定义与时间窗。

十二 · 时间序列对拍（kinetic_recon.py series）

给一个炮号与一段时间 [t0, t1]，逐时刻跑档 M（只磁测量），与装置自己的离线 EFIT（efit_east 树；可另加 P-EFIT · 实时 EFIT）逐时刻比。 本页收它写出的 fylite:KineticReconSeries。

EFIT 树是参考库（另一个程序存下的答案，二级数据库），不是诊断：它只出现在比较里，不进任何一片的拟合。差是两个解之差——同一组磁测量，两套基函数、两套剔道与竖直位置的做法。

时刻

  • --at-efit（缺省）：时刻就是离线 EFIT 自己在区间内的片（GTIME）——每个比较都在对方的片上，不插值。
  • --dt S：均匀网格；每个时刻与各来源最近的一片比，|Δt| 记在每片里（对方的片距比 S 粗时，同一片会被比好几次）。

取数一次，逐时刻归约

环 · 探针 · PF · Ip · TF 的整条序列各读一次（POINT 不读：档 M 用不到，它的弦每条几百万个采样），然后在每个时刻上按 pull 的同一条规则归约 （|t − t0| ≤ 5 ms 窗口均值、炮前漂移扣除）；参考树的 ψ · 边界 · q · p 也各读一次整个数组，逐片切出。 同一时刻，这样归约出的测量与单独 pull 的逐字节相同，切出的参考片与按下标单取的那一片逐字节相同。

每片独立

各片互不依赖，分给几个进程同时解（--jobs），按时间次序归并；每一片与同一时刻单独跑 run --tiers M 的档 M 逐字节相同。 从上一片热启动（沿用它的 Zc 与剔道）能省时间，但会改答案——这里不做，所以相邻两片的差全是数据的差。

比什么

q0 · q95 · 磁轴取两边各自报的；li · βp · W · 体积两边都用同一把尺——由 ψ(R, Z) · 边界 · p(ψN) 在网格上积出（compare 的那一段）：

W = 3⁄2 ∫ p dV ，βp = 2μ0⟨p⟩V / Bpa2 ，li(1) = ⟨Bp2⟩V / Bpa2 ，Bpa = ∮Bp dl / Lp (12)

几何的差：磁轴距离；两条边界之间的距离——a 上每点到折线 b 的最近距离、再反过来，

dmean = ½ ( ⟨minb |xa − b|⟩a + ⟨mina |xb − a|⟩b ) ，dmax = 两个方向上的最大者 (13)

X 点平衡：上、下两个 X 点（ψ 图在偏滤器区的鞍点）的 ψN 之差 Δ = ψN(上) − ψN(下)，两边同一段程序量。|Δ| < 0.005 为上下平衡的双零（DN，迹上两条灰横线之间）， Δ > 0 为下单零（LSN）、< 0 为上单零（USN），两个 X 点都在分离面外为限制器位形（LIM）；截面上 ◆ 标 X 点，实心的那个在分离面上。

本机 KEFIT（series --kefit，紫色）：同一片、同一组原始测量、档 M 最后的选道、同式误差、同基交给本机构建的 KEFIT（EFIT 的 EAST 分支）解一遍，当作一个参考来源。 它与我们的差是算法之差；与离线 / 实时 EFIT 的差里还混着那两份自己的输入处理——三条参考放在一起看，才分得开这两样。

以及 ψN 图之差的 rms（我们的网格点上、两条边界都在内的点）。汇总卡给每个量「我们 − 对方」在整段上的均值 · rms · 最大 |差|，另两样专门回答差是不是系统的： 差为正的片占几成（近 0 或 1 = 一边倒），差随时间的斜率（近 0 = 不随时间走）。
