门的说明

要回答的问题

拉长位形的托卡马克等离子体在竖直方向上是不稳定的：外场的曲率让它一旦上下偏离，就被继续推离。导体壁里感应的涡流会顶住它，但壁有电阻，涡流会衰减——于是本来以 Alfvén 时间尺度发生的理想不稳定，被拖慢成以壁的 L/R 时间尺度增长的阻性壁模。这个模必须由主动反馈拉住。本页回答三件事：它长得多快；PD 控制怎样的增益能拉住它、拉得多快、要多大电压；回路时延大到多少就再也拉不住。

被控对象（内核 code/vstab）

无质量刚性位移模型：等离子体电流分布整体竖直平移 ξ，外场刚度 k = Ip ∂²ψext/∂Z²（k > 0 去稳），导体电流 I 经耦合梯度 G = ∂Mpk/∂Z 与它相互作用。力平衡

k ξ + I_p Gᵀ δI = 0 ⇒ ξ = −(I_p / k) Gᵀ δI = C_ξ · δI

消去 ξ 后，导体电路满足

M* dI/dt + R I = B v, M* = M − (I_p² / k) G Gᵀ

秩一修正让 M* 恰有一个负特征值，那就是不稳定模；增长率 γ 是 −M*⁻¹R 的最大实部。三档判读由两个刚度定：k ≤ 0 稳定，0 < k < kideal 阻性壁，k ≥ kideal = Ip² Gᵀ M⁻¹ G 理想不稳（无质量模型里增长无穷快，门按名报出而不给一个看着正常的大数）。

成员：被动结构三组（内壳 40 件、外壳 40 件、被动板 10 件）与 IC1、IC2 两路快控线圈。门在 circuit: full 下给出全部矩阵，本示例把 12 路 PF 通道删掉——PF 由电源保持电流，对小信号动态没有贡献；EAST 的 PF 是超导线圈，把它们当成有电阻的回路成员会变成完美的磁通守恒体，把对象错误地稳住。接线判据：再把 IC 也删掉、只留被动结构，γ 必须落回门在 circuit: passive 下自己给的值；不相等就停。

控制回路（本示例）

ξ → [PD：u = −K_p ξ − K_d ξ̇_f] → [时延 e^(−sT)，Padé 4 阶] → [电源 1/(τ_a s + 1)] → v v_IC1 = +v ，v_IC2 = −v （反对称对产生竖直力的径向场） ξ̇_f ：微分经一阶滤波 τ_d

极性取使 Kp > 0 为恢复力的那一侧（两种极性都试一次 P 律，看哪一侧压得住）。增益图的 Kp 围绕 P 律下限 Kp,min 取对数，Kd 以 Kp,min/γ 为尺。

挑增益不看「最大实部」：被动板的慢 L/R 模 IC 控制不到，在稳定区里它一直占着最大实部，像一块平台。挑增益看的是 ξ 本身：从开环不稳定模的形状、ξ(0) = ξ0 出发，ξ 落进 ±2 % 的时刻（沉降时间），以及这一路要的峰值电压。时间推进用精确离散 xk+1 = eAΔt xk。

回路时延为什么是硬限制

一阶滞后能被 PD 的超前相位补回来，纯时延补不回来。经典结论：对 ẋ = γx − K x(t − T)，存在稳定的 K 当且仅当 γT < 1。时延扫描以 γT 为横轴，给出这台对象、这套 PD 律下可稳定的时延上限 Tcrit。

本页怎么读

  • 截面：线圈（金色是 IC）、被动结构按电流着色（红正蓝负，量程按整段最大值固定、各帧可比），等离子体边界按 ξ 刚性平移（放大倍数在工具栏）。「开环不稳定模」一档画的是每米位移对应的壁电流。
  • 增益图：灰色是不稳定区；最底一行是 Kd = 0（纯 P）。点出的圆圈是沉降最快的那一点。
  • 壁的作用：壁越远 γ 越大，到理想阈值为止；壁电阻率与 γ 严格成正比——这是阻性壁支的判据。

没做到的

  • 无质量刚性模型只管 n = 0 竖直模的小信号线性行为；大位移、形状变化、触壁之后都不在其中。
  • ξ 取模型真值（状态反馈）；真实系统要从磁测量估计。
  • 没有电源电压 / 电流限幅，没有测量噪声。
