# EAST 竖直不稳定性与竖直位置控制（被控对象来自内核 · 控制器与闭环仿真在这里）

给一份 EAST 平衡（G-EQDSK + 同名 A-EQDSK），算它的 n = 0 **竖直不稳定模**：被动壁把它从理想增长拖慢到壁的
L/R 时间，IC 快控线圈对以 PD 律把它拉回。回答三件事——

1. **它长得多快**，壁离得远一点、电阻大一点会怎样；
2. **PD 控制**怎样的增益拉得住、拉得多快、要多大电压；
3. **回路时延**大到多少就再也拉不住。

```bash
export PYTHONPATH=<fylite 仓>/python FYLITE_DEVICE_DIR=<fylite 仓>/dist/facts/device/east
uv run --no-project --with numpy --with pyyaml python vs_control.py run DATA_DIR -o out/vs.json
# 双击 vs_control.html → 把 out/vs.json 拖进去
```

`DATA_DIR` 是 EAST 数据目录（含 `g<shot>.*` 与 `a<shot>.*`；缺省炮号 115672）。一次完整运行约 6 分钟，其中壁扫描
13 次内核调用占 5 分钟；`--no-scan` 跳过它，约 80 秒。

★**分工**：被控对象（电路矩阵、增长率、判读档位、壁扫描）全部由内核 `code/vstab` 给；**控制器、执行器模型与闭环仿真是
本示例自己的**——内核仓对此明说「闭环飞行模拟器不存在，也刻意不做桩」（`fylite.scenario.control.gaps()`），所以这里的
控制部分只是**示意**，不是 EAST PCS。

★实验数据与结果**不入仓**（`.gitignore` 兜住 `out/ log/ *.json`）。

## 一 · 物理模型：被控对象（内核 `code/vstab`）

**无质量刚性位移模型**：等离子体电流分布整体竖直平移 ξ，外场刚度 $k = I_p\,\partial^2\psi_\mathrm{ext}/\partial Z^2$（$k>0$ 去稳），
导体电流 $I$ 经耦合梯度 $G = \partial M_{pk}/\partial Z$ 与它相互作用。力平衡

$$k\,\xi + I_p\,G^\mathsf{T}\delta I = 0 \quad\Rightarrow\quad \xi = -\frac{I_p}{k}\,G^\mathsf{T}\delta I \equiv C_\xi\,\delta I ,$$

消去 ξ 后导体电路满足

$$M^*\,\dot I + R\,I = B\,v,\qquad M^* = M - \frac{I_p^2}{k}\,G\,G^\mathsf{T}.$$

秩一修正让 $M^*$ 恰有一个负特征值——那就是不稳定模；增长率 γ 是 $-M^{*-1}R$ 的最大实部。三档判读由两个刚度定：
$k \le 0$ 稳定，$0 < k < k_\mathrm{ideal}$ **阻性壁**，$k \ge k_\mathrm{ideal} = I_p^2\,G^\mathsf{T}M^{-1}G$ 理想不稳（无质量模型里增长无穷快，
门按名报出 regime 2，不给一个看着正常的大数）。

**成员**：被动结构三组（内壳 40 件、外壳 40 件、被动板 10 件，取装置卡）与 IC1、IC2 两路快控线圈（装置卡里
`function = b_field_fb` 的线圈，R = 2.4 m、Z = ±0.6 m、2 匝）。

**为什么删掉 PF**：门在 `circuit: full` 下给出全部成员 **[PF 12 路 | 被动 90 | IC 2]** 的矩阵，而 IC 只在这一档进入回路
（`circuit: passive` 只留被动结构）。但 `full` 把 PF 也当成回路成员——EAST 的 PF 是超导线圈，门给的 R = 0，它们就成了
**完美的磁通守恒体**，会把对象错误地稳住（同一份平衡上 γ 从 8.88 掉到 6.43 s⁻¹）。实际上 PF 由电源保持电流，对小信号
动态没有贡献，所以从 M、R、G 里删掉 PF 的行列，留下「被动 + IC」92 维，再用
`fylite.scenario.control.lti.linear_model(…, plasma_response="rigid")` 做秩一修正。

**接线判据**（每次运行都查，不过就停）：

* 同一份 `full` 矩阵再把 IC 也删掉、只留被动结构，γ 必须落回门在 `circuit: passive` 下**自己**给的值——成员次序或删法错了，
  这里当场不等。#115672：8.87924 对 8.87924。
* 门的 $C_\xi$ 必须等于 $-(I_p/k)\,G$（截取是精确的，因为它只依赖 G 与 k）。

离散与入册基准 `mhd-vertical-freegsnke-east137985` 同一套：`coarsen 1 · nu = nv = 8`，被动组 `inner_shell,outer_shell,passive_plates`。
PF 通道安匝取 A-EQDSK 里 EFIT 拟合的 `ccbrsp[:12]`（与 `tools/benchmark-wall-vstab.py` 同）。

## 二 · 控制回路（本示例）

```
ξ → [PD：u = −K_p ξ − K_d ξ̇_f] → [时延 e^(−sT)，Padé 4 阶] → [电源 1/(τ_a s + 1)] → v
v_IC1 = +v ，v_IC2 = −v        （反对称对产生竖直力所需的径向场）
ξ̇_f：微分经一阶滤波 τ_d
```

闭环状态 $x = [I\ (92) \mid d\ (\text{微分滤波}) \mid z\ (\text{Padé},\ 4) \mid v\ (\text{电源})]$。

* **极性**：两种极性各试一次 P 律，取使 $K_p > 0$ 为恢复力的那一侧。
* **增益图**：$K_p$ 围绕 P 律下限 $K_{p,\min}$ 取对数（0.3×–300×），$K_d$ 以 $K_{p,\min}/\gamma$ 为尺（最底一行 $K_d = 0$ 即纯 P）。
* **初态**：开环不稳定模的形状，$\xi(0) = \xi_0$（缺省 1 cm）。
* **时间推进**：精确离散 $x_{k+1} = e^{A\Delta t}x_k$（缩放与平方 + Padé(6,6) 的矩阵指数）。

★**挑增益不看「闭环最大实部」**：被动板的慢 L/R 模（τ ≈ 400 ms）IC 控制不到，它在稳定区里一直占着最大实部，
像一块平台（#115672 上各时延都是 −1.642 s⁻¹）。挑增益看的是 ξ 本身：**2 % 沉降时间**与这一路要的**峰值电压**。

★**增益图不用模态叠加**：$\xi(t) = \mathrm{Re}\sum_i (c^\mathsf{T}V)_i(V^{-1}x_0)_i e^{\lambda_i t}$ 一次特征分解就给出全部时刻，
但 τ_a、τ_d 与 Padé 的极点挤在一起时特征向量矩阵近乎亏损（合成对象上 cond(V) ≈ 8×10¹¹），精度只到 10⁻⁵ 量级。
所以每个网格点逐步推进；模态叠加留在测试里作交叉核对。

**为什么时延是硬限制**：一阶滞后能被 PD 的超前相位补回来，纯时延补不回来。经典结论：对 $\dot x = \gamma x - K\,x(t-T)$，
存在稳定的 K 当且仅当 $\gamma T < 1$。时延扫描以 γT 为横轴，给出这台对象、这套 PD 律下可稳定的时延上限 $T_\mathrm{crit}$。

## 七 · 局限

- **无质量刚性位移模型**：只管 n = 0 竖直模的**小信号线性**行为；大位移、形状变化、触壁之后都不在其中。时延超限那一档
  仿真里 ξ 长到几米——那是线性模型越界，不是物理。
- **控制器与执行器参数是本示例的设定**（K_p、K_d、τ_a、τ_d、T），不是 EAST PCS 的实际值；**没有电源电压 / 电流限幅**，
  没有测量噪声。
- **ξ 取模型真值**（状态反馈），不是磁测量估计。门在装置声明磁通环时另给 `loops_c` / `loops_p` 两行，接观测器是下一步，没做。
- **只一个时刻**：一份平衡、一组线圈电流。沿放电的 γ(t) 要逐时刻的平衡。
- **#137985 对不上入册的 4.17 s⁻¹**：本机的 `g137985.04000` 给 2.56 s⁻¹——入册那次用的是案例库里的 KEFIT 平衡，本机没有；
  量级、档位、裕度一致。

## 九 · 结果页 `vs_control.html`

单个 HTML 文件，不加载任何外部资源、不上传（与 `east-free-boundary-evolution/fb_evolution.html` 同一套画法与配色 token）。
**双击打开** →「导入结果 JSON」，或把 `out/vs.json` 拖进页面。「原理与过程」页签不要结果也能读。

- **读数**：开环 γ（被动 + IC / 只有被动）、判读档位与裕度、P 律下限、可稳定的时延上限与 γT_crit、I_p。
- **截面与竖直位移扰动**：线圈（金色是 IC）、被动结构按电流着色（红正蓝负，量程按整段最大值固定、各帧可比）、等离子体边界
  按 ξ 刚性平移（放大倍数可选）；「开环不稳定模」一档画每米位移对应的壁电流。工况切换、播放、时间条。右侧 ξ(t)（四个工况叠画）、
  电源电压与指令、IC1 电流与被动电流之和，时间光标与截面同步。
- **PD 增益图**：选时延；着色可选沉降时间 · 峰值电压 · 最大实部；灰色是不稳定区，最底一行是纯 P，圆圈是沉降最快的那一点
  （在网格边上时注明）。旁边是**沉降时间 ↔ 电压需求**的散点与下包络——这一时延下「要多快就得给多大电压」的代价曲线。
- **回路时延上限**：每个 γT 下能做到的最好闭环最大实部，标出 γT = 1 与 γT_crit；**极点图**叠画开环与所选工况的闭环极点。
- **壁的作用**：γ 对壁距离（对数纵轴，标出理想阈值）、γ 对壁电阻率（双对数，γ ∝ η 参考线与偏离）。
- **明细**：对象表（含接线判据）、各工况表、门的说明与四条局限。
