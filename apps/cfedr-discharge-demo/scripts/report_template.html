概览

建模分层：1 → 40 s 限制器爬升期用 0-D 全放电模型（IPB98(y,2) 标定，参数化剖面）；从 40 s（偏滤器位形、体积已达平顶的约 90 %）起是一段连续的 1.5-D 输运推进，自 0-D 状态起步，走过满功率、L→H 转换、燃烧平顶，直到下降段 I_p 降回 10 MA（6170 s，体积与位形又回到平顶之外）再交回 0-D 层——两处交接对称。小截面与二维磁面是逐时刻自由边界平衡序列。

近似条件与未涉及的物理

主要近似

  • 1.5-D 通量面平均：热（电子 / 离子）、粒子（n_e）、电流三个通道；动量通道关闭（CFEDR 无 NBI、无力矩输入，文献同样不设旋转）。
  • 固定位形：输运度规取 CASE-20 平顶 g-file 一次追踪（51 面），全程不随自由边界平衡更新；故交接前限制器期不用 1.5-D。
  • 电流一致起步：40 s 起步磁通取平顶磁通按 I_p 比例缩放（形状即 l_i 仍为平顶的），I_p 由反馈环调边界圈电压跟随指令。
  • 输运系数不是预测：χ_e / χ_i 取给定剖面形状，幅值按 IPB98(y,2) 标度并以平顶标定储能为锚（H_98 ≈ 1.07），L 模与 H 模共用同一锚。
  • 台基：H 模时 EPED1-NN 给台基温度，作为下一步的边界 Dirichlet 值；无 ELM、无驻留时间。
  • 成分：D:T = 50:50、⁴He 灰 3 % n_e 恒定、Ar 按 Z_eff 定量（全程 Z_eff = 1.8，文献平顶为 2.0）；Ar 电荷态按冕区拟合。
  • 加热沉积：EC + IC 合为一张沉积表（ONETWO 平顶 RF 剖面）按指令功率整体缩放，形状与电子 / 离子分配不随时间变。
  • α 粒子：出生处就地沉积（Stix 临界能分配），快 α 稳态密度计入稀释；不输运、不慢化扩散、灰分不累积。
  • 边界：ψ_N = 0.98 处 Dirichlet；边界 n_e 随指令线平均密度缩放，边界 T 在 L 模取给定值、H 模取 EPED 台基。

未涉及的物理

  • 导体壁 / 被动结构：真空室涡流、稳定壁、垂直稳定性均未进入平衡序列（内核 code/vstab 有，未调用）。
  • 线圈电路方程与电源电压限制：平衡是逐时刻静态冷解，只限线圈电流额定。
  • 湍流输运模型：推进中不跑 TGLF / QLK / CDBM；新经典热输运（Chang-Hinton）本算例关闭。
  • MHD 事件：锯齿、NTM、ELM、破裂均未建模。
  • 杂质输运与钨：Ar 不输运；钨辐射（文献 42 MW）未计。
  • 中性粒子、再循环、充气：无壁模型、无 SOL；弹丸只作固定高斯源，无消融物理。
  • NBI、LHCD：CFEDR 方案本身不含；内核有但未绑定。
  • 快离子：ICRF 尾、α 纹波损失、TAE / 鱼骨模再分布未计。
  • 下降段：回放节点是合成的（无来源下降方案）；I_p < 10 MA 后的 1.5-D 只作敏感性扫描（见「尝试过的方案」），展示取 0-D 层。

数值与方法

  • 分窗推进（台账 I-20）：一窗一次内核调用、自适应物理步长 ≤ 25 ms（电子–离子交换上限另限），窗切在每个回放节点；爬升 / 下降窗 0.5 s、平顶窗 5–50 s；10 ms 输出取内核逐步迹（含 W_th），剖面取窗端。
  • 快照 / 暂停 / 恢复（台账 I-21）：窗前快照入环、节点前 / 事件前 / 拒绝前永久保留；本算例 150 s 之后即自保留快照恢复续跑。
  • 事件处理：孤立 L-H 翻转以 10 ms 定步重走该窗；L-H 颤振保留自适应结果。
  • 加料：弹丸高斯源（ρ 0.7、宽 0.2），按窗末 n_e 对指令线平均密度比例调节。
