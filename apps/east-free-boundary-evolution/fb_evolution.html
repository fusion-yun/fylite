一 · 算例与要回答的问题

给一份 t0 时刻的初始平衡（G-EQDSK，附 A-EQDSK 更好）、此后各时刻的等离子体电流 Ip(t) 与 14 个 PF 线圈、2 个快控线圈（IC1、IC2）的实测单匝电流， 按时间推进自由边界平衡；再把一组点状电流源（真空室、被动板等被动结构，只给了坐标与电阻）当成环向电流丝放进来，算它们对位形演化的影响，并报告每根丝处的极向磁通。

数据说明里说被动结构电流是「给定」的输入，但数据里没有被动电流的时间序列——只有位置与电阻。所以应用三种都做（--passive）：

模式被动丝电流用途
zero恒为零（给定）「没有被动电流」的基准；丝仍在，报告各丝处的磁通
prescribed由 --passive-file 给定的时间序列调用方有被动电流时用；把 induced 的丝电流当给定回放，应逐步复现 induced
induced回路方程自洽算出数据里有电阻、没有电流时唯一有物理依据的做法

一次 run 的输出里每一步都有：解出的 Ip、磁轴、电流中心 Zc、ψaxis 与 ψbnd、边界（最外闭合磁面）与它是限制器还是 X 点定的、q、li、βp、 虚拟线圈对的电流，以及每根丝的电流与三种磁通。ψ(R, Z) 的图只留了最后一步（psi_last_Wb；逐步的图由 --gfile-dir 写成 G-EQDSK，不在 JSON 里）。

二 · 自由边界平衡

每个时刻解 Grad–Shafranov 方程

Δ*ψ = −μ0 R jφ ，　jφ = λ ( R p′(ψN) + FF′(ψN) / (μ0 R) ) (1)

λ 每一轮由 ∫ jφ dA = Ip(t) 定。ψ 在计算盒上 = 等离子体电流的磁通（盒边界由自由空间格林函数给）+ 外部导体的磁通

ψext(R, Z) = Σc Gc(R, Z) Ic + Σk Gk(R, Z) Ik (2)

c 走线圈通道（安匝，按通道的元素权重摊到各线圈元素，元素再分成 4×4 根细丝取格林函数平均），k 走被动丝。边界格子按磁通所占份额带电流（内核的「边规则」）， 于是逐步差分的等离子体磁通没有网格量化的抖动。每一步的解有三种状态（gs_state）：2 = 收敛；1 = 定住（残差停在一个由掩膜量化抖动定的地板上，是稳态读数，不是达到了 tol）；0 = 都不是。

三 · 被动丝的回路方程（induced）

每根丝是一个独立的环向回路：

Rk Ik + dΨk/dt = 0 ， Ψk = Σj∈丝 Mkj Ij + Σc∈线圈 Mkc Ic + Ψpk (3)

M 是丝与丝、丝与线圈元素之间的互感（各自截面分成 8×8 根细丝平均；对角是自感），Ψpk 是等离子体电流在丝 k 处的磁通—— 与构造 ψext 的同一套格林响应反过来读（互易）。时间上用隐式欧拉：

( Mvv/Δt + R ) In+1 = (Mvv/Δt) In − Mvc (Icn+1 − Icn)/Δt − (Ψp,n+1 − Ψp,n)/Δt (4)

Ψp,n+1 取决于这一步的平衡，而平衡又取决于丝电流：内核在同一次自由边界迭代里每一轮都重算一次回路（「内耦合」），所以壁在等离子体找平衡的过程中就回应它的移动。 线圈通道是电流驱动（给定），它们的电阻不进方程。t0 的丝电流（--passive-init）要么取零，要么取 ramp：匀速变化下的稳态解 Ik = −Ψ̇k/Rk；从零起步会多出一段约 3τ1 的暂态。

结果里每根丝报三种磁通（本页「被动丝」卡）：

Ψtotk = Σj Mkj Ij + Ψpk ， Ψextk = Ψtotk − Mkk Ik ，　Ψpk (5)

Σ 里的 j 走全部导体（线圈通道与丝）；单位 Wb（丝截面平均的磁链）。psi_gfile_Wb_per_rad = σ Ψtotk/2π，σ = ±1 取成与输入 g-file 同一符号约定——同一条量换尺，本页不另画。

四 · 竖直位置：虚拟线圈对

实测线圈电流的回放没有竖直控制：真实的竖直控制就在实测的快控线圈电流里，但它是对真实等离子体调的，对模型里的等离子体只是一个固定的外场。于是不钉位置时， 自由边界迭代在这组电流自己的（竖直不稳定的）平衡附近上下跳、不收敛；多个壁时间之后等离子体会在模型里漂向真空室。

应用用内核的虚拟竖直线圈对（盒外一对反向圆环）把电流中心 Zc 钉在 Zanchor（比例保持）：

Ifb = −g |Ip| (Zc − Zanchor) ，　g = 8 (6)

缺省的 Zanchor 是 t0 处线圈对不出力的高度（对 Zanchor 二分 Ifb = 0），即 t0 的平衡是这组电流自己的平衡； 之后线圈对的电流就是「给定电流在这个高度留下的竖直力缺口」。结果里报成两样：Ifb/Ip（fb_amp / ip），与线圈对在磁轴处补的径向场 BR,fb（pair_br_at_axis_T）。

线圈对的电流是结果的一部分：读作「给定电流与模型之间的竖直力缺口」。它大（门的说明里写着有多少步超过 Ip 的 1 %），那些步是「电流 + 线圈对」的平衡， 不是这组电流单独的平衡——线圈电流测量、线圈与壁的几何、剖面假设、t0 的被动电流都可能是原因。

五 · 剖面随时间怎么变（假设）

--profile fixed（缺省）：p′(ψN) 与 FF′(ψN) 的形状取初始 g-file、整段不变，幅度每步按 Ip(t) 重定——数据里没有剖面演化的任何信息， 这是唯一不引入额外输入的做法；βp、li 于是只随几何变。

--profile efit-trend：每 --segment 秒一段，段首重定形状

p′ → h p′g ，　FF′ → κ h FF′g ，　h = eγ(1 − ψN) (7)

使同尺 βp、li(1) 等于 t0 的 g-file 值加上 magdata 的 EFIT 迹相对 t0 的变化量。EFIT 迹是 EFIT 的结果，不是测量；段首形状跳变产生的感应电动势不进回路方程。 本页在 li、βp 图上用竖虚线标出各段的起点。

六 · 同一把尺

βp、li、W、V 对任何一份平衡（本应用的、输入 g-file 的）都用同一段积分量：

βp = 2μ0⟨p⟩V / B̄pa2 ，　li(1) = ⟨Bp2⟩V / B̄pa2 ， li(3) = 2∫Bp2dV / (μ02 Ip2 Rgeo) ，　B̄pa = ∮Bpdl / ∮dl (8)

Bp = |∇ψ|/R。q、边界、形状取自内核 code/summary（F 的边值取输入 g-file 的 bcentr·rcentr，即假定环向场线圈电流不变）。 magdata 的 li、betap 是 EFIT 迹（参考），compare 拿 li 对 li(1)——本页照这个配对画。

七 · 线圈与被动丝的映射

PF：装置事实里的 12 个 PF 通道（PF7+9、PF8+10 各是一对串联线圈）。通道的安匝

Ac = Σj∈c Nj Icoil(j) (9)

Nj 是元素匝数，I 是 magdata 该线圈那一列的单匝电流。IC：IC1 / IC2 各接成一个单元素通道（安匝 = 匝数 × 单匝电流），几何取装置事实，--ic-rz 可改。 本页「线圈通道」卡画的就是这 14 个通道的安匝。线圈与限制器的几何取装置事实（这一炮、这条测量链解析出的装置文档，与交给内核的是同一份）：run / initial / case 的输出里是 geometry 块；更早的输出没有这一块，用 fb_evolution.py geometry 单独写一份 geometry.json 一起拖入。截面上 PF 线圈画成 dR × dZ 的矩形（按这一步所属通道的安匝着色），IC 线圈另画，位置取这一次实际用的（装置事实或 --ic-rz）。

被动丝：按文件次序把点串成轮廓（相邻间距大于 --contour-gap 就断开，首尾够近的轮廓闭合）。每根丝是一条沿壁的平行四边形截面，厚

tk = 2πRk ρ / (𝓡k ℓk) (10)

𝓡k 是 VVres 的第 k 个值，ℓk 是到前后两丝距离之半的和；于是内核的元件电阻逐丝恰好等于 𝓡k（wall 命令复核这一条）， ρ 只决定截面的形状、进自感的对数项。本页按轮廓把丝连起来画，并在被动丝的图上标出轮廓的分界。

八 · 本页怎么读

文件

  • 点「导入结果 JSON」（可多选）或把几份文件一起拖进页面。按 @type 分：fylite:EastFreeBoundaryEvolution（run）→ 演化页；fylite:EastFreeBoundaryInitial（initial）→ 初始态页； fylite:EastFreeBoundaryComparison（compare）→ 比较页。辅助：fylite:EastFreeBoundaryGeometry（geometry.json，装置事实里的 PF / IC 线圈与限制器）；fylite:EastFreeBoundaryCase（in/case.json）只取限制器、g-file 边界与轮廓断开距离； wall.json 没有 @type，按形状认（有 tau_s 与 contours）。别的一律按名拒收。
  • 文件只在你的浏览器里读，不上传。一份 run 约 8 MB：只解析一次，逐步要用的量在载入时算好。

演化页

  • 步：滑条、◀ ▶、键盘 ← →（Shift 一次 10 步，Home / End 到两端），或点任一张时间迹跳到那一时刻；「播放」按步走。换步只重画截面、被动丝两张图与各图的时间光标，曲线本身不重画。
  • 截面（等比例，量程含线圈）：PF 线圈（按所属通道这一步的安匝着色）、IC 线圈、限制器（装置事实；旧文件从 geometry.json 或 case.json 取）、计算盒（虚线框）、158 根被动丝按轮廓连起来、每根按这一步的电流着色（发散色标，零 = 底色，量程是整段的最大 |I|， 所以颜色在各步之间可比）、这一步的边界与之前的边界淡迹、磁轴与它整段的轨迹、X 点。ψ 等值线只在最后一步画（结果只留了最后一步的 ψ 图）。
  • 时间迹：Ip 对目标、磁轴 R 与 Z、Zc 对 Zanchor、Ifb/Ip 与 BR,fb（建模缺口）、丝电流之和与最大 |Ik|、 GS 残差与迭代数、li(1)、βp 对 EFIT 迹、q95 与 q0；限制器位形的时段涂浅灰。
  • 被动丝：这一步每根丝的电流与三种磁通（横轴 = 丝序号，轮廓分界标出）；时间 × 丝的电流热图（按时间降采样到至多 160 列、颜色分 6 档）。
  • 叠加：载入两份以上 run 时，「主」与「叠加」各选一份。叠加的那份用第二种颜色画进截面与各时间迹，另出一张卡：两份逐步之差（磁轴移动、边界距离、丝处磁通之差、丝电流之和之差）。 两份按时刻对齐——时间网格不同（如 1 ms 与 2 ms 步长）时只比对得上的时刻。

初始态页 · 比较页

  • 初始态：t0 的各个解（用 magdata 实测线圈电流的、用 a-file 里 EFIT 拟合线圈电流的）与参考（输入 g-file 同尺）的边界叠画，外加逐项对照表与 Zanchor 的二分扫描。
  • 比较：compare 给的每一对 run 的最大差与每份 run 的摘要。compare 只留最大值；要看差随时间怎么走，把那两份 run 也拖进来，点这一对的「看差」。

九 · 局限 · 本页画不出的东西

  • 竖直控制是虚拟的（§四）；剖面是假设（§五），fixed 下 βp、li 不跟实验走，与 EFIT 迹的一致只是自洽性检查。
  • t0 的被动电流不知道：zero 与 ramp 是两种假设。
  • ψ 图只有最后一步：中间各步的 ψ 等值线画不出（要看就用 --gfile-dir 写出的 G-EQDSK）。
  • 线圈与限制器取装置事实（geometry 块）；较早的 run 文件没有这一块，要一起拖入 geometry.json（限制器也可以从 case.json 的 g-file 取）；都没有就不画，并写明缺什么。
  • IC 位置：装置事实与数据附图不完全一致；截面画这一次实际用的那个，geometry --ic-figure-rz 记下的附图位置画成虚线框（未用）。
  • 没有做：被动电流作为未知量拟合（需要磁测量）；非轴对称涡流；环向场线圈电流的变化；等离子体电阻与环电压（Ip 是给定的）。
