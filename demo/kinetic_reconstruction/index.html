使用与科学说明

1 · 单一 Python 文件，命令行无需 HTML

Linux x86-64（AVX2 / x86-64-v3），Python 3.10+。执行、服务及制图数据生成仅用 Python 标准库；数值反演全部在随包的 libfylite.so 中完成。

python demo.py --run input/native.json --pressure input/pressure_onetwo.json --out output/my_run.json
python demo.py --build-html --out output/my_run.json
python demo.py --serve --port 8765

第一条直接执行反演，第二条将该结果及其配套输入写入 HTML，第三条打开本地服务。浏览器访问 http://127.0.0.1:8765。不要使用普通静态 HTTP 服务替代 demo.py；静态服务无法调用动态库。已存在的输出不会被覆盖，请换新路径。未收敛的结果仍保存，命令行退出码为 2，页面显示“未收敛”。

MDSplus 与诊断配方 · 已启用

选择 M（纯磁）、MK（磁+POINT）、MP（磁+汤姆逊）、MKP（三者），再选择 EAST MDSplus 并读取。服务器沿用 202.127.204.12:8000，可编辑；炮号与时间使用秒。读取成功会保存独立输入，点击执行才计算。无有效 POINT 或汤姆逊逐点误差会报错，保留旧输入和结果，不用 ONETWO 补替缺失诊断。

python demo.py --pull --recipe M --shot 94048 --time 5.760 --out output/mds.json
python demo.py --run input/native.json --diagnostics output/mds.json --recipe M --out output/magnetic.json

数据读取使用随包固定 libsp，Linux 系统还需 libnetcdf.so.19、libhdf5_serial.so.103 及其依赖。预设压力离线计算不加载 libsp。诊断配方的完整 settings/options 在 JSON 的 workflow 内编辑；原复现参数表仅用于预设压力模式。诊断阶梯暂输出 |F|，完整重构置信区间未验证。状态 unphysical 或 P/K 失败不冒充成功。

预设压力文件格式

选择 ONETWO 存档并“加载”会恢复原51点约束；导入文件会替换压力观测、σ及优先权重。图仍为旧输出，执行后才更新。自定义 JSON 必须包含来源和真实提供的误差，不自动填造 σ：

{"schema":"fylite/pressure-preset/1","source":"data:my-pressure-file",
 "label":"自定义压力","time_s":5.760,"psi_N":[0,1],
 "pressure_Pa":[30000,300],"sigma_Pa":[3000,600],"fit_weights":[1,1]}

上面两点仅为格式示例，不是新增实验数据。省略fit_weights时使用1；这与ONETWO原有FWTPRE优先权重不同。导入数据不来自当前反演，修改压力或误差后会标记为用户编辑模型约束。fylite组装压力评估与诊断/q₀/边界交互规划见随包说明文件。

3 · 如何读误差棒、F 符号与参考对比

蓝线为实际计算结果，绿色点线为原磁反演 M 保存基线，灰虚线为原 KEFIT 存档。M 阴影为原目标函数曲率条件σ，与蓝色测量传播σ含义不同。磁通环比较使用“等离子体磁通 + 拟合后的 PF 磁通”，不是原 PF 电流对应的磁通。磁/PF 的误差棒采用原假定 3%，压力采用输入 SIGPRE。空心方块表示未参与拟合的物理通道；探针40个补零槽不画。

阴影是固定磁面几何条件下 ±1σ；测量传播与目标函数曲率不是同一种统计定义。关闭误差带时不会伪造范围。q 条件误差只传播固定磁面上的 F 变化；边界 F 固定，因此该条件 q 误差可为零，不意味着真实边界 q 无误差。F=RBφ 为带符号量，本例 Bφ 为负，F 也为负；σ 本身始终非负。

修改输入后，磁反演 M 和 KEFIT 仍是同一存档参考，不代表它按新输入重算。磁面线是保存磁通场的逐单元线性等值线，只取封闭 LCFS 内区域；未作平滑或新物理求解。完整 LCFS 直接来自内核输出。

4 · 数据来源、尚未覆盖的内容

平衡时刻为 5.760 s；压力来自已有 ONETWO 6.510 s 输出，未重新运行 ONETWO。时间不一致是原案例限制。完整噪声 pilot 的 8 个样本均未在150轮内收敛，其中5个出现负压力；后续小幅试验不能外推为整体置信区间。

已有 Te/ne/Ti 处理后剖面不含原始通道、时间和误差列。预设压力复现案例不伪造缺失的 Te/Ti 误差棒。诊断阶梯支持 POINT 与汤姆逊原信号：K 将 POINT 法拉第行加入反演，P 重映汤姆逊压力约束；Te/ne 显示原实测误差，不将压力反演解释为独立的 Te/ne/Ti 反演。

5 · 输出文件、可复现性和结果对应关系

每次运行保存完整输出 run-ID.json、实际输入 run-ID.input.json、库/输入/响应表 SHA256 与创建时间 run-ID.identity.json、可视化数据 run-ID.charts.json。动态库固定为已验证版本，校验不符会拒绝运行。网页结果只在运行成功返回后更新；失败时保留旧结果并显示失败信息。

“下载可视化数据”包含该结果实际采用的输入，可再次导入离线 HTML。导入输入仅修改草稿；导入可视化数据会恢复配套输入并标记来源。重置仅恢复页面内置输入，不删除磁盘运行记录。
