# 动理学反演交互规划

本文件区分已有可执行功能与下一阶段设计。当前页面已支持ONETWO/自定义压力预设、完整JSON、原生执行和输出对比；现已接通EAST MDSplus实际读取及M/MK/MP/MKP诊断阶梯。通道三态、统一q₀模式选择、LCFS约束仍属后续规划。

## 主流程与布局

顶部依次为 **数据来源 → 诊断与质量 → 约束 → 执行 → 输出对比**。左侧为当前步骤的输入卡，右侧始终保留上一次结果；输入改动后标明结果已过期。手机采用单列，先显示数据/诊断摘要和执行按钮，完整JSON折叠于高级设置。每次执行冻结一份输入快照；运行期间的新草稿不混入正在计算的请求。

### 数据来源

选择“随包案例 / 本地文件 / EAST MDSplus / 已缓存的MDS读取”。连接卡提供设备、服务器、炮号、中心时间和窗口宽度（明确使用s）、诊断目录版本。动作是“检查连接 → 发现本炮通道 → 预览原始信号 → 读取选中诊断”。不在网页写死所有树名和节点；同一诊断的服务器/树/节点、标定、单位与坐标从版本化设备绑定中读取。实际连接沿用已有部署202.127.204.12:8000；可在页面修改，CLI可传--server或设置FYLITE_MDSIP_SERVER。用户名沿用FYLITE_MDS_USER或进程USER。树/诊断绑定来自随包装置事实。

数据卡显示实际采样时间、可用/缺失通道数、单位、σ来源、校准版本、窗口平均/基线处理、是否来自缓存。缺失诊断可仅关闭该组；单位或时刻不明的条目允许预览，不能自动升格为拟合约束。读取失败保留已有结果与缓存并明确来源，不能把缓存伪装成此次在线读取。不向源MDS树写入数据。网络依赖为可选适配器，离线最小包仍只要求Python标准库。

### 诊断配方与通道选择

| 配方 | 拟合内容 | 默认输出 |
|---|---|---|
| 纯磁 M | 磁通环、磁探针、PF和Ip | ψ、LCFS、Ip、q、F、磁残差 |
| 磁 + POINT MK | M加POINT线密度/法拉第信息，经相应外环 | M/K对比、逐弦观测/预测与误差 |
| 磁 + Thomson MP | M加TS及独立离子假设组装的压力 | ne、Te、压力与M/P对比 |
| 磁 + POINT + Thomson MKP | 组合有效诊断和映射外环 | 分阶段与最终结果 |
| KEFIT复现/预设压力 | 原磁约束加ONETWO或独立压力预设 | 当前已验证兼容求解器结果 |

“纯磁”是反演配方，不是一种传感器。所有诊断采用三态：**参与拟合 / 仅对比 / 禁用**。组级选择下可展开通道表，显示原信号、误差、异常/缺失、权重和排除原因。应先依赖原标定/质量标记，再允许人工修改；修改写入记录，不覆盖原信号。

POINT只有已有/给定平衡时可作为条件诊断计算单独运行；不能声称在缺失磁约束时唯一确定完整平衡。TS只有ne/Te不唯一给出总压力：Ti、离子密度/组分、快粒子项及误差必须另有数据或明确模型。不可将同一诊断派生的压力和原始ne/Te当成相互独立的数据重复加权。

### q₀预设

显示启用状态、目标q₀、来源（测量/模型/用户先验）、约束模式和误差/权重；结果同时显示目标、拟合值和偏差。允许保存命名预设，禁止把目标值复制成拟合输出。

一般重构已有`q0_target`/`q0_weight`软约束，未启用则不加该行。当前历史兼容模式还会在更新阶段按`q_target`归一化轴系数，因此**它不是可以仅凭q_weight=0关闭的软先验**。页面应标明“兼容模式：q₀归一化目标”，该模式暂不提供“关闭”。若提供统一的σq接口，要在后端按各模型的直接q或逆q行定义转换；不能把历史`q_weight`原样解释为1/σq。

### 边界预设

将三种概念分开：

1. **真空室/限制器几何**：装置事实，通常只读，从设备数据选择版本。
2. **初始等离子体形状**：R₀、Z₀、a、κ，可加载参考轮廓；只影响初始化，不代表最终LCFS。
3. **LCFS约束**：自动识别（当前默认）、目标轮廓软约束（待实现）、固定边界（独立模式）。

导入轮廓格式为闭合的R/Z数组，单位m，记录来源、时刻及位置误差。图中分别标识目标轮廓、实际LCFS、误差容差和真空室。闭合、点序、非自交、网格范围和壁面相容性必须检查。

当前兼容求解器只有由场/限制器推导的磁面，不能将编辑`initial.limiter`假装成用户LCFS约束。仓内`code/fixed_boundary`是给定轮廓及p′/FF′的正向平衡，不等同于带任意磁诊断的固定边界反演。后两种LCFS模式需单独实现/验收，不能以固定边界正解替代所请求的反演。

### 压力来源（已完成第一阶段）

- **预设压力**：ONETWO存档或自定义p(ψN)、σ和优先权重；作为拟合观测，不强制结果等于输入。
- **fylite压力组装**：独立ne/Te、离子密度/Ti和可选快压力经`code/pressure`组装，再映射为约束；尚未作为网页执行选项。
- **压力仅作对比**：只在不使用压力约束的配方中成立；不能继续拟合旧ONETWO压力同时标成已关闭。

压力预设载入后仅修改草稿，显示来源、时间、点数及单位，执行后才更新图。导入必须提供误差，禁止用0或任意比例填补缺失σ；修改原压力后标记用户模型约束。临时格式示例不能当实验数据。

## 后端路由与能力状态

现有统一动态库包含传统`code/reconstruction`及`code/kinetic` M/K/P阶梯；新页面目前仅编排`inputs.native_reconstruction`历史兼容模式。将压力权重清零并不等于完整纯磁配方，POINT的后验比较也不等于将法拉第行纳入反演。下一阶段由后端明确路由并校验能力，前端禁用尚未可执行的选项，禁止静默降级。

页面下载一个统一实验配置，Python CLI和页面读取同一配置与能力表；输入/输出、诊断选择、被排除通道、压力来源和约束语义均进入执行身份。参考M/KEFIT与新诊断配方无关时明确标成固定参考，只有实际重新执行该配方后才能称为当前M/K/P结果。

## 实施顺序与验收

1. 已完成：独立单Python、ONETWO/自定义压力预设、来源记录、实际调用、离线/在线可视化。
2. 已接通：M/MK/MP/MKP实际内核阶梯，必需诊断缺失拒绝；导入本地诊断请求，输出各档实际磁面/压力/磁残差与POINT/TS原信号。
3. 已接通：固定libsp的MDSplus读取，按配方取数，保存独立输入；后续完善通道三态、目录发现、原时序预览、窗口配置、单位审查、q₀模式能力表和独立压力组装。
4. 单独科学任务：LCFS软约束与固定边界反演；同输入对拍、约束残差、未启用逐位保持、不可识别性及不收敛检查。

验收必须覆盖离线、读取失败/部分缺失、未知单位、诊断只作对比、不支持组合拒绝、不同配方实际行装配、q₀关闭/软约束/兼容归一化的差异，以及压力来源不会来自自身反演的闭环泄漏。只有界面选项出现不算功能完成。

## 当前实现的明确边界

预设压力兼容求解器与诊断阶梯为同一libfylite的两条已有入口。诊断模式使用workflow.inputs与workflow.settings，常用兼容参数表禁用；可用CLI不经过HTML。当前MDS归约沿用既有±5ms磁窗、炮前漂移与POINT专用窗，TS采用距离受限的最近脉冲。磁误差为5%/位下限模型，TS要求实测误差；没有完整重构置信区间。阶梯输出|F|幅值，带符号F保留在复现模式。诊断读取成功不等同于物理质量通过，unphysical/清洗警报与未收敛记录均保留。
