认识 FyLite

FyLite 围绕平衡、输运及相关物理模型提供轻量计算能力。原仓库将主要用途组织为“设计一炮放电 → 建模剖面演化 → 由实验测量反演状态”，并配套装置数据读取与算例报告。

本网站沿着这些用途逐步交付应用：先说明问题与输入，再提供示范、计算过程和实际结果，让用户能在个人目录中修改参数并复跑。每个入口会标明当前部署范围；产品能力介绍与本服务器已开放的功能分别说明。

FyLite 与 FyTok

原仓库将 FyLite 和 FyTok 定位为同一套 fyo 语义契约的轻型与完整框架实现：以 IMAS 数据字典语义为基础，让物理量、输入和输出有共同的表达方式。

定位FyLiteFyTok
主要用途轻量物理内核与应用，便于学习模型、快速试算和复跑算例。完整集成建模框架，组织模型、外部程序及复杂工作流。
组织方式以内建物理能力和应用工作流组成计算过程。通过插件与工作流连接不同模型、程序和执行环境。
验证关系共同语义有助于对齐输入和输出。实现间交叉比较需采用匹配的物理模型、参数和独立参考；本站当前尚未完成与 FyTok 的交叉验收。

轻量试算、参考计算与模型标定可以相互衔接；具体的适用性和精度，以各算例的验证记录为准。

本网站如何运行，数据保存在哪里

浏览器负责交互与展示，神马服务器执行物理计算。当前 EQ 由服务器调用发布的原生内核，直接在 login117 运行，暂不使用 Slurm。浏览器访问地址中的 IP 和端口由 SSH 隧道映射到远端服务。

公共示范与程序按版本保存在 /project/FyLite/v0.0.1-alpha-rc3/eq/。另存的个人算例、实际输入、日志和结果保存在用户自己的服务器目录；修改个人副本不会改变公共示范。

关闭页面不会自动取消已启动的计算；保存运行目录后可回来查询。下载到浏览器所在电脑的文件与保存到服务器个人目录是两种操作。

当前服务按启动它的一个 Unix 用户权限工作，通过 localhost 和 SSH 隧道访问；共享多用户服务后续单独建设。

当前验证范围

本部署是 v0.0.1-alpha-rc3 实验预发布版。当前已执行原生内核加载、固定边界合成求解、解析量/网格误差检查，以及个人保存和计算接口验证。

这些检查覆盖已记录的合成模型和执行流程。94048固定压力工作流已接入本版本，验证状态见其运行记录；实验纯磁 M 档已有 164437 的实际数据与数值复现记录，但仍未获得实验物理资格；诊断外循环和自举反馈仍需逐项测试；当前合成结果不授予这些流程实验验收资格。模型假设、通道处理与约束设置应随算例一起阅读。

第一次使用

  1. 进入平衡应用，了解问题、输入和计算流程。
  2. 阅读示范结果及详细过程，认识各个输出量与验证范围。
  3. 另存到自己的服务器目录，调整参数并运行。
  4. 检查实际状态与结果，保留运行目录，下载所需输入和输出。
