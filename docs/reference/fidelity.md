# 保真度边界

**这一章不是免责声明，是逐条实测的能力边界。** 越界使用不会报错，只会给出
看起来合理的错数字。

本章记的是**跨模块的、由实测钉住的**那几条。逐模块的适用域——每个物理模块在什么
假设下成立、参数域到哪里、越界时是拒绝（返回哪个错误码）还是钳制、验到什么容差——
在[物理与数值](physics-00-overview.md)十五章各自的「适用域与失效条件」与「验证锚点」
两节里。两处不重复：那边是**模块自己的**边界，这里是**装配起来之后**才看得见的。

## 随包 Green 表是近似的（历史）

★**本分发不带 Green 表**（按 LICENSE 3.1 移除），磁通环与探针的响应行由内核按给定网格
**现算**。下面是当年随包表的实测后果，留作判据的口径说明——它解释了交付重构里哪些量可信、
哪些不可：随包表由 efund 的**理想丝**重实现生成。实测后果：

- **边界磁通规是好的**：磁驱动拟合的 `psi_bry` 落在参考值 ~1e-3 Wb/rad 内
  （93060: −0.4772 vs −0.4780；70754 loops-only: −0.3921 vs −0.3928）。
- **内部剖面不忠实**：93060 上全磁拟合给 q0 = 0.147 / q95 = 19.1，
  参考是 1.00 / 3.22。**内部剖面不可定量使用。**

## 全权重拟合质量仍差

即便探针已按幅值门控，残差仍拖动磁轴上移。缺的是**真正的逐道标定/权重**
（EAST `RWTMP2`），不是几何也不是核。故：

:::{important}
**磁通环-only 拟合（`--no-probes` / `FWTMP2=0`）是质量基准。**
:::

70754 上该基准：$I_p$ −0.3%、`psi_bry` +0.0007、轴 R 偏 −33 mm、
q95 3.00 vs efit 4.48——**内部依然不对**。

## 探针核已被免责

曾疑探针核不对，遂实现 8 点传感器长度平均核并 A/B 测试：ASIPP 参考表**经验上
表现为点核**（93060 的 psi_bry 闭合 +0.0008 点核 vs −0.009 平均核），
故点求值仍为缺省。**这条不是猜测，是测出来的。**

## 正解侧的两条

1. 可规定的剖面只有解析三参数；多项式通道在平衡模式下惰性（见
   [正解与演化](../guide/forward-and-evolution.md)）。
2. **与反演的闭环检验不闭合**：三参数拟合到该炮自己的动理学重构，q0 能到 −2.6%，
   但 q95 仍 +19%、轴高 73 mm、边界中位差 45 mm。瓶颈是**表达力而非数值**——
   三个解析参数复现不了一条在动理学压强与自举约束下拟合的 18 系数 p′/FF′。
   故该模式应作**独立正向求解器**用，不是反演的往返自检。

## 反演页（浏览器）的三条

这三条是 `app/pages/analysis.html` 上**逐条实测**的边界，判据是它自己的合成孪生
（真值已知）与卷宗交付的重构。

1. **q(0) 与 q95 的可信度不同，差得很远——而且与噪声无关。** 把磁通环噪声调到
   **零**，多项式 `p′/FF′` 基仍然装不下解析剖面族造出的真值：`a` = 0.425 对真值
   0.376 m（**+13 %**）、`κ` 1.60 对 1.34、**`q95` 4.23 对 2.40（+77 %）**，
   而 `q(0)` 是 1.00 对 1.07。σ = 0.5 % 时逐道残差 2.6 σ，σ = 0 时残差 RMS 仍有
   2.0e-3 Wb/rad（约最大读数的 1.3 %）。★所以这是**基的表达力**，不是噪声；把
   `q(0)` 与 `q95` 当成同一条曲线上的两个读数，是这一页最容易犯的错。

2. **真空室涡流在只有磁通环时定不出来。** 把真空室的磁通环特征投影到「等离子体基
   做不到」的方向上之后只剩 **5.6 %**，低于拟合自身的模型误差——页面据此拒绝作答。
   **加上 79 个磁探针后残存升到 19.8 %**，此时孪生注入的 12 kA 内壳电流被还原到
   12.44 kA，`q(0)` 的误差从 0.494 降到 **0.025**。外壳与被动板落在退化方向上仍然
   错（12.6 / 58.3 对 6 / −3 kA）：**能定出的是通道能看见的那几个组合**。

3. **法拉第约束有一个最优权重，且是非单调的。** 孪生上按 0 / 0.25 / 1 / 3 的相对
   权重扫描，`q(0)` = 1.006 / **1.072** / 1.043 / 0.881（真值 1.065）——权重适中时
   误差从 0.059 降到 0.007，**过大反而更差**。页面不替读者定这个权重。

★另有一条与实现有关而与物理无关：内部场的响应行**不能**用「每格一根丝」的探针
响应搭。两条独立路径（格林行×拟合电流+线圈份额 ↔ 解出的 ψ 上积分）在外侧弦上差
2 %，在贴着磁轴的两条弦上差 **32 % 与 46 %**——那里 `B_R` 是两个大量相消的小差。
按内核读 `B_R` 的同一个半格中心差分去建行之后，最坏 2.6 %（探针那条路本身就是
2.3 %）。

## 自举—欧姆—拟合电流的闭环（T-A9，2026-08-23 实测）

判据与数字取自 `app/tests/validate-closure.mjs`（EAST #137985 @ 4 s，控件默认，
密度通道开、σ_neo 取 Redl-2021 档）与 Rust 单测 `neoclassical::closure_tests` /
`neoclassical::sigma_oracle_tests`。

1. **换算是恒等式，不是模型，而且它闭合。** `⟨j·B⟩` 与 `⟨j_φ/R⟩/⟨1/R⟩` 由同一次
   拟合的 `p′` 与 `FF′` 两种写法各组一次，内核换算把第一条变成第二条：实测相对差
   **2.65e-12**（判据 1e-9，来源：会话文件 12 位有效截断）。同一条换算对 NEO 解析
   支路**自己同时返回的** `jpar`/`jtor` 逐面 **< 1e-12**。
   ★换算里的 `p′` 项是**抗磁电流**，属于总量而不属于任何一道：去掉它，环向电流动
   **24.3 %**。所以被换算的是**拟合值**，三条曲线的加法写在平行度量上。

2. **σ_neo 的两个外部答案彼此不一致，而不一致的方向是可以说清楚的。** 把漂移动理
   支路的每条梯度置零、`Epar0 = 1`，它返回的 `⟨j·B⟩` 就是电导率本身——同一套归一
   单位，不需要任何桥。在 `f_t = 0.566`、`Z_eff = 1`、`n_energy/n_xi/n_theta =
   6/25/25` 上：

   | ν\*_e | Redl-2021 / DKE | Sauter-1999 / DKE |
   | --- | --- | --- |
   | 0.328 | 0.9994 | 0.9742 |
   | 3.284 | 1.0008 | 0.9331 |

   即 **2021 那一档跟得住求解，1999 在这个捕获份额上低 2.2–6.7 %**——这正是 Redl
   等人重新标定的理由，此处是量出来的而不是引用来的。★**深香蕉区（ν\*_e = 3.3e-3）
   这个 oracle 用不了**：解本身还在随节距角分辨率移动（`n_xi` = 11/17/25/33/41 →
   1.6112 / 1.4936 / 1.4214 / 1.3806 / 1.3569 e6，最后两档之间仍差 1.7 %），在那里
   断言一个百分数就是在断言一个截断误差。页面缺省用 Redl-2021。

3. **σ_neo 的 Spitzer 因子与本仓的 `spitzer_eta_par` 曾差一个 `1/0.51`——T-A18
   （2026-08-24，ABI v111）已订正。** 当时后者带的是 NRL 的 **η_⊥** 系数
   （`1.03e-2 Z lnΛ T^-1.5` Ω·cm），平行那支是 `0.51 η_⊥`；实测
   `σ_Sauter × η_NRL = 1.958` 正是缺口的形状，走那一档算出的欧姆加热功率因此偏大
   约一倍。T-A9 批不改它（它是当时每一份已归档答案所依的数），改为钉住关系并记成
   `FEATURE.md` §3.4 的明写缺口；T-A18 批补上 0.51（垂直支改名 `spitzer_eta_perp`
   保留），钉住的关系随之改为两条：`σ_Sauter × η_par ≈ 1`（实测 0.998）、
   `η_par/η_perp ≡ 0.51` 逐点到 1e-15。受影响的数字见 changelog 同日条目。

4. **梯子求积不是拟合的 I_p。** 首测差 3.88 %（24 面、两端各补一段桩：I_梯子
   377.24 kA 对拟合 392.48 kA），当时归给「梯子的两端」。★**订正（2026-08-23 第六批，
   T-A19 关闭）：归因只对了四分之三。** 两端桩确实错（轴上密度钉零，而 dV/dψ 在轴上
   有限不为零；边缘持常），改成线性外推段修掉约 3 个点；但余差与求积**阶数**已无关
   （梯形对抛物线复合差 0.06 %），在**面数**与**拟合场的掩膜口径**上：正解场
   （Σ格 = I_p 恒等成立）24 面 +1.53 % → 96 面 +0.43 % 随加密收缩，拟合场 96 面
   +1.11 % 是掩膜口径的地板。梯子现为 **96 面**，口径写在反演页那一行的行名里，闸子
   钉 < 1.5 % 且 48 面差 > 96 面差。换算的恒等式残差 1.7e-16 不变；自举份额仍用
   **同一套求积**的分子与分母，所以那一处这份差从头到尾就对消着。

5. **自洽外环在参考片上是一个不动点，收缩很快。** 自举电流交给内核的规定电流道
   （`gs_inverse_solve` 的 `j_pre`，ABI v17 起就在，此前这一页从不调用），只把余下
   那份留给磁场拟合。自举份额逐轮 **4.033 → 4.237 → 4.239 %**：第一轮移动 4.83 %
   （★这一条是非退化前提：规定电流道若是空操作，「收敛」什么也没说），第二轮移动
   **0.036 %**，两轮后自停。**跨轮变动 0.036 %，判据 < 5 %**。I_p 跨轮漂移
   0.042 %。
   ★**连起点一起算是 4.95 %**，那一段量的是「外环改变了多少」而不是「外环稳不稳」，
   闸子把它报出来但不对它设阈——一个离阈值只有二十分之一的边界，失败的理由会与所断言
   的事情无关。

6. **反过来说，这条闭环没有证明纯磁拟合的电流形状是对的。** 由
   `⟨j_ohm·B⟩ = σ_neo⟨E·B⟩` 反推出的环电压**逐面不等**（轴上 2.19 V，到 ψ̄ ≈ 0.85
   过零并转负）。一个定常放电只有一个环电压，所以这条曲线的散布正是「磁测量定不出
   电流形状」这句话的定量版本，页面把它画出来而不是把它平均掉。

## 逐时片重构：本炮的原始通道不够（2026-08-23 实测）

装置卷宗现在带着 #137985 的**九个真实时片**（1–7 s，从 EAST MDSplus 服务器拉回、由
`fylite.io.est2.reduce_est2` 归约；与既有 HDF5 dump 在 4 s 上逐通道**差零**）。但这条
时间轴只有**参考时刻**能拟出像样的解，原因逐条实测如下：

| 组合（4 s） | 结果 |
| --- | --- |
| 交付磁通环 + 交付线圈 + 交付 Ip | 收敛，χ²/dof 1.3e-5，q95 3.878 |
| **原始**总磁通 + 交付线圈 + 交付 Ip | 收敛，χ²/dof 1.5e-5，q95 3.852 —— ★这条一致性正是「总磁通减线圈份额」那条路的判据 |
| 原始总磁通 + 交付线圈 + **原始 Ip**（`pcrl01`，400.9 kA 对交付 393.5 kA） | ★**收敛**（订正见下） |
| 原始总磁通 + **原始线圈**（Rogowski）+ 原始 Ip | **发散** |

★**订正（2026-08-23 复测）**：第三行原写「发散（法方程奇异）」，复现不出来——原始磁通环
加原始 Rogowski **Ip** 在 4 s 上照常收敛（交付 393.46 kA 对原始 400.94 kA，差 1.90 %，
两档都收敛，l_i(3) 2.677930 → 2.377973）。发散只归**原始 Rogowski 线圈电流**那一行。
`pcrl01` 与 `cpasma` 差 1.9 % 仍然是事实，它只是不足以让解散掉。

两条结论：

1. **线圈电流被求解器当作精确已知，而原始 Rogowski 达不到那个精度**（与交付拟合值逐道
   差 2–9 %）。EFIT 自己是**把线圈电流一起拟合**的，本内核不拟——所以这不是调参能解决的，
   是内核少一类未知量。
2. **`pcrl01` 不是等离子体电流**，它与交付重构的 `cpasma` 在平顶差 1.9 %。

## 线圈电流作为带 σ 的观测量（T-A5，2026-08-23 实测）

上一节第 1 条已经关闭：内核多了一类未知量。`inverse::solve_inverse_coils` 把线圈电流从
右端（真空场 + 逐道减去的线圈份额）搬进待拟参数向量，每道带一条 σ 先验；C-ABI 入口是
`fylite_rs_gs_inverse_solve_coils`，老入口 `fylite_rs_gs_inverse_solve` **一个字节没改**，
σ 全零时两者逐位相同（Rust 单测钉住）。

**开关打开前后，同样九片、同样原始 Rogowski 电流、同样基阶数：**

| | 落在 l_i(3) ∈ [0.5, 3] 的片数 | l_i(3) |
| --- | --- | --- |
| 线圈当作精确已知（原状） | **0 / 9** | 4 片解不出；其余 9.01 / 10.90 / 14.15 / 17.77 |
| 线圈作为带 σ 的观测量 | **8 / 9** | 1.18 – 1.85 |

默认 σ：线圈 0.07 × \|I_道\|（实测逐道差 2–9 % 的中上段），磁通环 0.03 × max\|ψ_等离子体\|。
八片的线圈位移 0.98 – 1.49 σ，I_p 等式相对差最大 5.15e-5，最小 a = 0.411 m——**既有的两条
退化判据一条都没有放松**，另加第三条：位移超过 5 σ 的片按失败报出。

三件必须一起写下来的事：

1. ★★**这个开关问的是两个 σ，不是一个。** 加权最小二乘只有在 `w = 1/σ` 时才是后验，而本仓
   每份卷宗给的磁通环权重都是 **0/1 掩膜**——那等于宣称 σ_环 = 1 Wb/rad。对着一条百分之几的
   线圈先验，这句宣称的意思是「磁通环不值钱」，拟合于是**一动不动**：实测 4 s，20 % 的线圈
   先验只把电流挪了自身的 3e-4，l_i(3) 21.30 → 18.06。所以「把线圈一起拟合」不是一个可以
   单独打开的开关，它**逼着读者说出磁通环测得多准**。内核把这句话收成一个参数
   （`CoilObs::meas_sigma`，「权重 1.0 代表多大的测量误差」），页面把它做成一条滑块。
2. ★**逐道的线圈电流本身不可辨识，可辨识的是真空场。** 一圈磁通环看外面几台线圈，只看得到
   几个低阶多极矩。孪生实测：拟合把某一道的修正改错了方向，同时把磁通环残差压掉 14 倍、把
   真空场对真值的 RMS 误差压掉一半以上。Rust 单测因此断言的是**场空间**那一条，不是逐道
   还原——要求后者等于向纯磁拟合要它给不出的东西。
3. ★**结果不是 σ 的光滑函数。** 在 σ_线圈 ∈ [0.02, 0.10]、σ_环 ∈ [0.005, 0.05] 上扫描，
   落在窗内的片数在 5 与 9 之间跳，没有单调结构：边缘那几片的 Picard 迭代是混沌的，
   一个 1e-16 的输入差就能把它送到另一处（同一件事也表现为——把 worker 里两个折叠的
   求和次序换掉，批处理队列十一行里有一行从「内核拒绝」变成 `shape_metrics` 失败）。
   默认那一档实测 8/9；整片可信区域里实测 7–9/9。**判据钉在 7，因为判据就是 7。**

★**爬升段的结论要改。** 上一节说爬升段（1.0–2.5 s）「在两种组合下都解不出」，并归因于
真空室涡流不可辨识。线圈电流一起拟合之后，1.0 / 1.5 / 2.0 / 2.5 s **四片全部解出**，
l_i(3) 1.43 / 1.53 / 1.85 / 1.18。涡流不可辨识（上一节 5.6 %）仍然成立，但爬升段解不出
**不是**它造成的：造成它的是同一件事——线圈电流在爬升段变化最快，而它们被当成了精确已知。
唯一还解不出的是 **t = 4 s**，即参考时刻那一片（等离子体掩膜在迭代中塌掉）。

因此页面的做法是：时片带自己的线圈电流与 Ip（物理上各归各的），**失败的片按失败报出并
写明原因**，另给一个「线圈电流用卷宗那份」的开关并把上表的取舍写在开关旁边。

## 稳定性侧的一条

只用内壳会把 γ **高估 270 倍**（3437 vs 12.6 s⁻¹）。凡报 γ 必须同时报所用的
被动导体集。

## 失败时怎么办

★**这一条已随 EFIT 驱动一起离开。** 保留 `/tmp/kefit_run_*` 工作目录、在错误消息里附上
求解器 stdout 尾部，是那条 fork 子进程路径的做法；本分发里没有那个子进程，也没有那个
工作目录。

今天的对应物是**当场报出**而不是留痕：内核的每个入口把负返回码抬成 `KernelError`；
重构在自己的两条陈述不成立时按失败报出并指明是哪一条（等式约束 `|I_fit − I_约束|/I_约束
≤ 0.5`、解出的是等离子体而非一团 `a ≥ 0.1 × 真空室半宽`）；装置数据缺件抛
`MachineDataMissing` 并写明缺哪个文件；oracle 未命中抛 `OracleMissing`。**没有一条会返回
一个看着合理的数**。
