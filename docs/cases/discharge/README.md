# 完整放电模型案例

这三份案例覆盖启动、电流上升、平顶、下降和终止。参数是明确列出的模型假设，
并非装置额定运行点或实验炮。EAST 案例与结果仅供内部使用。

用当前构建的原生宿主执行，例如：

```bash
fy demo --case docs/cases/discharge/iter-full-pulse.json \
  --facts ../fylite_dev/dist/bundled-facts --out output/iter-full-pulse-new
```

每次选择新输出目录。`--kernel` 可指定实际被测的原生动态库；默认使用宿主链接的内核。
旧内核缺少粒子焓输运支持时会拒绝案例。输出保留全部文档门输入、响应、哈希回执、
案例和事实快照，成功结束后生成 `discharge-demo.json` 与独立 `viewer.html`。
看板可离线导入其他同格式结果，播放或逐片拖动，不插值计算状态。

启动使用原生 0D 处方模型；交接后使用连续状态的固定几何 1.5D 热、密度与电流模型。
0D/1.5D 交接尚未通过守恒映射验收。二维 GS/PF 显示初始设计；归一量中使用名义
电流的诊断标“参考”。这不是动态平衡、完整 PCS 或硬件验收。

固定磁面粒子焓通量使用 ASTRA（Pereverzev 与 Yushmanov，2002）式 83–84，
取显式修正因子 `ge=gi=1`。ITER/CFEDR 终止阶段使用声明的有效热扩散率和短时冷粒子
边界储库。这些假设用于展示终止过程，未经实验标定；粒子边界补给与体积加料源分别记录。

完整末时刻与关断验收分开：检查所有原生包围电流面、温度、密度、热储能和执行器状态。
任一不满足都保留实际结果并返回失败。`COMPLETE` 表示上述案例条件满足，
不代表全部数值守恒门、实验验证或发布验收通过。

视频生产者为 相邻开发仓的 `tools/discharge/render.cjs`。设置本机 `PLAYWRIGHT_MODULE`、
`CHROMIUM_EXECUTABLE` 后，传入新输出目录及原生 JSON；逐片渲染并生成 FFmpeg concat
清单。视频只改变播放速度，保留每个切片的实际物理时间和阶段。


自由边界电路诊断可通过 `code/evolve_free_boundary` 的 `source=inversion`
使用实际压力/电流源，`newton_krylov=0` 默认使用 Picard；正整数 1–50
启用原生 Newton–Krylov 迭代，物理源和未加速残差的收敛判据保持不变。
`save_circuit_state=1` 保存电压电路续算状态；电压驱动的 `equilibrium_out=1`
发布同一状态的几何与磁网格。电流驱动也可发布其拥有的最终原生压力解，
但不提供电压电路 checkpoint；两种发布都要求内耦合和零虚拟增益，须清除 `hold_boundary` 和 `face_ip*` 二次细化选项。
输出不包含插值热状态。移动域库存、压缩功、边界通量由独立物理交接负责；
重分区遇到域扩大时要求显式外部状态。上述诊断接口尚未接入这里的完整放电生产者。


`code/core_material_motion` 接受 `previous_equilibrium`、`equilibrium` 和旧
`core_profiles`，以及版本 1 的 `material_motion` 文档。文档须提供
`old_material_faces`、`new_material_faces`、`time_start`、`time_end`；两组坐标
从零严格递增并覆盖同一材料域，各含对应控制体数加一个面。旧状态时间须等于
`time_start`，`settings/time` 须等于 `time_end`。这是一项显式材料运动声明，
不会从磁标签推导；已有 `fylite:material_faces` 必须与旧标记一致。

该接口先在材料坐标上 P0 守恒重分区，再执行一次理想气体 BE 压力功，输出
粒子账本和独立的 `pressure_work`，以及新状态时间和材料标记。它不接受外部
填充，不包含磁历史或旋转交接；不能在后续热步再次应用同一体积比或压力功。
若提供有效电荷，则在固定电荷态假设下转移 `n_e*Zeff`；电离另有职责。
P1 账本包含两端半控制体，接入输运内部域时还须处理外部储库和重分区域份额。
原 `code/core_rezone` 的物理体积重叠语义保持不变。两者尚未接入完整放电生产者。


材料运动账本另有 `interior_accounts`，对应输运实际推进的 `[0,n-1)` 节点域；
最后固定边界半控制体属于储库。`to_reservoir`／`from_reservoir` 表示材料重分区
改变计算域造成的份额转移，不能当作物理粒子通量。逐新控制体的电子／离子
`*_cell_pressure_work` 包含最后半控制体，内部域只取前 `n-1` 项。
隔离热步诊断已能接收交接状态并保留原热、密度、辐射和聚变闭合；电流关闭时
其磁通占位输出不能覆盖持有磁状态。该诊断不代表共同时间事务或磁历史交接完成。

`code/material_block` 将材料重分区／压力功与热／密度推进放入同一
`t_start`—`t_stop` 物理区间。内部材料阶段不产生完成状态时间；最终热步必须
到达 `t_stop`，才发布热／密度状态。候选平衡时间及材料事件时间必须与该区间
一致，禁止重复旧容量或体积功事件。当前要求热、密度开启，拒绝电流、欧姆、
动量和 probe；输出排除未推进的磁通占位值，不能覆盖独立磁状态。

该接口采用一阶算子分裂，在候选终态几何上推进热方程。材料阶段的 BE 压力功
不等同于使用热步终态压力的整体隐式解；终态压力与几何的一致性须由外层求解
闭合。材料标记仍须显式声明，不能从磁网格推断真实物质运动。
实际梯子短区间重放中，EAST 200 μs、CFEDR 100 μs 的原生热平衡相对误差分别为
3.74e-14、1.43e-13；两项针对性测试通过，四份旧接口完整响应重放保持一致。
原始请求、响应、库哈希及回执位于
`output/east-cfedr-evolution-2026-10-12/shared-material-block-replay` 与
`shared-material-block-legacy-replay`。这些结果尚不构成完整放电、电流／欧姆
历史交接或动态 GS/PF 耦合验收。

`tools/discharge/probe_shared_geometry_feedback.py` 进一步从固定旧热状态、旧几何
和 EAST 已接受电路状态重复求解共同时间块，再把其终态压力交给原生 GS/PF。
压力使用候选几何及其直接发布的磁坐标；每次试算均从同一个旧状态开始。
`--resume` 只续接已经终止的 `MAX_PASSES` 批次，并验证实际原生请求／响应哈希、
库身份和成功回执。Python 只编排调用和比较数组，不求解或混合物理状态。

该诊断尚未闭合：EAST 32 次试算后仍有几何差异；CFEDR 第 14 次压力 GS 求解
在 3000 次迭代后残差 0.0051628，原生拒绝返回。此前实际热步全部通过原
1e-11 热平衡门。几何比较的 1e-7 仅为预先声明的诊断停止条件，不替代完整
科学验收门。原始失败、继续批次和逐回执审计位于同一证据根的
`shared-geometry-feedback*`。这些试算没有采用为时序状态；下一步须处理原生
外层耦合和相容初态，再接电流／欧姆历史。

压力反演另可显式绑定 `inputs/frozen_current`：版本 `model_format=1`，
`coordinate=psi_norm`，`psi_convention=outward_full_turn`，`time_start`／
`time_end` 与 `pulse/fylite:time` 的首末时刻严格一致。该文档携带一个独立旧
输运框架的 `rho`（m）、`vprime`（m²）、`gm2`（m⁻²）、`psi_norm`（1）和
`psi`（向外取向的整圈 Wb），由 Rust 计算该框架的包围电流曲线。压力仍来自
候选终态热状态；电流曲线在整个诊断区间内固定于所声明的 `psi_norm` 标签。
候选 GS 发布的磁通不能隐式替换这个旧电流来源。

此绑定仅接受 `source=inversion`，返回 `frozen_current=1`；缺省仍反演当前
输入状态，不改变旧接口行为。这是显式固定电流源诊断，并非电流扩散、磁历史
交接或材料流动模型。`probe_shared_geometry_feedback.py --frozen-current`
可编排该对照；续接批次不能更改电流来源职责。

固定旧电流对照中，CFEDR 40 个共同时间块试算的热平衡最大 1.104e-12，
每个 GS 内部求解收敛，外层几何差异仍约 1e-4，未达到诊断停止条件。
EAST 前五个试算返回，第六个材料事件要求过大的单次压缩，被拒绝。
该拒绝现明确标为压力功步需要细分，而非网格错误；细分必须来自物理运动
路径，不能仅改完成时间或温度来通过。3 项电流来源测试、7 项材料运动测试
通过，两份默认 GS 完整响应保持一致；错误信息修正后的三份实际成功响应也
保持一致。证据见 `frozen-current-audit`、`frozen-current-legacy-replay` 和
`frozen-current-work-step-replay`。外层闭合、相容初态及完整放电仍未验收。

材料文档可显式选择 `work_integrator=adiabatic_exact`，缺省仍为
`backward_euler`。精确路径只积分封闭、无热源的理想气体机械阶段：
`dU/dV=-(2/3)U/V`，因此 `T_new=T_ref*(V_ref/V_new)^(2/3)`，
压力功为独立的 `-∫p(V)dV`。原生算子同时转移粒子、更新热能并记录逐控制体
压力功，避免在热算子中重复计功；微小体积差使用 `ln1p`／`expm1` 保留精度。
这一选项无需 BE 的有限压缩分母，但不提供物质运动路径，也不使整个
材料／热算子分裂成为精确的联合演化。

10 项材料测试与6项交接文档测试通过；四份默认材料／共同时间块响应与旧记录
完全一致，未知积分选项被拒绝。`audit_adiabatic_work.py` 使用90位算术独立积分
P1 体积和压力功，核对真实 EAST/CFEDR 电子／离子状态，通过原1e-11门。
选择精确机械阶段后，两套模型各16次共同区间热／GS试算返回，热平衡最大
1.58e-13／8.35e-13；EAST不再因 BE 压缩限制中断，但两套外层几何均未闭合。
原始回执和审计在 `adiabatic-exact-assessment`、`adiabatic-exact-audit-both`、
`adiabatic-exact-legacy` 及 `shared-geometry-exact-work`。候选状态没有进入完整
放电生产链；下一步仍需相容初态与原生外层闭合，再接电流／欧姆历史。

固定电流文档可另给 `lcfs_current`（A，正的电流幅值），绑定独立的整条 LCFS
电流边界。该值须与常值 `pulse/fylite:ip` 幅值及显式 `ip_a` 一致；原生算子
保留每个内部电流面，另加入轴上零包围电流与 LCFS 边界。`ip_faces` 仍报告
原内部域末面，`ip_lcfs_bound` 报告 LCFS 数据，不能将两者校准成相同数值。
压力／电流反演可使用独立采样域，新增电流边界不会补造 LCFS 压力数据。
`--lcfs-current` 对照使用原输运处方的 0.6 MA／15 MA；缺省诊断接口行为保持。

另已修复 F 边界读取：当 F 表与 `psi_norm` 配对且止于小于1的磁面时，表末值
属于内部面，不能逐轮作为 LCFS 的 F 常数。此时原生发布使用声明的真空
`r0*B0` 参考；确实覆盖 LCFS 的完整表仍使用其边界数据。这项修正改变派生
F／q／rho／度量。EAST/CFEDR 原请求隔离重放确认，二维磁通、实际电路／
等离子体源数组、事实和电路状态均保持相同；旧派生几何结果留存，不覆盖。

修正后，EAST 52次、CFEDR 19次短区间试算达到原诊断1e-7几何停止条件，
最大几何差异分别9.19e-8／4.64e-8；热平衡最大9.65e-14／4.06e-13，通过原
1e-11门。7项相关原生测试通过。逐回执审计位于 `boundary-current-assessment`，
F边界隔离在 `boundary-f-isolation`，全部原始试算在 `shared-geometry-boundary-f*`。
这些是固定电流和声明材料标记下的短区间闭合；尚未验完整电流／欧姆历史、
物质运动模型、相容启动、全放电或新视频。

`probe_matched_current_heat.py` 使用与已接受热候选网格严格相同的原生磁发布，
在固定几何、边界磁通率为零的条件下初始化并续算电流／欧姆／热／密度。
初始化不假定更早的磁历史；下一段直接读取前段发布的磁通、电导率及其真实
间隔。两段100μs与一次200μs的温度、密度、磁通和电导率差异均小于1e-11，
实际热平衡最大6.77e-14／4.21e-13。欧姆密度的分段差异仍约1e-7／3e-8，
不宣称其达到1e-11。

电流内耦合残差已改为比较本步磁通增量，避免静态绝对磁通偏置掩盖电场率
变化；原1e-6固定点阈值保持。独立二进制精确制造控制先失败后通过，另5项
相关耦合／续算／边界时钟测试通过。CFEDR欧姆密度与最终磁历史的90位独立
检查差异从1.59e-3降至5.64e-8，EAST为6.46e-7。原始响应及审计在
`matched-current-heat`、`matched-current-rate` 与 `current-history-assessment`。

另在无时间推进的初始探针中发现，CFEDR一维末面电流为15.9331MA，而原GS
单元电流均为正、合计15MA。这不能用分域差异解释，尚不接受一维面电流与
二维场的离散兼容性；没有缩放电流来隐藏差异。见 `current-initial-metric-probe-bound`。
下一步核对磁面包围电流和面通量，再接移动磁历史与电路边界；完整时序仍未验收。
