# 测量重构与约束阶梯

*平衡 (Equilibrium) · 本域答：从一炮的磁测量、MSE、动理学剖面反推平衡，反得准不准——★判准必须落在**可观测空间**。*

从一炮真实放电的测量反推那一时刻的平衡：磁探针、磁通环、MSE、动理学剖面，凑出一个
自洽的 $\psi$。这是本册里**唯一直接对着实验说话**的一域，也因此是最容易把话说过头的一域。

★★**这一章有一条不能让步的规矩：判准必须落在可观测空间。** 重构出来的内部量（$q_0$、
$l_i$、磁轴位置）没有真值可比——两个码给出不同的 $q_0$，你无法判定谁对，因为没有人测过
$q_0$。能判的只有一件事：**各自的解正过来预测测量，与实际测到的差多少**。上游 SRS 把这一条
写成 MUST，而它恰恰是上一册长期记名的缺口——旧册的孪生记录主判据落在内部量上。
按域组织之后这类偏差自己显形，不必等人想起来。

第二条难处是**约束阶梯**。一次重构用了哪些约束（只磁测量 / 加 MSE / 加动理学剖面）决定了
它能声称什么。★**拿三级约束的结果去和别人一级约束的结果比，比出来的差是约束的差，不是
码的差。** 记录必须把阶梯的档位写进 `validity_domain`，并在 `caveat` 里点明哪些量是
**喂进去的**而不是算出来的——这一条在重构里尤其关键，因为喂进去的量看起来和算出来的一样。

上一册这一域最厚：`B-06` / `B-11` / `B-12`（EAST 重构、对 EFIT-EAST、对原始树 KEFIT）、
`B-15` / `V-18`（孪生对 KEFIT / 孪生重构）。已退役。
