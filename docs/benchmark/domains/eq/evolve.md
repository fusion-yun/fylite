# 演化自由边界与涡流电路

*平衡 (Equilibrium) · 本域答：让平衡随时间走，被动结构里的涡流跟不跟得上——轨迹对不对。*

让平衡随时间走：等离子体电流在变、线圈电流在变，而被动结构（真空室、支撑、包层）里被感应
出的涡流反过来改磁场。这一章问的是这条回路闭得对不对。

★**它与前向求解不是一件事，虽然每一步都在解前向问题。** 单步解得准，不保证轨迹对——
轨迹的对错取决于电路方程与场方程之间的耦合怎么离散、时间步怎么推。一个每步都很准的解
串起来完全可以漂到别处去。

量它的尺有两把。**零等离子体极限**是硬的那把：把等离子体拿掉，剩下的纯电路问题有解析解，
轨迹必须逐位对上——这一档不该有容差，对不上就是接线错了。带等离子体之后没有解析解了，
只能对着另一个码的一次运行量，那就落进"对拍"而不是"验证"：★**两套模型吻合到百分之几
不等于谁对，两个错误也能互相抵消。**
