# 解析判据阶梯：外扭曲模 q 极限与气球模第一稳定边界

*MHD 稳定性 (MHD Stability) · 本域答：教科书有闭式答案的那两级：均匀电流柱的 q 带边、气球模 alpha_c(s) 曲线。★它们是本册的**尺**——尺不准，上面的都不算数。*

这一章是本册的**尺**。外扭曲模在均匀电流柱上的 $q$ 带边、气球模的第一稳定边界
$\alpha_c(s)$——这两级在教科书里有闭式答案，所以它们能被验到机器精度，而不是"对拍到
百分之几"。

★★**尺不准，上面的都不算数。** 后面两章（能量原理内核、全 $\delta W$）没有解析解可依，
它们的可信度是从这一章借来的：同一套变分机器，在有闭式解的极限下复现到 $10^{-10}$，
它在没有闭式解的地方给的数才值得看。所以这一章的记录在本册里的地位与别处不同——
它不是"又一条比较"，是**其余稳定性记录的前提**。

这一章还有一类判据是别处没有的：**拒绝求解**。共振面落在计算域内时，正确的行为不是给
一个数，是拒绝——给数就是在一个方程奇异的地方硬凑。同理，理想不稳时必须 fail-loud 而不是
返回一个看起来正常的增长率。★**"它不肯算"也是一条要被验的判据**，而且是容易被忘掉的那种。

收敛档要记明。上游的判据里写着截断阶 24 与 32 差 $<10^{-3}$，并**记明 16 不够**（偏低 3.6 %）——
把"不够的那一档"写进记录，比只写"够的那一档"有用：后者只说明选对了，前者说明为什么。

★上一册在这一域**没有记录**。L0 / L1 这一层的门在内核侧，公开册从未量过它——这是一处
真空白，不是被遗漏的条目。

### 尺的第一格：外扭曲模的 q 带边（2026-09-18）

`FR-EQ-017` 入册，判**成立**。★2026-09-18 之前**内核里理想 MHD 稳定性一行都没有**——
上面那句「这是一处真空白，不是被遗漏的条目」，今天开始填。

★★**本机没有写下这条方程**，所以推导是自己做的，而推导对不对有一个干净的自检：
**它必须同时给出两条带边**。均匀电流时方程里的驱动项恒为零、边缘跃变项只剩一个极点，
代进边缘匹配解出 $m-nq_a=1-\lambda$——正是下带边 $(m-1+\lambda)/n$；上带边 $m/n$ 是同一式的极点。
下边带着 $\lambda=(a/b)^{2m}$，**一个凑出来的常数能对上一个数，对不上两个，更对不上带壁的那一个**。
20 组 $(m,n)\times b/a$ 上最劣相对 **9.3e-14**。

壁扫描的带宽**逐个对闭式** $(1-\lambda)/n$，而不只是看它单调——★这里我先写错过一条断言：
以为 $b/a=1.05$ 时带该「几乎归零」，实测 0.254。$\lambda=1.05^{-6}=0.746$，
**$2m$ 次方让 $\lambda$ 掉得比直觉快**，贴到 1.05 远不是贴到 1。

★★**「它不肯算」**这一格照上面的要求验了两头：共振在域内按名拒绝，
而整条剖面在共振之下时**不**拒绝——只验前者会放过一个见 $q$ 变化就拒的实现。

★★收敛档按上面的要求**记明不够的那一档**：峰化剖面上 201 点差 4.5e-8（不够），
801→3201 才进 1e-9。而走到这一步用了四次改动，其中两次是反直觉的：
**内点升四阶而端点留二阶，结果比全用二阶更差**（边缘跃变项直接吃 $q'(a)$）；
**RK4 半步的驱动项取两端平均**，这个看着无害的平均把四阶方法压回了二阶。
实测收敛阶 2.98 而不是 4——照实记，还有一处三阶的环没找出来。
详见 [`mhd-analytic-external-kink-qlimit`](../../reports/mhd-analytic-external-kink-qlimit.md)。

### 尺的第二格：气球模第一稳定边界（2026-09-18）

`FR-EQ-018` 入册，判**成立**——这一域到此清空。s-α 模型下偶模从 $F(0)=1$、$F'(0)=0$ 打出去，
Newcomb 节点判据：域内有零点即不稳，于是打靶量 $S(\alpha)=F(\theta_{max})$ 的零点就是边界。
$\alpha=0$ 时它**逐位**是 1；$\alpha_c(s)$ 单调升，$s=1$ 处 0.6086（教科书 $\approx0.6$），大剪切端斜率 0.60 / 0.62。

★★**上面要求「记明不够的那一档」，这一条记下的东西与判据写的方向相反**：
判据说上游「16 不够，偏低 3.6 %」，而这里的 16 是**偏高** 0.97 %。原因是结构性的——
真边界上节点在无穷远，有限截断要等 $\alpha$ 再大一点把节点拉进域内才看得见，所以截断**从上方**收敛。
★方向不同说明两边的「截断」不是同一个量；**不去凑那个 3.6 %**，凑出来的数就不再是测量。

★★而本实现的截断有一样比「24 vs 32 < 1e-3」有用得多的东西：**它的误差严格按 $1/N$ 走**
（逐段差除以 $\Delta(1/N)$ 恒为 0.094，彼此差不到 1.5 %）。律一旦量准，Richardson 一阶消去就是对的那一阶，
外推换一对 $N$ 只动 3e-5——**这才是收敛的证据**。单看两档之差不行：24 vs 32 以 1.7 % 的余量过了判据，
而 32→48 同样动 1e-3。
详见 [`mhd-analytic-ballooning-first-stability`](../../reports/mhd-analytic-ballooning-first-stability.md)。
