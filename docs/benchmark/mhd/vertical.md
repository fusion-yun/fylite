# 竖直稳定性、线圈受力与电磁线性模型

*MHD 稳定性 (MHD Stability) · 本域答：拉长的位形会不会竖直漂走、增长率多快；线圈受多大力；导出的线性模型对不对。*

拉长的位形在竖直方向上本征不稳：等离子体往上下任一方向偏一点，受力就把它推得更远。
被动结构里的涡流延缓这个过程，控制线圈再把它按住。这一章问的是增长率 $\gamma$ 与位移
裕度算得对不对，以及线圈到底受多大力。

★**这一域是本册里少见的"有解析锚"的稳定性问题**，这一点值得用足。单回路情形有闭式解
$\gamma = (1/\tau_w)\,k/(k_{\rm ideal}-k)$；刚度与衰减指数之间有恒等式 $k = 2\pi I_p n B_z$；
壁越远 $\gamma$ 越大是结构性单调。这些锚不需要任何外部码，却能抓住绝大多数接线错误。
★**先把锚钉牢，再去和别人对拍——顺序反了，对拍出的差你解释不了。**

线圈受力有三个各自独立的解析锚：单环自感的环向力、双环互感力 $\dd M/\dd z$、环心场
$\mu_0 I/2R$；再加一条系统合力 $F_z = 0$。四条一起过，接线就基本不会错。

难处在**壁的模型**。涡流算得对不对，几乎全取决于被动结构怎么离散、超导线圈屏不屏蔽。
上一册在这里踩过一次并改判过：`V-23`（ITER 被动回路）最初把 $\tau$ 的差归给导电接头，
后来查明是超导线圈的屏蔽。★这类改判是记录制度**在起作用**的证据，不是它的污点——
所以本册要求每条记录带 `change[]`，把改判本身留在册里。

上一册这一域有 `B-17` / `B-18`（对 FreeGSNKE 的壁与竖直不稳）、`B-19` / `B-20`（对 KEFIT 的
efund）、`V-23`（ITER 被动回路）、`C-03`（TokSys rzrig）。已退役。
