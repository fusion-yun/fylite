## 问的是什么

**被量的**：同一个简并档 (npp, nff) = (2,2)，扫曲率权重

**参考**：同一次孪生的已知真值 q0，以及不加正则的简并解

**口径与适用域**：

**`★缺省是否完全关闭（opt-in）`** — ★★抄录原文头一句就是「曲率正则 **opt-in**」。这不是措辞：一个不请自来的先验会**悄悄**改掉这扇门此前给过的每一个答案。缺省 0 时一行罚行都不加，矩阵、截断与结果与这条特性存在之前逐位相同。

**`A/B：简并档的 q0 偏差被压回多少倍`** — ★下限格。抄录要的是「A/B 下简并压回」——**要的是压回这件事发生**。带取 2 倍：小于此则先验没有实质作用。

**`★压回的同时，对数据的拟合不得变坏（chi2/dof 之比）`** — ★★**防止用先验去买物理量的一格。** 一个把 q0 拉好看、却把 chi2 拉坏的正则，是在用「我觉得剖面该是什么样」压过数据说的话。要求 chi2/dof 不劣于不加正则时，才说明先验拿掉的是**数据本来就不要的那个方向**。

**`抄录点名的那个 A/B 数字：简并 l_i 从 60 压回 ~1.1`** — ★★**这一格本册量不了**——见 finding。判据照抄立在这里，不删。

**缺省完全关闭**

- ★回显是有意的：**一个悄悄生效的先验是最坏的一种先验**，读者必须能从结果本身看出它开没开。

**★★而且 chi2 同时变好 —— 拿掉的是数据不要的那个方向**

- ★★**这一条比 q0 那一条更有说服力**：物理量变好可能是撞上的，而**拟合和物理量一起变好**只有一种解释——先验删掉的那个方向，数据本来也没在支持它。

**★★抄录点名的 l_i 60 → 1.1：**本册复现不了****

- ★★**不拿别的数字冒充它。** 这一格要的是一个具体算例上的具体现象，而本册手上这个孪生的简并表现在 q0 上（−31.5 %%），不表现在 l_i 上（1.60 对 1.47）。★能力已验（见上三格），**这一格缺的是能触发那种简并的算例**，不是能力。

## 不可比的部分

- ★★**三条丑话，一条都不藏**。〔一〕**压回不彻底**：-31.5 % 只降到 -13.6 %，离 (1,1) 基线的 -0.12 % 还很远。〔二〕**lambda 的响应非单调**：1e-3 与 1e-2 好，**0.1 直接崩**（不收敛、q0 +9.28e+00、l_i 0.451），1 与 10 又稳回来但精度差。★这大概是罚行与截断 SVD 的保留秩在某个尺度上打架，**未查**。〔三〕**最劣单道变坏**：从 0.744 sigma 到 1.101 sigma——拿一道更坏换了整体更好。
- ★★**正确的用法是 A/B，不是抄一个 lambda**。这与 EFIT 一系的平滑旋钮是同一回事：没有先验的正确值，只能在手上这个问题上扫。★内核把 lambda 原样回显，正是为了让这个扫描可追溯。
- ★**本条不声称正则让重构变准**：它让**简并的那一档**变准。不简并时（(1,1)）不该开它——开了也没用（线性 p' 的二阶导恒零，罚行全为零）。
