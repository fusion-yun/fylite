**`通道集是否**描述子驱动**（按名加/删通道零求解器改动）`** — ★判据原文：「通道集自动生成**且被求解器消费**」。要验它只需问一句：**加一道通道要不要改求解器？**

**`安培 / 回路电压驱动是否成立`** — ★判据的第三句。

**`★B0 压缩项：缺省 0 是否**逐位不变的死路径**`** — ★★判据原文点名「`b0_dot_over_b0` 缺省 0 **逐位不变**」——**这句话本身就是一条判据**：一个新装的项若在关掉时也改答案，它就悄悄改写了这扇门此前给过的每一个结果。

**★通道集**不是**描述子驱动的**

- ★这不是「没做好」，是**另一种架构**：四个手写求解器各自把自己那道方程的物理写死在里面。★**要满足这条判据得重写这一层**，不是补一个表。

**★★2026-09-17 补齐：ETS 的五种边界类型**

- ★★**照抄 ETS 的设计，而不是发明一个枚举**：五种物理边界都翻译成同一个 `(V, U, W)`，于是**装配那一行的代码只有一份**——「新加一种边界」不需要碰求解器。★这正是本条第一格（通道描述子）要的那种性质，只不过用在了边界上。
- ★★**缺省路径逐位不变**：`EdgeBc::value(y)` 落成 `(0, 1, 0, y)`，实现对 `V = 0` 短路，连 `V/h` 这个除法都不做。★660 项既有内核测试（含硬编码到 1e-13 的参考值）一项没动——**这不是巧合，是选那个离散化的理由之一**。
- ★三处照抄时必须看清的地方：〔一〕梯度型 `W = -g`（规范黑体强调：`g` 取正对应向边缘**下降**的正常剖面，写成 `+g` 会得到一个向外爬升的剖面而它看着像生效了）；〔二〕标长型取 `(V,U) = (L,1)` 而非规范翻译表的 `(1,1/L)`——同一条件，但 `L -> 0` 时仍良态，**规范文本与源码在这一处的差别是条件数不是物理**；〔三〕通量型隐式耦合，边界行**每轮重装**。
- ★★**一处实测逼出来的拒绝**：稳态（`dt = inf`）配纯梯度边界（`U = 0`）是**奇异**的——守恒算子每行和为零，纯梯度边界再来一行和为零，常数向量落进零空间。此前那种请求**返回一个 1e14 的答案**，而 1e14 与 1e2 在下游看来都只是「一个数」。现按名拒绝（`SteadyNeedsAnchoredEdge`）。★梯度型本身没问题——它用在**含时**步进上就是良态的，ETS 的方程本就是含时的；被拒的是「稳态 + 不锚定值」这个组合。

**★电流驱动两条路都有**

- ★这一格是本条里成立的那一半，写清楚免得「判 fail」被读成「什么都没有」。

**★★B0 压缩项：关掉时**逐位**不动**

- ★两头都要验：只验「关掉是零」会放过一个**开了也什么都不做**的实现，那种实现同样「逐位不变」，却等于这一项没装。
