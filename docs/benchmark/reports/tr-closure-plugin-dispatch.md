**`五个名字给出几种**互不相同**的行为`** — ★★下限格。**一个不看名字的分派器给不出针对名字的行为**——「行为」既包括解出不同的答案，也包括**因不同的理由被拒绝**。

**`无效名是否被**按名**拒绝并列出有效集`** — ★防的是「悄悄退回默认闭包」——那种实现会让一个拼错的名字产出一个**看着正常**的答案，而没有人会发现。

**`统一前端：各闭包的产出契约是否同一套`** — ★抄录的「统一前端共享」：换闭包只该换**扩散系数**，不该换前端——网格、边界、装配与产出的那组名字都该是同一套。

**`沉积积分闭合`** — ★抄录第三句。★**本条不重测它**，见 finding：同一条抄录判据行已由 `tr-closure-15d-source-switches` 量过，**一个量再量一遍就是两个数一个名字**。

**★★五个名字，五种行为 —— 拒绝是最好的证据**

- ★★**「只有两个跑通」不是这条的弱点，是它的强项。** 五个名字给出**五种不同的行为**：两种解法不同的解，三种**内容各不相同**的拒绝（要 b0 与密度 / 要 chi_given / 要扩展门的答案）。一个忽略名字的分派器产出不了针对名字的缺料清单。
- ★另三个之所以跑不起来，是因为它们各自要的输入本条没喂——**那是算例的事，不是分派的事**。★要把它们也跑通需要各自配一组输入，本条没做。

**无效名按名拒绝，并把有效集列出来**

- ★错误串里**把五个有效名都列了出来**——于是拼错名字的人当场知道该写什么，而不是拿到一个看着正常的默认解。

**产出契约只有一套**

- ★★**这一格的证据面窄，照实说**：只有两个闭包跑通，所以「统一前端」是在**两个**闭包上验的，不是五个。★要把它验满，得给另三个各配一组输入。

**沉积积分闭合 —— **不在这里重测****

- ★★**故意不重测。** 抄录里 `FR-TR-003` 与 `FR-TR-004` 共用同一行判据；同一个量在两条记录里各量一遍，迟早会得到两个数——而**两个数一个名字**正是本册一直在防的事。★这一格标 unevaluated 不是「没验」，是「验在别处、指过去」。

## 不可比的部分

- ★**本条不判哪个闭包算得对**，只判「名字被当回事、前端是同一套」。各闭包的物理准不准是别的记录的事（如 `tr-paradigm-pereverzev`）。
- ★★本条**没有门**：四格里三格是当场跑出来的读数，没有一道 pytest 会在分派坏掉时变红。见 open_defect。
