# 浏览器演示

`app/` 下的交互页面由同一份 Rust 内核编译成 WebAssembly：打开即用，计算全部在
浏览器内完成，不依赖任何服务端（**唯一的例外是装置数据页**，它前面站着一个只读窄端点的
本地网关——理由见[下文](#app-mds-gateway)）。演示按**一台机器被过一遍的顺序**组织——**设计 → 建模 → 反演**，另有一页不算物理的
装置数据。**五页**：三个场景页与**两个**工具页，都在 `/pages/` 下，首页在站点根。

★链接给的是**已发布站点的绝对地址**，不是文档站内的相对路径：演示是**产品**，
不是这本书的一章，文档站不再随身携带一份 `app/` 的副本（2026-09-01 裁定）。

★**这张表本轮改过一次，改的是事实不是措辞**：合并前它列的是 `design` / `pulse` /
`sim` 三个入口（外加 `model` / `analysis`），共五个场景页。三条入口已按
`FYL-DESIGN-09` 分期 P5 收成一页 `pulse_design`，那三份文件不复存在——**旧表上
那三行是三条死链**。

★**站点是十个文件、三种形态**（`app/tests/validate-site.mjs` 按 `data-page` 分这三支判）：
三个**散文页**各有中英两份，三个**场景页**运行时切换语言，两个**工具页**（`data` 装置数据、`report` 算例报告）——
一份文件、语言就地切换，但它**不算东西**：没有部件、没有 worker、没有计算键，
挂在 `site.js` 的 `TOOLS` 表而不是 `SCENARIOS` 上。

★**三个散文页各有中英两份，场景页只有一份。** 散文页由
`tools/make-app-pages.mjs` 从词条生成（模板在 `tools/app-pages/`），**文本在 markup
里**、不加载 i18n 运行时——单页 JS 从 156–190 KB 降到约 5.6 KB（`theme.js` 一个文件），
关掉 JavaScript 也能读，抓取器看到的就是正文。语言**在文件名里**，于是英文站有了可以
发出去的链接、`<html lang>` 与 `<meta description>` 对每位读者都是对的、页脚二维码
指向的也是确定的那一份。改了词条或模板之后要重跑该脚本并提交产物；
`node tools/make-app-pages.mjs --check` 是它的闸子。

★**入口不自动跳转**：站点根 `/app/index.html` 恒为中文，英文读者点页脚的国旗过去。
每个散文页在加载时把自己的语言写进 `localStorage`，所以从中文首页点进场景页拿到的
是中文界面，反之亦然。场景页仍是**运行时切换**（原地重绘），它页脚里通往散文页的
链接会跟着当前语言选文件。

★**一页就是一个场景，也是一个界面**：一个计算内核、一条工具条、**一个计算键**。
★★**站点上的演示从九个收敛为少数几条功能栏**：击穿场零、场零可行域、局域线性稳定性三个演示，
以及整个**控制仿真场景**（它只有一条静态判据——刚性 n=0 垂直稳定性——闭环、时延与电源都
没建，页面自己就这么写着），都已从站点撤下。撤下的只是**页面**：内核入口一字未动，
`fylite.scenario.design.breakdown` / `.feasible`、`fylite.scenario.model.tglf`、
`fylite.scenario.control` 照跑；1.5D 输运栏把闭包切到「湍流」时，用的仍是同一份 TGLF 制品。

★**站点自报为 alpha**：入口页正文第一段之后有一行状态说明，每页页脚的版权行也带
「alpha 版 / alpha release」——功能与数值口径仍在变动，结果格式可能在没有迁移路径的情况下
改变。★阶段只进文字：**徽标（`assets/fy_mark.svg`，同时是 favicon）保持 `Fy`**，16 px 下
写不下第二行字。

## 功能栏

一个场景由若干**功能栏**组成，一条栏就是这一页的一项功能。栏上有一条**标题条**，
从左到右依次是折叠钮、标题、它在等谁、它上一次做了什么，以及**这条栏自己的计算键**：

```
（建模页）
▾ 1.5D 芯部输运          已解：41 点，12 ms          ▶
▸ 自洽平衡—输运          未运行                      ▶
```

三条规矩，缺一条这套东西就不成立：

- **折叠**：点折叠钮把整条栏收成一条标题条，**记在浏览器里**，下次打开还是这样；
  栏里每个面板也各自能折。看四条栏全开的页面，和看你专程来看的那一条，不是同一件事。
  ★折叠只关**显示**：折起来的栏照样能按它的计算键。（早先每条栏还有一个开关，用来
  决定页面那一个计算键跑不跑它；计算键搬进每条栏之后，那个开关就不再回答任何问题，
  已经移除。）
- **共享数据**：栏与栏之间走一条**产物总线**（`S.publish()` / `S.take()`）：上游栏发布它的
  产物，下游栏在**整页运行时**取用。★只在整页运行时取：按计算键的意思是「把这个场景跑
  一遍」，那时上游的答案就是下游的输入；而拖某一条栏自己的控件，意思是「按我看得见的值
  重算这一栏」——那时去取上游的数，等于动了你手上的滑块。
  ★**总线是页面内的**。0D 栏 2026-08-22 移到设计场景之后，「0D 工况 → 1.5D 输运」变成
  **跨页面**的事：在设计页导出「工况」文件，在建模页导入。跨页面怎么传得更好（以及怎么
  把**完整平衡**而不只是七个标量传过去），评估记在内核仓的实测笔记里
  （`equilibrium-handoff`），不在本仓。
- **依赖排序**：一条栏声明它 `needs` 谁，**运行顺序是这些声明的拓扑序**，不是段落写下来的
  顺序。上游被关掉时，下游栏的标题条上写「待 ⟨上游⟩」，而不是拿着过期的控件值硬算。

**同一个量只有一个控件**：被多条栏读的量放在功能栏**之外**的「共用参数」面板里——
放电设计页是平顶 I<sub>p</sub>（三条栏共读），建模页是 χ₀、加热功率、沉积宽度与
n<sub>e</sub>(0)（1.5D 栏与自洽外环共读）。栏一关或一折会把自己的面板带走，共用控件若住在
里面就会连着另一条栏的输入一起消失。

自洽平衡—输运默认**关着**：它每轮解一次自由边界平衡，是**秒级**的离线档。

导入不问格式、按文件内容判定；导出按一下弹菜单，条目按栏分开列出。

## 场景之间怎么交接结果

一条链常常跨页：**0D 工况**在设计场景算出来，**1.5D 输运**在建模场景用；**反演**出来的
平衡也要拿去建模。两条路，装的是**同一份文档**：

- **文件**：在产出的那一页导出（工况 JSON 或平衡 g 文件），到建模页按「导入」。可归档、
  可给别人、可跨机器——这条永远在。
- **同源直传**：产出页的工具条上按「**交给建模场景**」，建模页的工具条随即出现
  「⟨设计⟩场景 ⟨3 分钟⟩前交来一份 ⟨平衡 g 文件⟩ — **取用** / 不用」。省掉存盘与找文件，
  但只在**同一个浏览器**里有效（用的是浏览器自己的存储；无痕窗口或文件太大时页面会
  如实告诉你改走文件）。★**从不自动应用**——它只是把东西放在那儿，按「取用」才生效。

建模页的 1.5D 栏能直接读 **g 文件**（EQDSK）：形状取自它**解出的边界**、q95 取自它自己的
q 剖面、B 取 `bcentr`；★**n<sub>e</sub>(0) 与边界温度不在 g 文件里，因此不会被设定**——
边界值定的正是这一栏结果的标度，留给你。★几何仍是那条边界的 **Miller 拟合**；把**逐面
度规**整个传过去是下一步，评估记在内核仓的实测笔记里（`equilibrium-handoff`），
不在本仓。

:::{note}
上述绝对路径在 `myst build --html` 产出的站点上直接可用。本地 `myst start`
预览时，静态文件挂在**内容服务端口**（`--server-port`，通常为应用端口 +100）：
访问 `http://localhost:<server-port>/app/index.html`。`app/` 内容修改后需重启
`myst start` 才会重新拷贝。
:::

## 装置数据页：这一页需要一个请求面

除装置数据页（`data`）外，站点上的一切都在浏览器内算完、不依赖服务端。**这一页是例外**，
而且例外的理由是协议性的：mdsip 是裸 TCP，页面没有套接字，wasm 也不改变这一点
（`FYL-DESIGN-06` §1）。所以它前面站着一个**只读窄端点**的本地进程：

```bash
fylite-app --mdsip 127.0.0.1:8000
```

★**启动参数是同一个文件定义的**（`FYL-DESIGN-15`）：页面从 URL 接受 `device`（钉住装置）、
`lang`（`zh` / `en`）、`theme`（`light` / `dark` / `system`），`page` 决定打开哪一页；
它们在 `python/fylite/_cli.json` 的 `hosts.app.params` 里各说一次，`fylite-app --page data
--device east --lang en` 把它们写进打开的地址，页面读的名字受门核对。`fylite-app --help`
列出全部选项——用法由同一个文件生成，与 `fylite app --help` 同源。

★**只此一份**（2026-09-01 起）。从前仓里还有一台 Node 网关（`app/server/gateway.mjs`），
与它「两个宿主、一组端点」互为判据；那台网关已退役，理由与替代的判据见 `FYL-DESIGN-13`。

- **端点是窄的**，没有一个收表达式的口子——MDSplus 自带的两个 bridge 是
  `/eval?expr=<任意 TDI>` 直通，那是协议参考而不是部署；
- **只绑回环，且没有旗标可改**：它坐在一个**不做认证**的协议前面。要给别人用，前面放一个
  **会认证**的反向代理，或者把隧道给他；
- **守卫在宿主这边也判一遍**——只跑在调用方机器上的守卫不算守卫；
- 页面上那格 mdsip 地址改的是**宿主连哪台装置服务器**，随便填：能敲那个框的就是启动这个
  进程的人，他本可以直接打 `--mdsip`。

取数是**两遍**：第一遍每路最多 256 点把整炮铺开，第二遍按图的像素宽度补点；在任一张图上
横拖选一段，两遍就在那个时间窗里重跑（步长塌下去而点数几乎不变）。★`\PCRL01` 是 Rogowski
读数，**不等于等离子体电流**（本仓 #137985 平顶实测与重构的 `cpasma` 差 1.9 %）——先看它是
对的，拿它做等式约束是错的。

闸子**既不需要浏览器也不需要 mdsip 服务器**：编解码与参数面守卫在 `cargo test` 里
（`rust/fylite_data/src/mdsip.rs` 17 项、`rust/fylite_data/src/bin/app/api.rs` 6 项），
端到端那一层由
`app/tests/validate-app-mdsip.mjs` 对着**真机录下来的帧**跑发布出去的那个宿主——宿主问了
夹具里没有的问题，门会红。夹具怎么录见 `tools/mds-record.mjs`。★那份录音是装置内网的
实验数据，**不随本分发发布**：拿得到的人用 `FYLITE_MDS_FIXTURE` 指过去，拿不到的这道门
自报跳过。

## 装置数据

### 预设装置

页面**预设**的装置是 fyo/JSON-LD 文档，放在 `app/devices/` 下（今天两份：`east.jsonld`
与 `iter.jsonld`），由 `app/devices/catalogue.jsonld` 列出。它们是**入库的产物**：当初从
A-Box 的装置描述生成，★而那个生成器**不在本仓**——所以预设今天按入库文件维护，出处逐条
写在目录文件的 `prov:wasDerivedFrom` 里。

★★**预设不是内部件的逐字节副本**（2026-09-02 两次裁定叠加）：仓内 `machine_desc/` 已废弃，
没有可对拍的在仓源；而且发布件是**再加工件**——`c58c2c6` 把已发布内容里的内网地址与开发机
路径抹掉了，内部件没抹。所以「预设 == 内部描述」这条判据的前提已经不成立，
`python/tests/test_machine_desc.py` 里那一条随之改写（见该文件的说明）。

| 预设 | 线圈 | 磁通环 | 出处（目录文件 `prov:wasDerivedFrom` 逐条列出） |
| :--- | ---: | ---: | :--- |
| EAST | 14 | 35 | ASIPP efund `&IN3` 卷宗 + EFIT_POINT_GUI_v5；**带参考放电 #137985 @ 4.0 s**（实测 PF 通道 A·匝与 35 道磁通环读数） |
| ITER | 12 | 110 | ITER EDA 公开设计文件 33NHXN v3.15 / 2ACJT3 v3.1；R0/B0 取 TEQ 参考平衡表头。不带参考放电 |

★★**`app/` 是要发布的，所以预设即再分发**，而这正是 **CFETR 与 BEST 已经撤下**的理由
（2026-09-01）：两台的 PF 线圈表出处都是**个人通信**，不是本仓可以再分发的东西。它们的
条目移到目录文件的 `fylite:not_presets` 里，说明为什么撤、撤的是什么。**站点上那两份
在下一次发布前仍在**——撤下它们是那次发布的一部分。

哪台机器做预设是**裁定**而非规则：EAST 带实炮那一条是 2026-08-22 的明确裁定，目录文件把
每台的出处逐条写在数据里，闸子只保证**出处已声明**，不替这件事下判断。

`cfedr` / `jt60sa` / `west` **不是**预设，理由与许可无关：分别缺壁、缺线圈、缺装置级
B0，`FyoDevice.fromFyo` 读不成一台可解的机器。它们的 fyo 描述在 A-Box 里，拖得出来但装不进页面。

★预设曾经是 `app/assets/dev-iter.js`——一个把描述符推进全局变量的 JS 文件。那让这个
build 唯一自带的机器成了 app 里**唯一不是文档**的机器：无法与它来自的描述对拍、
无法被重新导入、走的读取路径也与其他机器不同。现在它与导入的文件走**同一个**
`FyoDevice.fromFyo`。

★预设是**取来的**（fetch），所以页面 `boot()` 会等它——页面本来就要 fetch `.wasm`，
即本来就得由服务器伺服而非 `file://` 打开，因此没有新增约束。目录读不到时页面照常
可用，只是没有预设，每台机器都靠导入进来。★**预设优先**：同 id 的导入装置不会遮蔽
预设（`importFyo` 早就拒绝占用预设的 id，现在这条规则改在 `all()` 合并处生效，
因为 localStorage 是能被绕过去写的）。

其余装置是**输入**：页面读的是 fyo/JSON-LD 装置文档，从 A-Box 拖出来
（`tools/abox-to-machine-desc.py`，见[安装与环境](install.md)），按 `+` 导入，
导入后 `?device=<装置>` 即可选中。装置数据本身不随 `app/` 发布。

**装置选择栏**（每页工具条左端）＝一份清单 + 两个动作：

| | |
| :--- | :--- |
| 下拉 | 预设在前、导入的在后并带 `*`；换装置会**重新加载页面**（每一张响应矩阵、每一个控件量程都属于某台机器，半换的页面还在显示上一台的数字） |
| `+` | 导入装置描述，**可一次选多份 JSON**：全部存下，只切到第一台（一次一份就是一份一次重载，四台里只有最后一台留得下）。有读不进的文件会**逐个报出**文件名与原因，不会被悄悄丢掉 |
| `×` | 忘掉当前这台导入的装置；预设装置不可删（它随构建分发，删了就没有回退的机器），此时按钮为禁用态 |

导入的装置存在**本浏览器的 localStorage** 里，刷新后仍在；隐私模式下浏览器可能拒绝
存储，届时状态行会说明「刷新后这台装置会消失」。

## 页脚：版权行与本页二维码

每页页脚有一行**版权与许可**，以及**这一页自己的二维码**（扫码即在手机上打开同一页）。
二维码是 `tools/make-app-qr.py` 一次性生成并提交的 SVG，指向**已发布的地址**
（`https://fusion-yun.github.io/fylite/…`）——前端不引第三方 JavaScript，也就不在页面里
现编码；站点若换地址，重跑脚本并提交新文件。

## 物理功能与边界页

`/app/features.html`（与英文版 `/app/features.en.html`）讲：现在能算什么物理、**明确算不了
什么**（含「拒绝作答」的那几类）、每一项**凭什么被认为是对的**（验证依据四层），以及接下来
补什么。同一批口径在本书里由[保真度边界](../reference/fidelity.md)与
[物理校验](../reference/benchmark.md)两章承载——页面是摘要，两章是口径，数字必须一致。

## 版权与致谢页

站点还有 `/app/credits.html`（与它的英文版 `/app/credits.en.html`），**版权、许可、逐项出处、致谢与参考文献都在这一页**
（每个页面的页脚都通到它）。它是 `LICENSE`、`NOTICE`（随内核源码留在 `fylite_kernel`，打轮时装入分发件）与本书
[致谢](../ACKNOWLEDGEMENTS.md)的可读摘要——有法律效力的逐文件声明仍以前两份为准，
页面上说的每一句都必须能在它们里面找到。
