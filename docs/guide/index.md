# fylite 用户指南

fylite 是一个**自足的托卡马克平衡—输运—湍流内核**：一套 Grad-Shafranov 正逆解、
一步 1.5 维芯部输运、新经典与回旋朗道流体闭包，以及一条平衡重构链，写成**一个
可重入的 Rust 内核**；Python 层做装配与编排，浏览器端跑的是同一个内核编译出的
WebAssembly。

本书讲**怎么用**与**结果怎么读**。两种用法互不依赖：

:::{list-table}
:header-rows: 1

* - 用法
  - 要装什么
  - 适合
* - [浏览器](browser.md)
  - 什么都不用装
  - 上手、教学、快速试算、把一次运行分享给别人
* - [Python 包](python.md)
  - `pip install fylite`（alpha 期仅 Linux x86-64）
  - 脚本化、批量、把结果接进自己的分析流程
:::

两条路径调用的是**同一个内核**：同一份 `c_api` 导出面，原生库与 WebAssembly
模块出自同一次编译配置。所以浏览器里得到的数与脚本里得到的数是同一个数——
这一点由自动门在每次改动时校验，不靠承诺。

## 状态

**alpha。** 能力与数值口径仍在移动：入口、结果格式可能变化且不保证迁移路径。
缺口是**列出来**的，不是用返回零的函数填上的；超出模型适用范围的请求返回错误，
而不是一个看起来像答案的数。
