# 约束与权重

## 约束阶梯

反演按**阶梯**逐级加入信息，每一级都可单独关掉——差异即该级的贡献，
而不是一个黑箱。

| 级 | 约束 | 开关 |
| :--- | :--- | :--- |
| **L1** | 磁探针 + 磁通环 + $I_p$ | `fwtmp2` / `fwtsi` / `fwtcur` |
| **L2** | POINT 极化-干涉（内部电流约束，11 弦） | `point=True` |
| **L3** | Thomson/TXCS 压强 + $n_e$ 剖面（逐点实测 σ） | `pressure=True`, `thomson_ne=True` |
| **L3+** | MSE 内部电流行（`&INS` 组） | `mse=` |

:::{warning}
MSE 行必须写进 EFIT 自带的 **`&INS`** 命名组；写进 `&IN1` 会**静默无效**——
与 `&INWANT` 同坑。`kfile.mse_namelist()` 已处理此事。
:::

## 探针门控是数据卫生，不是调参

探针只在测得幅值合理时入拟合（`0.02 T < |B| < 1.0 T`）。这不是"调"出好结果，
而是剔除死道与非特斯拉离群值：#70754 上 76 道里 39 道死、3 道离群，
把它们按权重 1.0 塞进去会**压垮拟合电流并弄坏边界追踪器**。

## 逐道标定缺口（K-4）

**全权重拟合的质量仍然不好**，即便门控之后。残差经三轮复核已排除标定、
朝向与锚点，定位为「模型少一个近处场源」，尚未解决。因此：

:::{important}
**磁通环-only（`FWTMP2=0`）是当前的质量基准。** 随包的 #137985 交付件即以此
口径产出——它与全权重反演的含义不同，引用时请一并说明。
:::

## 曲率正则是精确可表达的

`CALPA`/`CGAMA` 是**对剖面多项式系数的通用线性约束行**，而
$p''=\sum_n c_n (n{-}1)(n{-}2)x^{n-3}$ 也是同一组系数的线性泛函——
故曲率惩罚**精确可表达，非近似**。`kfile.curvature_rows()` 生成它，
测试对每个基函数用数值二阶差分逐一核对。

## 快离子压强是"加"不是"放宽"

`kfile.pressure_namelist(p_fast=…)` 把快离子压强按 $\psi$ 插值后**加到总压强行**。
刻意不采用"放宽 σ"的做法：后者是把「更大」说成「更不确定」，
是本仓两度铲除的失败型。
