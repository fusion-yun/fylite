(fylite-data-abstract)=
# 摘要 (Abstract)

本文件描述**装置数据页**（`data`）：把一台 MDSplus 服务器当成**可以走进去的目录**
的一页只读浏览器。它是 `FYL-CONOPS-00` S-L2 的**取数面**，本身不自成一条场景线。

**这一页什么也不算。** 没有内核、没有 worker、没有功能栏——四页里唯一的**工具页**
（P-1）。它的全部产物是**你看过了什么**：一炮的零级量、一棵树、几条抽稀过的时序，
以及每一个数旁边那句「它是从哪来的」。

四条裁定各管一件这一页独有的事：

- **P-10** 缺进程时**如实降级**——没有网关就印出启动它的那条命令，不画空图。
- **P-11** 画的是**抽稀**不是归约；**工作区存设定，不存样点**。
- **P-12** 守卫在**网关与客户端两侧各做一遍**；两个宿主、一组端点、**没有取表达式
  的端点**。
- **P-18** 目录说某路信号在这台机器上**存在**，**从不**说这一炮**记了**它。

:::{note} 本篇在四页里的位置
四页各有一份设计文档：`pulse_design` → `FYL-DESIGN-09`；`model` →
`FYL-DESIGN-10`；`analysis` → `FYL-DESIGN-12`；`data` → **本篇**。

★**四页共同的十四条纪律**（P-1..P-8 · P-13 · P-14 · P-15 · P-25 · P-26 · P-27）写在 `FYL-DESIGN-10`
{ref}`fylite-pages-common`，本篇**引用它们，不抄一遍**。`P-` 编号在四页之间是
**一条全局序列**，对照表见 `FYL-DESIGN-10` {numref}`tbl-fylite-pages-numbering`。
:::

(fylite-data-conventions)=
# 约定与术语 (Conventions and Terminology)

实质断言携认识论状态标签（〔已确立〕/〔工作假设〕/〔开放猜想〕），不使用 RFC 2119
规范关键字；缺失值记 `[TBD]`，不虚构。

**工具页（tool page）**
:   没有 `FyScenario.part(...)`、没有功能栏、没有 worker 的一页，因为它什么也不算
    （P-1）。`data` 是本仓唯一的一页。

**抽稀 / 归约（decimation / reduction）**
:   抽稀是**每隔 N 个取一个样点**；归约是把一炮的信息压成更少的数并留下配方。
    这一页只做前者，且**逐图写明**（P-11）。

**本机网关（local gateway）**
:   浏览器打不开裸 TCP，wasm 也不改变这件事，所以这一页前面站着一个只读窄端点的
    本机进程：桌面单文件宿主 `rust/fylite/src/bin/app/api.rs`
    （`fylite-app --mdsip HOST:PORT`）。
    ★2026-09-01 起**只此一份**：仓里那台 Node 网关（`app/server/`）已退役，理由与
    去处见下表下方一段。

(fylite-data-composition)=
# 页面的构造 (How the Page Is Put Together)

〔已确立〕两栏栅格，自己声明——**不借用场景页的运行链**。理由写在它自己的样式
注释里：**这一页没有栏，因为什么也不算——没有东西可折、也没有东西可等**（P-1）。

〔已确立〕它仍与另外三页共用骨架的那几样：一条**状态行**、一个**装置牌**、一条
**版本片**、同一套 `style.css` / `site.css`。共用的是**外观与出处纪律**，不是运行
模型——这正是 P-1 说的「形态上的不一致是如实的」。

〔已确立〕站点分类上它挂在 `site.js` 的 `TOOLS` 表而不是 `SCENARIOS`：
`validate-site.mjs` 按 `data-page` 分三支判（三个散文页 × 两语言、三个场景页、
一个工具页，共十个文件）。

(fylite-data-decisions)=
# 设计裁定 (Design Decisions)

(fylite-data-p10)=
## P-10 缺进程时如实降级 (degrade by naming the missing process)

〔已确立〕没有网关时，这一页**不画空图、不弹错误横幅**，而是**印出启动它的那条
命令**（Node 网关 / 单文件宿主 / SSH 隧道三选一）。理由写在控制器头上：
「一个用空图来失败的工具，教给读者的是这台装置没有数据」。

〔已确立〕单文件宿主在**没给 `--mdsip`** 时，`/api/health` **照答**，只是
`ok:false` 并带一句为什么——面板据此画成禁用并说明原因，「这比 404（面板凭空消失）
教给读者的多」。

〔已确立〕★这一条有一段**实测的前史**，记在这里因为它正是这条裁定要防的形状：
内嵌是按目录收的，所以 `pages/data.html` 一开始就编在桌面可执行体里——**而它在
里面是死的**，因为请求面（当时只有 Node 网关）不在发布子集里。实测表现是
`/api/health` 返回 404、面板自我禁用。补上原生请求面之后，这一页在桌面宿主里
才真的活了（`FYL-REPORT-05` §3b.5）。

(fylite-data-p11)=
## P-11 抽稀不是归约，工作区不是数据仓库 (this page is not a data repository)

〔已确立〕图上画的是**每隔 N 个取一个样点**，不是均值、不是 min/max 包络——**比
步长更窄的尖峰不在这条曲线里**，每张图注都写着「抽稀」二字与它的步长。

〔已确立〕采样率跟着**窗**走而不是跟着整炮走：在图上拖出一个窗，两趟取样在窗内
重跑，点数几乎不变而**步长塌下来**；叠加的炮同窗重取，两炮共用一个步长；双击回到
整炮。

〔已确立〕工作区存的是**设定**，不存样点——「存了样点的工作区就是一份没有出处的
数据副本」。要把一炮的**归约**连同配方与清单存下来，那是
`tools/mds-shot-to-fyo.py` 的事，不是这一页的。

〔理由〕这一条同时是**治理**上的：数据本身能不能外传不是这一页能回答的问题，而一个
会把样点写进工作区文件的页面，等于替所有者做了那个决定。

(fylite-data-p12)=
## P-12 守卫两侧各做一遍，两个宿主同一组端点 (guard on both sides, one API)

〔已确立〕六个端点——`/api/health` `/api/shot` `/api/tree` `/api/node`
`/api/signal` `/api/measurements`——Node 网关与单文件宿主**形状逐字段相同**，
因为页面是同一份。

〔已确立〕**没有取表达式的端点，因为没有取表达式的客户端方法**——每个 TDI 串都由
校验过的节点路径与整数拼出。MDSplus 自带的两座桥都被拒绝，理由是它们等价于
`/eval?expr=<任意 TDI>`：其中一座连上去就是一张通用远程求值的面孔，
`getenv("HOME")` 是答得出来的。

〔已确立〕树名、节点路径与整数在**网关里检一遍、客户端里再检一遍**；页面给的
`server=` 被采纳，用户名**从不**取自页面——「mdsip 不做认证，调用方自选的用户名是一个
没有任何东西在核的身份声明」。

〔2026-09-01 改判〕**两个宿主都只绑回环，且都不可配置**。网关此前有 `--host` /
`--allow CIDR`（发布到站点网段 + 按来访地址 403），现已移除：一串 CIDR 不是认证，
它决定的只是谁能借用别人的隧道，而这不是一台工作站上的工具该回答的问题。于是
`server=` 的「只在回环绑定时采纳」不再有第二种情形——它永远被采纳。要服务多人，
前面放会认证的反向代理。

〔已确立〕**判据是与另一个宿主逐字段对拍**，不是「两边都跑通了」：`measurements`
15 个键、`tree` 44 个节点的名/类/用途/长度、`signal` 15 个键、`node` 8 个键，
**全部相同**（离线的那一份写成了门 `app/tests/validate-app-mdsip.mjs`，两个宿主
指向同一台假 mdsip 服务器）。

:::{warning}
★★**这一测把内核 mdsip 客户端里三处缺陷抓了出来**——它此前只有单元测试，
**从未连过一台真服务器**：① 登录应答是 `dtype = 0` + 零字节，而解码器先查宽度表，
于是**每次会话的第一条消息**就失败，握手根本完不成（旧单元测试还用「空载荷 + 未知
dtype」当例子，把错的规则钉住了）；② 缺 dtype 5（u64），而 `TIME_INSERTED` 正是
它，于是每个节点都报「从未写入」——**那看起来像个答案**；③ 定宽文本表的**填充是
分隔符**，在解码处 trim 掉就再也切不开名字。三条都已修并各留判据。

这段记在设计文档里而不是只记在提交里，是因为它是 P-12 的**证据**：两个宿主逐字段
对拍不是形式主义，它是唯一能发现「解码器一直在自洽地答错」的办法。
:::

(fylite-data-p18)=
## P-18 装置的事实与页面的事实分开 (a catalogue says exists, never recorded)

〔已确立〕诊断目录说某路信号在这台机器上**存在**，**从不**说这一炮**记了**它：
#137985 存了它 79 个磁探针里的 21 个。节点的「字节数」是那条记录有多大：为零的
一定取不到，不为零的**也未必取得到**（存的可能是一条引到别处的表达式，本炮那一处
没数）。

〔已确立〕空节点在列表里**变灰而不是隐藏**——一个把另外 58 道藏起来的浏览器，等于
在回答「这台装置有 21 个探针」，那是假的，而且**从页面上证伪不了**（P-6 的一处
成文拒绝）。

〔已确立〕**节点路径不说明它住在哪棵树上**，而那个映射推不出来（`east` 树对
`\PCRL01` 答 `%TREE-W-NNF`），所以九个关键零级量**各自带着自己的树**。

(fylite-data-p13-here)=
## P-13 在这一页的落法 (provenance, made concrete)

〔已确立〕四页共同的 P-13（每个数带着它的出处，正本在 `FYL-DESIGN-10`
{ref}`fylite-pages-p13`）在这一页做到了**每一格**。状态行「不是六个数，是**每个数
各自从哪来**」：

- `I_p` 来自 `\PCRL01`（Rogowski 读数）——本仓在 #137985 平顶实测它与重构的
  `cpasma` **差 1.9 %**。**先看它是对的，拿它做等式约束是错的**。
- **放电时长**由本页自己的规矩推出（|I_p| ≥ 峰值的某个百分数），并写明**这是本页
  的规矩，不是站点的定义**。
- **日期**取 `TIME_INSERTED`，即**那条记录被写下的时刻**，不是等离子体产生的时刻。
- `I_t` 与日期两格**曾经空着**——本仓当时不知道它们在哪个节点，**宁可留白也不拿
  近似量顶替**。
- 真空环向场 `B_t` 仍单列一格：**它不是 `I_t`**。

(fylite-data-p24)=
## P-24 ★什么也不算的一页，产物是「你看过了什么」 (a page that computes nothing still owes a record)

〔工作假设·本轮新立〕这一页没有判定块（它没有解可判），但它**仍然有产物**：一次
浏览会话看过了哪棵树、哪一炮、哪几路信号、各以什么步长取的。工作区存的就是这个
——**设定与足迹，不是样点**（P-11）。

〔理由〕P-1 说工具页不该套一个永远「已就绪」的运行按钮；但那不等于它可以什么都
不交代。一次取数是**别人机器上的一次读**，而这一页的每张图都带着一个隐含的判断
（抽了哪几点）。把这两样记下来，是让「我当时看的是什么」可复现——这与另外三页的
运行清单是同一条纪律的工具页版本，只是记录的对象从「一次求解」换成「一次查看」。

〔工作假设〕**推论——工作区不得因此变成数据副本。** 足迹是**指针**（树 · 炮号 ·
节点路径 · 窗 · 步长），不是值。这条边界正是 P-11 的那一条，写在这里以免 P-24 被
读成它的例外。

(fylite-data-p30)=
## P-30 ★抽稀必须画得出来 (decimation has to be visible in the picture)

〔工作假设〕P-11 说**抽稀不是归约**：画出来的是每隔 N 个取一个样点，不是均值、
不是 min/max 包络，比步长更窄的尖峰**不在这条曲线里**。P-30 是它的视觉落法，
一句话：**曲线上要看得出这是取样的结果**。

〔工作假设〕三条，都可断言：

1. **采样点画出来。** 一条不画点的平滑折线读起来像连续记录；画上点，读者一眼看见
   点与点之间没有信息。点密到画不下时（> 1 px 间距以下）改为**不画点并在图注写明
   「点已密到画不出」**——不是默默不画。
2. **图注写两个数**：`256 / 12480 点`。一个数说不出抽稀率；两个数说得出。**全取时
   两个数相等**（`121 / 121 点`），而不是省略图注——省略之后读者无从区分「全取」
   与「忘了写」。
3. **步长跟着窗口走，且这件事写出来。** 在图上横拖选一段就是**回服务器重取一遍**，
   不是本地放大；两次取回的步长因此不同。选区上写「重取一遍」，取回后图注里的
   两个数随之改变。

〔理由〕这一页是四页里**唯一什么也不算的一页**（P-1），它交付的全部东西就是
「你看到的这条曲线代表什么」。**把取样这件事画掉，这一页就没有产物了**——剩下的
是一条来历不明的曲线，而读者会拿它去写结论。

〔工作假设〕**推论——缺席的三种形状各不相同，不得共用一个灰。** 「没有网关」
（进程缺席，P-10）· 「该炮无此节点」（数据缺席）· 「服务器拒绝了」（请求被拒，
P-12）——三者的处置完全不同：起一个进程、换一个节点、看服务器说了什么。
所以三者各写各的话，并且**服务器那一条原样转述服务器的措辞**，不翻译成自己的话。

(fylite-data-visual)=
## 这一页在外壳上的三个槽与首屏 (this page's slots, and its first screen)

〔工作假设〕外壳三槽（`FYL-DESIGN-10` {ref}`fylite-pages-p25`）在本页取值：

- **④ 输入槽装的是 mdsip 数据源**，不是装置下拉。★这是 P-25 在四页里最实质的一次
  应用：「选一个数据来源」与「选一台装置」**是同一个槽**，差别只在这一页的来源是
  一台服务器。今天这一页**根本没有工具条**，同一件事长在左栏的一个面板里
  （`FYL-DESIGN-11` 的 F-2）。
- **⑤ 运行态**：网关连没连上、这一次取回取了几路。这一页不算东西，所以它的运行态
  说的是**取数**，不是计算——`网关未连 —— 这一页需要一个能开套接字的进程`。
- **⑥ 出口：空，且不留空格。** 这一页没有「交给某某场景」——它交出去的是
  P-24 的那份足迹，走的是导出，不是场景交接。**一个永远空着的槽会被读成缺数据**，
  所以它整个不出现。

〔已确立·实测〕首屏判据（P-26）**本页不满足，而且形状与另外两页不同**：整整
1500 px 内没有一处输出——不是「输出在下面」，是**没有取回任何东西之前本来就没有
输出**。

〔工作假设〕**本页的落法因此也不同**：不是把图挪上来，而是**在没有数据时也给出
一个有形状的空态**——画出坐标轴、写明它将要画什么、以及此刻缺的是哪一步
（「没有网关」／「还没选信号」／「选了 3 路，按取回」）。这正是 P-10 的
「命名那个缺失的进程，而不是画一张空图」用在首屏上：**空态图不是空图**——
它有轴、有标题、有一句话说明下一步。

(fylite-data-g8)=
**G-8 时间预算没有量过.** 取数耗时由网络与服务器支配，本仓没有可复现的基准，
因此表里是 `[TBD]` 而不是一个好看的数字。判据：给出一个**可复现**的口径（例如对
本仓自带的假 mdsip 服务器计时），或明确声明这一档不适用 NR-ENV-005 并说明理由。

**G-15 工作区不记足迹（P-24 新立）.** 今天工作区存的是设定；P-24 要的「看过了
什么」（树 · 炮号 · 节点 · 窗 · 步长）尚未成为可导出的一份记录。判据：导出物含
足迹且**不含样点**，两条同时可断言。

**G-16 桌面宿主未在 Windows 上实机验证.** 交叉编译出的是正确格式的 PE32+，但本
环境无 Windows 也无 wine（`FYL-REPORT-05` §3b.4）。判据：在 Windows 上双击运行、
页面加载、`/api/health` 与六端点答出与 Linux **逐字段相同**的答案。

**G-17 取样不可见（P-30）.** 今天曲线是折线，不画采样点，图注只写抽稀后的点数。
判据：采样点画出（点距小于 1 px 时改为在图注写明「点已密到画不出」）；图注写两个
数，全取时两个数相等且**不省略**；横拖选段后两个数随之改变。

**G-18 三种缺席共用一个灰（P-30 推论）.** 「没有网关」「该炮无此节点」「服务器
拒绝了」今天在页面上是同一种灰面板。判据：三者各写各的话，服务器那一条**原样转述
服务器的措辞**；闸子按三种情形各断言一条不同的文案，并断言三条互不相同。

**~~G-19~~ 首屏没有空态图（P-26）.** **已闭合（2026-09-01）**，在
`pages/page_data.html` 上：无数据时给出**有形状的空态**——坐标轴、标题、以及缺的
是哪一步（没有网关／还没选信号／选好了按取回），实测首处输出 **335 px**。
