(fylite-data-abstract)=
# 摘要 (Abstract)

本文件描述**装置数据页**（`data`）：把一台 MDSplus 服务器当成**可以走进去的目录**
的一页只读浏览器。它是 `FYL-CONOPS-00` S-L2 的**取数面**，本身不自成一条场景线。

**这一页什么也不算。** 没有内核、没有 worker、没有功能栏——它是一页**工具页**
（P-1）。它的全部产物是**你看过了什么**：一炮的零级量、一棵树、几条抽稀过的时序，
以及每一个数旁边那句「它是从哪来的」。

四条裁定各管一件这一页独有的事：

- **P-10** 缺进程时**如实降级**——没有请求面就印出启动它的那条命令，不画空图。
- **P-11** 画的是**抽稀**不是归约；**工作区存设定，不存样点**。
- **P-12** 守卫在**请求面与客户端两侧各做一遍**；一组只读端点，**没有取表达式
  的端点**。
- **P-18** 目录说某路信号在这台机器上**存在**，**从不**说这一炮**记了**它。

另有两条本页自己立的：**P-24** 什么也不算的一页仍欠一份记录（足迹是指针不是值）；
**P-30** 抽稀必须画得出来。

:::{note} 本篇在四页里的位置
四页各有一份设计文档：`pulse_design` → `FYL-DESIGN-09`；`model` →
`FYL-DESIGN-10`；`analysis` → `FYL-DESIGN-12`；`data` → **本篇**。

★**四页共同的十四条纪律**（P-1..P-8 · P-13 · P-14 · P-15 · P-25 · P-26 · P-27）写在 `FYL-DESIGN-10`
{ref}`fylite-pages-common`，本篇**引用它们，不抄一遍**。`P-` 编号在四页之间是
**一条全局序列**，对照表见 `FYL-DESIGN-10` {numref}`tbl-fylite-pages-numbering`。
裁定与缺口**编号不重排、条搬家不改号**：P-10 / P-11 / P-12 / P-18 与 G-8 是随本页
自 `FYL-DESIGN-10` 迁来的。
:::

(fylite-data-conventions)=
# 约定与术语 (Conventions and Terminology)

实质断言携认识论状态标签（〔已确立〕/〔工作假设〕/〔开放猜想〕），不使用 RFC 2119
规范关键字；缺失值记 `[TBD]`，不虚构。「多宿主」「两个运行时」「跨运行时一致」
按 `FYL-DESIGN-16` H-3 的改口使用；本页不算数，故跨运行时一致（NR-ENV-004）对它
无对象。

**工具页（tool page）**
:   没有 `FyScenario.part(...)`、没有功能栏、没有 worker 的一页，因为它什么也不算
    （P-1）。站点的 `TOOLS` 表今天有两页：`data`（本篇）与 `report`（2026-09-02 加入，
    读一份记录、不算），后者不在本篇范围。

**抽稀 / 归约（decimation / reduction）**
:   抽稀是**每隔 N 个取一个样点**；归约是把一炮的信息压成更少的数并留下配方。
    这一页只做前者，且**逐图写明**（P-11）。

**本机网关 / 请求面（local gateway / request face）**
:   浏览器打不开裸 TCP，wasm 也不改变这件事（`FYL-DESIGN-06` §1），所以这一页前面
    站着一个只读窄端点的本机进程。**只此一份**：桌面单文件宿主的请求面
    `rust/fylite_runtime/src/bin/app/api.rs`（`fylite --mdsip HOST:PORT`），
    它调用中间层的 mdsip 客户端 `rust/fylite_runtime/src/mdsip.rs`。
    ★沿革一句：仓里曾另有一台 Node 网关（`app/server/`），2026-09-01 退役
    （{numref}`tbl-fylite-data-hosts`）。本篇下文「网关」指的都是这份请求面。

(fylite-data-composition)=
# 页面的构造 (How the Page Is Put Together)

〔已确立〕两栏栅格，自己声明——**不借用场景页的运行链**。理由写在它自己的样式
注释里：**这一页没有栏，因为什么也不算——没有东西可折、也没有东西可等**（P-1）。

〔已确立〕它仍与另外三页共用骨架的那几样：一条**状态行**、一个**装置牌**、一条
**版本片**、同一套 `style.css` / `site.css`。共用的是**外观与出处纪律**，不是运行
模型——这正是 P-1 说的「形态上的不一致是如实的」。

〔已确立〕站点分类上它挂在 `site.js` 的 `TOOLS` 表而不是 `SCENARIOS`：
`SCENARIOS` 上挂的一切都假定场景的形状（`render()` 找 `ln.<id>.lead` / `.bound`，
`validate-site.mjs` 要一个 `section.tool`、一个工具条宿主、一个注册部件的控制器），
什么也不算的一页满足不了其中任何一条，为过闸写一个空部件是造假。
★**工具页进页眉**（用户裁定 2026-09-01）：一个只能靠敲网址到达的页面，对没被
告知网址的读者等于不存在；页眉因此由 `SCENARIOS.concat(TOOLS)` 生成，`TOOLS` 表
说的是「哪一类页」，页眉说的是「出现在哪」。`validate-site.mjs` 按 `data-page`
分支判站点形状，实测 2026-09-04：16 个文件——三个散文页 × 两语言、三个场景页、
两个工具页，加五张 v2 外壳页。

〔已确立〕页面载入的脚本只有站点公共件（`i18n` / `lang-*` / `theme` / `host` /
`version` / `site`）加三份自己的：`plot.js`、`mdsplus.js`（控制器）、`mds-catalog.js`
（诊断目录面板）。**没有 `fylite.js`、没有 `worker.js`、没有 wasm**。

(fylite-data-decisions)=
# 设计裁定 (Design Decisions)

(fylite-data-p10)=
## P-10 缺进程时如实降级 (degrade by naming the missing process)

〔已确立〕没有请求面时，这一页**不画空图、不弹错误横幅**，而是**印出启动它的那条
命令**（`fylite --mdsip HOST:PORT`；服务器在所内网段够不着时先搭 SSH 隧道，再让
`--mdsip` 指向隧道口）。理由写在控制器头上：「一个用空图来失败的工具，教给读者的是
这台装置没有数据」。

〔已确立〕单文件宿主在**没给 `--mdsip`** 时，`/api/health` **照答**而不是 404：
答 `ok:true`、`locked:false`、`mdsip:null`，并带一句 `reason`（「启动时没给
`--mdsip`——在服务器格里填 HOST:PORT，或重起它并加上 `--mdsip`」）。「没配」不是
「不能用」，是「还没填」：服务器格是可写的（P-12），面板据此把这一格标出来而不是
消失——「这比 404（面板凭空消失）教给读者的多」（`api.rs` 的判据
`health_answers_when_no_mdsip_is_attached`）。

〔已确立〕★这一条有一段**实测的前史**，记在这里因为它正是这条裁定要防的形状：
内嵌是按目录收的，所以 `pages/data.html` 一开始就编在桌面可执行体里——**而它在
里面是死的**，因为请求面（当时只有 Node 网关）不在发布子集里。实测表现是
`/api/health` 返回 404、面板自我禁用。补上原生请求面之后，这一页在桌面宿主里
才真的活了（内核仓 `FYL-REPORT-05` §3b.5）。

(fylite-data-p11)=
## P-11 抽稀不是归约，工作区不是数据仓库 (this page is not a data repository)

〔已确立〕图上画的是**每隔 N 个取一个样点**，不是均值、不是 min/max 包络——**比
步长更窄的尖峰不在这条曲线里**，每张图注都写着「抽稀」二字与它的步长。

〔已确立〕采样率跟着**窗**走而不是跟着整炮走：在图上拖出一个窗，两趟取样在窗内
重跑，点数几乎不变而**步长塌下来**；叠加的炮同窗重取，两炮共用一个步长；双击回到
整炮。

〔已确立〕工作区存的是**设定**，不存样点——「存了样点的工作区就是一份没有出处的
数据副本」。要把一炮的**归约**连同配方与清单存下来，那是内核仓
`tools/mds-shot-to-fyo.py` 的事，不是这一页的；按绑定表把一炮取成一份 fyo 文档的
批式路径在中间层 `fylite data fetch`（`FYL-DESIGN-14` L-10）。

〔理由〕这一条同时是**治理**上的：数据本身能不能外传不是这一页能回答的问题，而一个
会把样点写进工作区文件的页面，等于替所有者做了那个决定。

(fylite-data-p12)=
## P-12 守卫两侧各做一遍，一组只读端点 (guard on both sides, one API)

〔已确立〕六个端点——`/api/health` `/api/shot` `/api/tree` `/api/node`
`/api/signal` `/api/measurements`——全部只读，宿主只答 `GET` / `HEAD`。每个端点
答多少个键是**钉住的**（`measurements` 15、`signal` 15、`node` 8；`tree` 44 个节点
的名 / 类 / 用途 / 长度）：少答一个字段在页面上表现为某一格空着，闸子把它提前到
本机的一次失败。

〔已确立〕**没有取表达式的端点，因为没有取表达式的客户端方法**——每个 TDI 串都由
校验过的节点路径与整数拼出（`mdsip::is_tree_name` / `is_node_path`）。MDSplus 自带
的两座桥都被拒绝，理由是它们等价于 `/eval?expr=<任意 TDI>`：其中一座连上去就是
一张通用远程求值的面孔，`getenv("HOME")` 是答得出来的。

〔已确立〕树名、节点路径与整数在**请求面里检一遍、客户端里再检一遍**（`api.rs`
一遍，`fylite_runtime::mdsip::tcp::connect` 再一遍，两遍查同一条规则）；会计算的
东西在开套接字之前就被拒。页面给的 `server=` 被采纳，用户名**从不**取自页面——
「mdsip 不做认证，调用方自选的用户名是一个没有任何东西在核的身份声明」。

〔已确立〕**请求面只绑回环，且不可配置**（裁定 2026-09-01）。唯一的调用者就是启动
这个进程的人——他本可以直接打 `--mdsip`，所以 `server=` **永远被采纳**，健康答复里
`locked:false`（键留着，页面靠它决定要不要把服务器格置灰）。★沿革一句：此前网关
有过 `--host` / `--allow CIDR`（发布到站点网段 + 按来访地址 403），已移除——一串
CIDR 不是认证，它决定的只是谁能借用别人的隧道，而这不是一台工作站上的工具该回答
的问题。要服务多人，前面放会认证的反向代理。

〔已确立〕**判据是逐字段对拍，不是「跑通了」**。今天的对照有两层：
① `validate-app-mdsip.mjs`——发布出去的那个宿主，对着**真机录下来的帧**
（`fixtures/mdsip-east.json`，`tools/mds-record.mjs` 架在客户端与站点之间录得），
宿主答的每一句都能在帧里命中，每个端点的键数钉住；② `validate-jmds.mjs`——
一份**独立实现**（`tools/jmds` 纯 Java 客户端，在内核仓）与宿主逐字段比、两条数组
**逐位**比（要真服务器）。★沿革一句：退役前的判据是 Node 网关与单文件宿主互拍
（`measurements` 15 键、`tree` 44 节点、`signal` 15 键、`node` 8 键**全部相同**）；
它的弱点是两边共用一台按其中一方读法写的假服务器，表达式拼错了假服务器照收——
录下来的帧没有这个毛病。

:::{warning}
★★**P-12 的证据：逐字段对拍抓出了 mdsip 客户端的三处解码缺陷。** 那份客户端
（今天在中间层 `rust/fylite_runtime/src/mdsip.rs`）此前只有单元测试，**从未连过一台
真服务器**，而三条缺陷各自都在自洽地答错：

1. 登录应答是 `dtype = 0` + 零字节，而解码器先查宽度表，于是**每次会话的第一条
   消息**就失败，握手根本完不成（旧单元测试还用「空载荷 + 未知 dtype」当例子，把错的
   规则钉住了）。
2. 缺 dtype 5（u64），而 `TIME_INSERTED` 正是它，于是每个节点都报「从未写入」——
   **那看起来像个答案**。
3. 定宽文本表的**填充是分隔符**，在解码处 trim 掉就再也切不开名字。

三条都已修并各留判据（`mdsip.rs` 的 `cargo test`，{numref}`tbl-fylite-data-gates`）。
「两边都跑通了」发现不了其中任何一条。
:::

(fylite-data-p18)=
## P-18 装置的事实与页面的事实分开 (a catalogue says exists, never recorded)

〔已确立〕诊断目录说某路信号在这台机器上**存在**，**从不**说这一炮**记了**它：
#137985 存了它 79 个磁探针里的 21 个。节点的「字节数」是那条记录有多大：为零的
一定取不到，不为零的**也未必取得到**（存的可能是一条引到别处的表达式，本炮那一处
没数）。

〔已确立〕空节点在列表里**变灰而不是隐藏**——一个把另外 58 道藏起来的浏览器，等于
在回答「这台装置有 21 个探针」，那是假的，而且**从页面上证伪不了**（P-6 的一处
成文拒绝）。

〔已确立〕**节点路径不说明它住在哪棵树上**，而那个映射推不出来（`east` 树对
`\PCRL01` 答 `%TREE-W-NNF`——不是空数据，是**不在**），所以九个关键零级量**各自
带着自己的树**。「按诊断选」面板读的正是那张写下来的映射
（`app/facts/device/east-signals.json`：73 个诊断、376 路信号，自 EAST Wiki 收得）；它是
运行方的内部文档，**不进公开发布**，随其数据走——公开副本里那次 `fetch` 404，
面板照实说「没有目录」，持有者把文件放回原位面板即回来。

(fylite-data-p13-here)=
## P-13 在这一页的落法 (provenance, made concrete)

〔已确立〕四页共同的 P-13（每个数带着它的出处，正本在 `FYL-DESIGN-10`
{ref}`fylite-pages-p13`）在这一页做到了**每一格**。状态行「不是六个数，是**每个数
各自从哪来**」：

- `I_p` 来自 `\PCRL01`（Rogowski 读数）——本仓在 #137985 平顶实测它与重构的
  `cpasma` **差 1.9 %**。**先看它是对的，拿它做等式约束是错的**。
- **放电时长**由本页自己的规矩推出（|I_p| ≥ 峰值的某个百分数），并写明**这是本页
  的规矩，不是站点的定义**。
- **日期**取 `TIME_INSERTED`，即**那条记录被写下的时刻**，不是等离子体产生的时刻。
- `I_t` 与日期两格**曾经空着**——本仓当时不知道它们在哪个节点，**宁可留白也不拿
  近似量顶替**；今天 `I_t` 认到 `\TOP.T2:TFP`，栏里点名它查实的节点。
- 真空环向场 `B_t` 仍单列一格：**它不是 `I_t`**。
- 单位缺失就写「树里没写」，不猜一个；直接路径等宽、可复制。

(fylite-data-p24)=
## P-24 ★什么也不算的一页，产物是「你看过了什么」 (a page that computes nothing still owes a record)

〔工作假设〕这一页没有判定块（它没有解可判），但它**仍然有产物**：一次浏览会话
看过了哪棵树、哪一炮、哪几路信号、各以什么步长取的。工作区存的就是这个——
**设定与足迹，不是样点**（P-11）。

〔理由〕P-1 说工具页不该套一个永远「已就绪」的运行按钮；但那不等于它可以什么都
不交代。一次取数是**别人机器上的一次读**，而这一页的每张图都带着一个隐含的判断
（抽了哪几点）。把这两样记下来，是让「我当时看的是什么」可复现——这与另外三页的
运行清单是同一条纪律的工具页版本，只是记录的对象从「一次求解」换成「一次查看」。

〔工作假设〕**推论——工作区不得因此变成数据副本。** 足迹是**指针**（树 · 炮号 ·
节点路径 · 窗 · 步长），不是值。这条边界正是 P-11 的那一条，写在这里以免 P-24 被
读成它的例外。

(fylite-data-p30)=
## P-30 ★抽稀必须画得出来 (decimation has to be visible in the picture)

〔工作假设〕P-11 说**抽稀不是归约**：画出来的是每隔 N 个取一个样点，不是均值、
不是 min/max 包络，比步长更窄的尖峰**不在这条曲线里**。P-30 是它的视觉落法，
一句话：**曲线上要看得出这是取样的结果**。

〔工作假设〕三条，都可断言：

1. **采样点画出来。** 一条不画点的平滑折线读起来像连续记录；画上点，读者一眼看见
   点与点之间没有信息。点密到画不下时（> 1 px 间距以下）改为**不画点并在图注写明
   「点已密到画不出」**——不是默默不画。
2. **图注写两个数**：`256 / 12480 点`。一个数说不出抽稀率；两个数说得出。**全取时
   两个数相等**（`121 / 121 点`），而不是省略图注——省略之后读者无从区分「全取」
   与「忘了写」。
3. **步长跟着窗口走，且这件事写出来。** 在图上横拖选一段就是**回服务器重取一遍**，
   不是本地放大；两次取回的步长因此不同。选区上写「重取一遍」，取回后图注里的
   两个数随之改变。

〔理由〕这一页什么也不算（P-1），它交付的全部东西就是「你看到的这条曲线代表
什么」。**把取样这件事画掉，这一页就没有产物了**——剩下的是一条来历不明的曲线，
而读者会拿它去写结论。

〔工作假设〕**推论——缺席的三种形状各不相同，不得共用一个灰。** 「没有网关」
（进程缺席，P-10）· 「该炮无此节点」（数据缺席）· 「服务器拒绝了」（请求被拒，
P-12）——三者的处置完全不同：起一个进程、换一个节点、看服务器说了什么。
所以三者各写各的话，并且**服务器那一条原样转述服务器的措辞**，不翻译成自己的话。
判定类信息不得以颜色为唯一编码（NR-QUAL-004，正本 `FYL-DESIGN-11`）在本页的对象
就是这三种缺席。

:::{note} Rationale
装置数据页不自成一条场景线，它是 S-L2 的取数面。本文件不改变对那条场景线的现状
判定；它记录的是**一页什么也不算的工具页为什么仍然需要这么多纪律**——因为它做的
每一件事都是在**别人的机器上读**，而读错、读漏、或把读到的一部分说成全部，都不会
让任何东西变红。P-18 那句「目录说存在，从不说这一炮记了」是全篇的缩影：这一页最
容易犯的错不是算错，是**答了一个比它知道的更肯定的答案**。
:::
