(fylite-model-abstract)=
# 摘要 (Abstract)

本文件描述**物理建模页**（`model`）：`FYL-CONOPS-00` 场景 **S-L1（物理建模）** 在
浏览器前端的形态。这一页回答的是**「给定这套度规与这条边界，剖面 / χ 长什么样」**
——一个不带时间的问句。

三条功能栏，**全部不含时**：

- **给 χ 求 T.** 1.5-D 定态输运解（今天的输运栏）。
- **给电流与位形求 ψ 与度规.** 固定边界 / 自由边界平衡、边界条件、逐面度规
  ——**它自己是一条栏**，不是别人的一个下拉菜单（P-20）。
- **给 T 反求 χ.** 把同一条能量平衡反过来解（今天的反演栏）。它同样不含时。

**一条居中的裁定：一个应用只有一条时间轴，它不在这一页。** 原先的含时演化栏收敛进
放电设计页，在那里成为仿真推进的 1.5-D 保真度档（P-19 · `FYL-DESIGN-09` D-22）。
今天它还在这一页上（{ref}`fylite-model-g11`）——**搬迁未落**，而这正是本篇最大的
一处缺口。

**这份文件不提出新能力**：这一页今天已落地并有门禁守着。写下来是因为它的纪律已经
足够多，而**它与另外三页之间的一致性此前无人记录**。

(fylite-model-conventions)=
# 约定与术语 (Conventions and Terminology)

实质断言携认识论状态标签（〔已确立〕已落地有证据 /〔工作假设〕方向已定待落地 /
〔开放猜想〕俟需求定型），不使用 RFC 2119 规范关键字——本文件是设计描述，规范条款
经 {ref}`fylite-model-deltas` 提案、落地时进 `FYL-SRS-01` / `FYL-SDD-01`。缺失值记
`[TBD]`，不虚构：没量过的时间预算一律写 `[TBD]`，不填一个好看的数字。

裁定编号取 **`P-`**（page），与 `FYL-DESIGN-09` 的 `D-` 分开——两份文件的编号若
同名，代码与门禁里「按编号引用某条裁定」的注释就会悄悄指错页。

**场景页 / 工具页（scenario page / tool page）**
:   场景页有一个 `FyScenario.part(...)`、若干条功能栏、一个 worker 与一条运行链
    （`model`、`analysis`、`pulse_design`）。工具页没有这些，因为它什么也不算
    （`data`）。二者的差别是**这一页算不算东西**，不是风格偏好（P-1）。

**功能栏（function bar）**
:   一页里一件可以独立跑起来的事：自己的控件、自己的结果面板、自己的判定块。
    **注册顺序就是运行顺序，也是依赖顺序**（P-2）。

**判定块（verdict block）**
:   一次运行结束时页面写下的那一段话：解出来没有、按什么判据、以及**它自己知道
    自己不知道什么**。它是一等产物，不是装饰（P-5）。

**拒绝（refusal）**
:   页面**不给答案**并说明为什么：半径盖不住这套度规、判据判定「返回的不是等离子
    体」、节点取不到。拒绝优于一条编出来的曲线（P-6）。

**出处（provenance）**
:   每一个数旁边那一句「它是从哪来的」：哪一档解的、哪一份文档来的、抽了哪几样
    （P-13）。

(fylite-pages-common)=
# 四页共同的纪律 (Discipline Shared by All Four Pages)

〔已确立〕这一节的十四条裁定**属于四页**，不属于建模页。写在这里只因为它们最早在
这里成文；`FYL-DESIGN-09` / `-12` / `-13` **引用本节，不抄一遍**——同一条纪律抄四
份，第一次改动就会剩三份是旧的，那正是 P-14 说的那种脱节。

(fylite-pages-p1)=
## P-1 一页算不算东西，决定它长什么样 (a tool page is not an impoverished scenario page)

〔已确立〕`data` 页没有功能栏、没有折叠机制、也不借用场景页的运行链，而是自己声明
两栏栅格。理由写在它自己的样式注释里：**这一页没有栏，因为什么也不算——没有东西
可折、也没有东西可等**。

〔理由〕把工具页硬套成场景页，会得到一个永远「已就绪」的运行按钮和一条永远没有
判定块的状态行——那是在教读者「这一页算过了什么」，而它没有。形态上的不一致是
**如实的**，比一致但撒谎的外壳好。

(fylite-pages-p2)=
## P-2 注册顺序即运行顺序，即依赖顺序 (registration order is the dependency order)

〔已确立〕场景页的功能栏按依赖顺序注册：`model` 是 输运 → 含时演化 → 反演（迁后
为 输运 → 边界 → 反演，P-19 · P-20）；`analysis` 是 剖面拟合 → 平衡反演 → 时间
序列 → 批处理；`pulse_design` 的六条栏按三个模式分组注册。一条栏读的是上一条栏的
产物，页面的「从头跑一遍」因此有唯一确定的次序。

(fylite-pages-p3)=
## P-3 共用控件住在栏外 (a shared control cannot live inside a fold)

〔已确立〕`model` 页的「这台机器」面板（`a`、`R/a`、`κ`、`δ`、边界 q、`B₀`、
`n_e(0)`、`χ₀`）在所有栏之外。理由是机械的：**栏一折就把自己的面板收起来**，共用
控件若住在里面，折起一条栏会连另一条栏的输入一起看不见。

〔已确立〕当一条栏离开 Miller 几何时，六个形状滑块**变灰而不是消失**——一个不再
起作用的控件仍要看得见，否则读者会以为自己填的那个形状还在起作用。

〔关联〕这与放电设计页的 D-20「一个量一个控件」是同一条纪律的两半：D-20 说不要有
第二个控件，P-3 说那**唯一**的控件不能被折叠带走。★`pulse_design` 落地时正是这么
做的：共用控件住在功能栏之外的 `page-shared` 面板上，各栏经框架的 id 回退链
（栏 → 部件 → 页面）读同一份。

(fylite-pages-p4)=
## P-4 栏间相接：两种机制，各自的代价写明 (two ways to hand work along)

〔已确立〕`model` 页靠**页内文档**（导入的参考剖面 CSV、g 文件、解出来的度规与
边界；`MODEL_REF` / `MODEL_GFILE`）：一页一份，两条栏共读。`analysis` 页靠**页面
总线**（`publish` / `take`）。

〔已确立〕两种机制的代价都是实测出来的：总线**不唤醒**读它的那条栏
（`FYL-DESIGN-12` G-2，实测「重新拟合剖面后等着，那句提示逐字不变地留在原处，
永远」）；页内文档则要求读者自己记得「这一份是从哪来的」，所以反演栏在面板上写明
当前载入的是哪一份。

(fylite-pages-p5)=
## P-5 判定块是一等产物 (a verdict is a deliverable, not a decoration)

〔已确立〕每条栏在结束时写下一段判定，且**逐字区分**下列几件事：

- 1.5-D 输运：「**未收敛**（残差 …）——宁可如实报出来，也不给一条看着光滑、其实
  没解出来的曲线」；湍流档另有「到外迭代上限即止（N 轮）——剖面停在这里，不是收敛
  到这里」。
- 通量匹配档：「没有收敛……**这里不退回常数 χ**——剖面停在最后一次牛顿迭代的落点，
  不是稳态，别拿它当结果读」。
- 含时推进（今天在本页、按 P-19 迁往放电页）：「推进在 t = … 自己停了」 /
  「跑满了 N 步而**不是**停在稳态——这是「时间到了」，不是「稳了」」 / 「★★这次
  推进用的是**没有收敛的**自由边界平衡：N 次求解里 M 次没达容差」。
- 平衡反演（`FYL-DESIGN-12`）：「这次拟合：χ²/自由度 = …，约束来自 …；按 k·RMS
  判有 n 道离群」，并按是否跑过后验加上「后验 σ(q95) = …」或「★未跑后验——这一行
  里**没有**不确定度」。
- 反演栏：「有 n 个点低于梯度地板，那里**没有答案**（图上是断口）——不是零，也不是
  很大的数」。

〔理由〕这几句话是这几页最容易被砍掉的东西，也是最不能砍的：一个「求解器返回了」
被读成「解出来了」的代价，比一个数算错更大，因为它不留痕迹。

(fylite-pages-p6)=
## P-6 拒绝优于外推 (refuse rather than invent)

〔已确立〕四页各有成文的拒绝：

- 反演栏：导入剖面的半径范围盖不住这套度规时**拒绝**，而不是把边缘补齐——「在编
  出来的剖面上反演，反出来的是编出来的 χ」。
- 平衡反演：三条判据（P-7）任一成立即判「解出来的不是等离子体」，不出结果。
- 剖面拟合：「由卷宗剖面重采样」那一档在面板上标明它是**合成的**。
- 放电设计页：插值片的平衡截面带「插值（未解）」标注，不冒充解出来的那一片
  （`FYL-DESIGN-09` D-8）。
- `data` 页：节点取不到时如实报错，**不给一条空曲线**；空节点在列表里**变灰而不是
  隐藏**。

(fylite-pages-p7)=
## P-7 判据只有一处 (one place judges)

〔已确立〕「解出来的不是等离子体」由 worker 里的一处判据判定，三条：① `I_p` 等式
约束偏离 > 50 %——「求解器返回了，但返回的不是所问那个问题的答案」；② 拟合的 `a`
< 装置自身半宽的 0.1——「是一团贴着限制器的电流丝」；③ 线圈被拉动超过判据 σ——
「拟合是靠不再相信读者给的标定把残差压下去的」。实测：默认 σ 下九片卷宗的最大
线圈拉动为 **1.04–1.60 σ**。

〔已确立〕**批处理队列不另立判据**：它把同一处判据判出来的三态（已收敛 / 未解出 /
未运行）逐行抄下来，未解出的行写明是哪一条不成立。一张各行判据不同的汇总表，
比较的不是任何东西。

(fylite-pages-p8)=
## P-8 失败不得留着上一次的答案 (a failed run must not leave the last one standing)

〔已确立〕这一次没有解出来时，判定块写明「★**这一次没有解出来**：…。上面的图与表
还是上一次成功的那次运行，不是这一次问的」。

〔理由〕这是本仓实测过的失败：一次被拒的拟合若静默返回，页面上留着的仍是上一次的
截面与逐道表，而读者刚刚改过输入——他会把旧答案读成新答案，且**没有任何迹象**。

(fylite-pages-p13)=
## P-13 每个数带着它的出处 (every number carries where it came from)

〔已确立〕图注写明这条曲线来自哪一档、哪一份导入文档；反演的 χ「只和你给的源一样
可靠——这是所有 interpretive 分析的老实话」。`data` 页把这一条做到每一格

(fylite-pages-p14)=
## P-14 自述不得与能力脱节 (a page's own account of itself is part of the product)

〔工作假设〕一页写在自己面板上的「做不到什么」，和它的代码一样是产物，**必须随
能力一起改**。今天有一处成立的反例（{ref}`fylite-model-g1`）：含时演化栏的
`e.caveat` 仍把台基模型、湍流闭包、杂质输运与动量道列在「还没有的」里，而四样都已
在标记与控制器里接上。

〔工作假设〕这类脱节机器守得住：一条门禁按「面板上出现了这个控件 ⇒ 自述里不得
把它列为缺失」的形式断言即可（DE-LOG-09，见 {ref}`fylite-model-deltas`）。

〔已确立〕★这条纪律**不止管页面**。同一形状的脱节在本轮实测里出现过两次，都不在
页面上：一次在闸子（`validate-site.mjs` 报告自己检查了一页，实际匹配到零个面板，
`FYL-DESIGN-09` {ref}`fylite-pulse-design-asbuilt-app`），一次在样式表
（`style.css` 的抬头写「用到的三个字重是 400 / 500 / 700」，而 `600` 在两份样式表
里用了 8 处，`FYL-DESIGN-11` §视觉缺口）。**一份自述过期，是唯一一种读者无从察觉
的失败**。

(fylite-pages-p15)=
## P-15 主线程还是 worker，按规模定 (where a computation runs is a measured choice)

〔已确立〕`model` 页的 1.5-D 定态解**在页面线程上跑**：41 个点是微秒量级，一次
worker 往返比计算本身还贵。湍流档是唯一的例外，它有**自己的一个 worker**，并在
其中惰性载入 `fylite_tglf.wasm`。其余走页面的主 worker。

〔已确立〕这不是风格：拖一个控件即重算的交互档，代价的大头是往返而不是浮点。

(fylite-pages-p25)=
## P-25 ★页面写外壳以下：外壳报状态，页体放开关 (the page owns what is below the strip)

〔已确立〕四个功能页面**共用一条 header toolbar**，它由 `FYL-DESIGN-11` 裁定
（V-11 · V-12），不属于任何一页。四篇页文档因此各自只写**那条带子以下**的样子，
外加**带子上属于自己的三个槽**取什么值：④ 输入（装置 / 数据源）· ⑤ 运行态 ·
⑥ 出口。

〔工作假设〕**判据一句：外壳报告状态，改变状态的控件留在页体。** 这是
`FYL-DESIGN-11` V-11「工具条上是运行态不是计算键」的一般形式，也是任何一页想往
外壳上加东西时该问的那一句——**它是读还是写？** 读的可以上去（而且多半应该，
因为外壳常驻），写的留在页体。

〔理由〕外壳的价值全部来自**它由一处生成**。一旦某一页被允许往上面插自己的控件，
四页就只是「长得像」而不是「共用」，而下一次改动会漏掉其中一页——`FYL-DESIGN-11`
的 F-2 记的正是这种退化：同一段代码生成的装置下拉，一页用页内规则收窄到 260 px，
另一页摊到 1086 px。

〔已确立〕**第一个实例是放电设计页的模式开关**：当前模式在 ⑤ 槽里始终可见，
三枚切换键在页体顶上（`FYL-DESIGN-09` {ref}`fylite-pulse-design-d23`）。那一篇
v1.2 及以前写的是「模式开关在标题栏」，改口的理由记在条内。

(fylite-pages-p27)=
## P-27 ★每一种状态都带一个非颜色通道 (colour is never the only channel)

〔工作假设〕每一页画出的每一种**状态**——不是数据本身，而是「这个数可信到什么
程度」——除颜色之外**必须还有一个通道**：形状、线型、底纹、位置或文字。每一页
把自己的清单画成一张表，评审时逐行核对中间那一栏。

〔理由〕这一族页面画的东西里有很大一部分是**限定词**：已解还是插值、你给的还是
反求的、抽稀还是全取、约束住了还是没约束住、算过还是没算。这类信息一旦只靠颜色，
在灰度打印、在投影仪上、在色觉差异者眼里，**它说的就不是「不确定」，而是什么也
没说**——`FYL-DESIGN-11` V-8 第 3 条。

〔工作假设〕三条具体约束，四页通用：

1. **同一物理量的两种身份用线型分，不换颜色。** 颜色已经被占用了：`--coil` 紫说
   的是「这是线圈电流」，换掉它等于说这是另一种物理量（V-8 第 2 条）。
2. **「有问题」的几种状态不得共用一个橙色而不加字。** 越限、限值缺失、模型过期、
   服务器拒绝——处置完全不同，一个颜色说四件事等于一件也没说。
3. **缺席要写出来，不能留空。** 空白与「零」在图上长得一样（P-6 · P-10 的同一条）。

〔已确立〕四张词汇表：`FYL-DESIGN-09` {numref}`fig-fylite-pd-vocab` ·
本篇 {numref}`fig-fylite-model-vocab` · `FYL-DESIGN-12` · `FYL-DESIGN-13` 各一张。

# 建模页自己的裁定 (Decisions of This Page)

(fylite-model-p17)=
## P-17 单位与网格写在解的旁边 (the grid convention travels with the answer)

〔已确立〕本页的输运网格是**米**，不是 `r/a`。旧网格上 χ 以 m²/s 供给而半径以
`r/a` 计，方程里少了一个 `a²`——**χ 还是滑块时这个错误看不见**，换成物理闭包供给
χ 的那一天它就错了。因此网格约定与轴上约定写在解的旁边，且旧会话文件里的轴温与
今天不同这件事**写明是这个原因**。

〔理由〕这是一条关于**什么时候会被发现**的裁定，不是关于排版的：一个只在换了供给
方式之后才显形的量纲错误，靠肉眼复查是抓不住的；把约定写在解旁边，是让下一个人在
接线之前就读到它。

(fylite-model-p19)=
## P-19 ★建模页不含时：它解的是定态与边界 (the model page has no time axis)

〔已确立·用户裁定 2026-08-31〕**含时演化栏迁出建模页**，成为放电设计页仿真模式的
1.5-D 保真度档（`FYL-DESIGN-09` D-22）。建模页此后只留**时间无关**的问题，重心
落在三件上：

1. **1.5-D 定态输运**——给定这套度规与这个 χ，剖面长什么样（今天的输运栏）。
2. **边界与度规**——固定边界 / 自由边界平衡、边界条件、逐面度规（P-20）。
3. **功率平衡反演**——给定一条测出来的剖面，反求 χ（今天的反演栏）。

〔理由〕两条，都不是审美：

- **一个应用只该有一条时间轴**（D-22）。两条时间轴意味着两组作动器、两套源、两种
  判定块，并且迟早在同一个物理量上给出两个不同的数——本仓对「两套物理」的态度是
  一贯的（DE-COMP-04 不变式）。
- **重心问题.** 建模页三条栏里两条本来就是定态的；第三条却带着四十个控件、五组
  面板与逐步流式的结果，读者一进来看到的是**一次放电**而不是一次建模。搬走它，
  这一页的问句才回到它自己的那个。

〔工作假设〕**推论 1——G-1 不是被改对的，是跟着栏一起走的。** 那句过期的 `e.caveat`
随含时演化栏迁往放电页，并在那里按 D-22 重写（它此后描述的是 1.5-D 档，而不是一页）。
留在建模页要改的只有一处指路：输运栏的「那些在含时演化栏里」改成「那些在放电设计
页」——**这句话今天成立、迁后仍成立**，变的只是它指向哪里。

〔工作假设〕**推论 2——「几何是固定的」从缺陷说明变成分工。** 输运栏那句长期的限制
（压强改变不了它所在的磁面）在这一页有了正面的读法：**几何在这一页被解出来、被交出
去**。`FR-MODEL-001`（固定边界）与 `FR-MODEL-002`（自由边界）在浏览器一侧因此第一次
有了自己的面，而不是藏在一条含时栏的「每 K 步重解一次」里。

〔工作假设〕**推论 3——反演栏留下。** 它反的是与 1.5-D 档同一条能量平衡，但它**不
含时**：给一条测出来的剖面反 χ。若将来要「逐时片反演一整炮」，那是**放电页的时间
轴**上的事，不是在建模页上重新长出一条时间轴。

〔工作假设〕**推论 4——搬迁不能只发生一半。** 栏从建模页移出与它在放电页出现是
**同一次搬迁的两面**：只移出会丢掉能力，只出现会有两份含时演化。门禁按这一条断言
（`FYL-DESIGN-09` 分期 P6）。

(fylite-model-p20)=
## P-20 ★边界与度规是一条栏，不是一个下拉菜单 (the boundary earns a bar of its own)

〔工作假设·本轮新立〕平衡与逐面度规在这一页**自己是一条功能栏**，位置在输运栏与
反演栏之间（P-2 的依赖顺序：先有度规，才谈得上在它上面解剖面或反 χ）。

〔理由〕三条，逐条是今天就能指出来的：

1. **它是前后两条栏共同站着的东西。** 输运栏解的是「在这套度规上」的剖面，反演栏
   反的是「在这套度规上」的 χ。一个两条栏都依赖的东西藏在其中一条栏的一个下拉菜单
   里，读者无从知道另一条栏用的是不是同一份。
2. **它有自己的判据，而下拉菜单没有地方放判据。** 自由边界解收敛没有、边界与目标
   差多少、逐面度规在轴附近退化到哪里——这些都是 P-5 意义上的判定，需要一个判定块。
3. **它有自己的档。** 65×65 自由边界解实测 **≈1.2 s**，与输运栏的微秒量级不是同一
   档（P-15）；把它塞进一条即拖即得的栏里，那条栏就不再是即拖即得的。

〔工作假设〕这条栏**不新写求解器**：它调用的是 `FR-MODEL-001` / `FR-MODEL-002` 的
既有入口（浏览器侧既有的 `solve` 命令）。DE-COMP-04 不变式在这里与在别处一样——
场景层只组合既有能力。

〔已确立〕今天它**尚未成栏**（{ref}`fylite-model-g12`）：能力散在两处——含时演化栏
的「几何来源 + 每 K 步重解自由边界」，与输运栏的「几何是固定的」那句限制。★注意
这两处**都不是缺能力**，缺的是**一个面**：同一件事在一处被当作别人的参数、在另一处
被当作一句免责。

(fylite-model-p21)=
## P-21 ★交出去的是一份有名字的工件 (the hand-off is an artifact, not a bus)

〔工作假设·本轮新立〕建模页交给放电设计页 1.5-D 档的，是**度规 + 边界 + χ 闭包
标定**这一份**有名字的工件**——不是一条页内总线，也不是一次剪贴板往返。

〔理由〕P-19 把两页分到了时间轴的两侧，这条边因此从「同页两条栏之间的方便」变成
**跨页的主路**。一条主路要能被检查，而能被检查的前提是它有名字：

- 工件须自述它**站在哪一次平衡上**（P-13）——一条剖面脱离它所在的度规是没有意义的；
- 两宿主须对同一份工件给出同一个答案（显式容差，同 `FYL-DESIGN-09` D-10 的口径）；
- 它是**未提升**的会话文档（浏览器页面产不出有身份的工件，也不得伪造，同
  `app/assets/session.js` 既有的裁定）。

〔已确立〕这条边今天以文件形式**勉强**存在：0-D 栏迁去放电设计页之后，两页之间只
剩基于导出 / 导入文件的交接，评估见 `docs/note/equilibrium-handoff.md`
（{ref}`fylite-model-g3`）。P-19 之后它**换了方向也换了地位**——不再是「便利损失」，
而是一条必须有判据的主路。

〔工作假设〕这一页有一件另外三页都没有的事：**同一个符号在两条栏里是两种身份**。

- **解出来的量画实线 + 实心采样点**（T 在输运栏、χ 在反演栏）——点是「这里有一个
  解出来的值」；

## 这一页在外壳上的三个槽与首屏 (this page's slots, and its first screen)

〔工作假设〕外壳的三个槽（P-25）在本页取值：④ 装置 `EAST`；⑤ **哪一条栏在跑 ·
