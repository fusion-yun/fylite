(fylite-analysis-abstract)=
# 摘要 (Abstract)

本文件描述**实验分析页**（`analysis`）：`FYL-CONOPS-00` 场景 **S-L2（实验分析）**
在浏览器前端的形态。这一页回答的是**「这一炮当时长什么样」**——把「由测量恢复
位型」当作一个统一的**正向—推断**问题。

四条功能栏，按依赖顺序（P-2）：

- **剖面拟合**——移位勒让德基 + GCV 选阶，由测点给出压强 / 温度 / 密度剖面。
- **平衡反演**——磁通环与磁探针、干涉与法拉第、压强剖面**一起**进拟合；
  误差棒由后验采样给出，**并只说它抽了的那几样**（P-9）。
- **时间序列**——逐片完整重构，**时片之间不插值**。
- **批处理**——整队用开跑那一刻的设定，每行自报三态之一。

**这一页不含时。** 它解的是**某一个时刻**的问题；时间序列栏是「同一个问题在若干
时刻各解一遍」，不是一条时间轴——一个应用只有一条时间轴，它在放电设计页
（`FYL-DESIGN-09` D-22 · `FYL-DESIGN-10` P-19）。

**一条居中的判断.** 磁测量单独**约束不住**内部剖面：很不一样的剖面能给出几乎一样
好的磁场拟合。把解定下来的是**动理学约束**——这正是「动理学重构」的分别所在，也是
这一页何以不是一个磁反演小工具（P-22）。

:::{note} 本篇在四页里的位置
四页各有一份设计文档：`pulse_design` → `FYL-DESIGN-09`（唯一有时间轴的一页）；
`model` → `FYL-DESIGN-10`；`analysis` → **本篇**；`data` → `FYL-DESIGN-13`。

★**四页共同的十四条纪律**（P-1..P-8 · P-13 · P-14 · P-15 · P-25 · P-26 · P-27）写在 `FYL-DESIGN-10`
{ref}`fylite-pages-common`，本篇**引用它们，不抄一遍**——同一条纪律抄四份，第一次
改动就会剩三份是旧的。`P-` 编号在四页之间是**一条全局序列**，对照表见
`FYL-DESIGN-10` {numref}`tbl-fylite-pages-numbering`。
:::

(fylite-analysis-conventions)=
# 约定与术语 (Conventions and Terminology)

实质断言携认识论状态标签（〔已确立〕/〔工作假设〕/〔开放猜想〕），不使用 RFC 2119
规范关键字；缺失值记 `[TBD]`，不虚构。场景页 / 功能栏 / 判定块 / 拒绝 / 出处几个词
沿 `FYL-DESIGN-10` §约定，不重定义。

**后验（posterior）**
:   一次拟合之外再跑 N 次重解，用**被扰动的输入**得到解的散布。它给出的不是「所有
    输入的不确定度」，而是「**这几样**只知道到 σ」——见 P-9。

**页面总线（page bus）**
:   `publish` / `take`：一条栏把产物挂上去，另一条栏取用。**发布不唤醒读者**
    （{ref}`fylite-analysis-g2`）。

**三态（three verdicts）**
:   批处理与时间序列每一行的判定：已收敛 / 未解出 / 未运行。三态由**同一处**判据
    判出（P-7），批式路径不另立判据。

(fylite-analysis-composition)=
# 页面的构造 (How the Page Is Put Together)

〔已确立〕一个部件（`data-part="analysis"`，控制器 `app/assets/scenario-analysis.js`）、
四条功能栏、一个主 worker、一条状态行——四条栏**轮流**在这条状态行上说话。

〔已确立〕栏间靠**页面总线**相接（P-4 的两种机制之一）：剖面拟合的产物成为平衡
反演的动理学约束，重构结果成为时间序列与批处理的底本。这与建模页靠**页内文档**
相接是两种机制，各自的代价都实测过。

〔已确立〕**这一页没有 `caveat` 段落**——同样的话分散在每个面板的注里，加上判定
块。这是与建模页的一处**真实差别，不是遗漏**：四条栏共读一条状态行，把限制集中
成一段会让它离开它所限制的那个控件。

(fylite-analysis-decisions)=
# 设计裁定 (Design Decisions)

(fylite-analysis-p9)=
## P-9 误差棒只说它抽了的那几样 (an error bar is defined by what was sampled)

〔已确立〕后验面板上的「抽哪几样」不是一个高级选项，而是**误差棒的定义**：抽压强
σ、磁通环 σ、线圈相对 σ、拟合基阶数 ±1 里的哪几样，带的含义就随之改变。面板上
因此写着：「这不是『所有输入的不确定度』，而是『这几样只知道到 σ』」——诊断几何、
装置描述与模型本身的不确定度**都不在里面**。

〔已确立〕自洽外环（自举—欧姆—拟合电流）**已经闭合**，但后验**不抽它**：误差棒
说的不是自洽迭代的不确定度（{ref}`fylite-analysis-g5`）。

〔已确立〕未跑后验时，判定块写「★未跑后验——这一行里**没有**不确定度」。这句话
是 P-5 的直接落点：一个**缺席的**误差棒比一个错的更容易被读成「没有误差」。

(fylite-analysis-p16)=
## P-16 折叠起来的控件仍然是控件 (a folded control is still a control)

〔已确立〕平衡反演栏有约四十个滑块，而**对某一个具体问题只有五个要紧**。面板因此
对半分：**决定某一块物理进不进拟合的那个开关留在明处**，塑造它的那几个数（权重、
噪声、ridge、迭代次数）折进它下面的「进阶」。

〔已确立〕折叠改变的只是**读者先看到什么**：`<details>` 藏起子节点而不移除它们——
id 不动、值照样进消息与会话文件、门禁照样用 `getElementById` 够得到。

〔已确立〕哪几组展开**不是一张固定清单，而是一条规则**：进阶组属于它上面那个开关，
开关开则组开。预设因此白拿到了自己的行为（「纯磁反演」关掉六个开关，六组随之收起），
而读者一旦离开所有预设，这条规则仍说得通——固定清单做不到。读者自己勾一个开关时
**只会展开**：因为他关了别的就把他正在用的那一组收起来，是页面在跟他争。

〔关联〕与 `FYL-DESIGN-10` P-3 的两半：P-3 说共用控件不能被折叠带走，P-16 说
**被折叠的那些仍然算数**。两条合起来才是「折叠是排版，不是语义」。

(fylite-analysis-p22)=
## P-22 ★动理学约束是这一页的分别所在 (the kinetic constraint is the point)

〔已确立·本轮新立〕这一页的边界句是：**磁测量单独约束不住内部剖面**。很不一样的
剖面能给出几乎一样好的磁场拟合；把解定下来的是动理学约束。

〔理由〕这不是一句谦辞，它决定三件界面上的事：

1. **约束来源面板是一等面板，不是一个折叠项。** 读者必须一眼看到「拟合里到底有
   什么」——哪几类测量在、哪几类关着、关着的那几行**缺的是装置数据还是接线**
   （今天关掉的两行缺的是**装置数据**，{ref}`fylite-analysis-g4`）。
2. **纯磁预设必须自报它是纯磁的。** 它是一个有用的对照，不是一个更快的等价物；
   页面不得让它看起来只是「少勾了几个框」。
3. **q₀ 一类芯部量的误差不能只由磁残差判。** 磁残差很小与内部剖面对，是两件事
   ——`docs/note/benchmark/reports/B-06-east-reconstruction.md` 正是本仓第一条能
   区分这两者的记录：磁轴 5.07 / 6.54 mm、ψ 图 rms 1.18 %、q95 +1.44 %，而 q₀
   **−58.9 %**。

〔工作假设〕**推论——「重构剖面」不得回喂拟合而不加标注。** 剖面拟合栏的「由卷宗
剖面重采样」那一档在面板上标明它是**合成的**：「一份重采样的剖面若以数据的身份
回到拟合里，就是本页在拟合自己的假设」（P-6 的一处成文拒绝）。

(fylite-analysis-p23)=
## P-23 ★预设只填不跑 (a preset fills the form; it does not press the button)

〔已确立·本轮新立〕分析预设（纯磁反演 / 动理学重构 / 爬升段 …）**只把控件填好**，
不代用户运行。

〔理由〕两条：

- 一次反演是**秒级**的批式动作，而预设是一次**选择**。让选择自动触发计算，读者就
  会拿到一个他还没来得及看输入的结果——而这一页的判定块讲的全都是「这次拟合用了
  什么」。
- 预设之间的**通道基准不可混用**：两套预设若各自假定不同的道集与标定，自动跑会把
  两套基准的结果并排放在同一条状态行上，而它们不可比。

〔已确立〕这条与 `FYL-DESIGN-09` D-2「预设是文档不是表单缺省值」是同一族纪律的
两侧：D-2 管**预设是什么**（一份会话文档），P-23 管**它被施用时发生什么**（填，
不跑）。

(fylite-analysis-p29)=
## P-29 ★不确定度画成什么样，取决于它度量了什么 (an uncertainty band must say what it covers)

〔工作假设〕这一页画的三样东西——**后验采样带**、**残差**、**拟合与测量**——各有
一种正确的画法，而它们今天最容易被画成同一种（都是曲线），于是读者分不清哪一条是
测量、哪一条是模型、哪一条是不确定度。

:::{table} 三种图元，三件事。★中间一列是它除颜色之外带的通道（P-27）。
:name: tbl-fylite-analysis-figures
:align: left

| 画什么 | 用什么图元 | 为什么不能换 |
| :--- | :--- | :--- |
| 后验采样带 | **带**（半透明填充）+ 抬头一句「只含压强 σ」 | 画成两条虚线，读者会当成「另外两次拟合」；而**带**天然读作「一个范围」 |
| 残差 | **零线上的杆 + 端点**，一路一根 | 画成折线会暗示这些点之间有插值关系——它们是**不同的诊断通道**，横轴根本不是连续量 |
| 拟合 vs 测量 | 测量是**点**，拟合是**线** | 两个图元，读者不必看图例就知道哪个是数据 |
:::

〔已确立·这一条的实质〕P-9 已经说了误差棒只度量它抽了的那几样；P-29 是它的**视觉
落法**：**带的抬头必须写它包了什么**，并且**没包进去的那几样要在旁边灰底列出**——
诊断几何、装置描述、模型本身。一条不写来源的带，读者会默认它是「总不确定度」，
而它不是。

〔工作假设〕**推论——没有约束住的东西要画出来。** P-22 说磁测量单独约束不住内部
剖面。落法是：约束清单里每一路带一个在场 / 缺席标记（勾 / 叉 + 文字，不是有色 /
无色），并且**只有磁测量时那一栏明说「内部剖面未被约束」**——不是省略这句话。

(fylite-analysis-visual)=
## 这一页在外壳上的三个槽与首屏 (this page's slots, and its first screen)

〔工作假设〕外壳三槽（`FYL-DESIGN-10` {ref}`fylite-pages-p25`）在本页取值：
④ 装置 `EAST`；⑤ **哪一条栏在跑，以及它准备好了没有**（例：`剖面拟合 · 就绪
（线圈响应矩阵 109 ms）`）；⑥ 交给建模场景。

〔已确立·实测〕**这一页是四页里唯一满足 P-26 的**：首条功能栏在 412 px、首处输出
在 553 px，16:9 首屏之内看得见图。**它之所以能做到，不是因为做了什么，而是因为
它的引言只有 181 px 且第一条栏默认展开**——另外三页要补的正是这两件事。

:::{note}
★把「本页已达标」写下来，是为了让它**不许退**。这条今天成立，靠的是两个可以被
一次改动破坏的条件（引言的长度、默认展开的是哪一条栏）；P-26 的闸子因此对四页
一视同仁地跑，不因为这一页现在是绿的就跳过它。**一条只在别处跑的闸子，等于给这一页
发了一张永久豁免。**
:::

〔工作假设〕**本页仍要补的一件小事**：位形截面必须**等比例**。一幅拉伸过的
poloidal 截面会让读者把拉长比读错，而拉长比恰恰是这一页解出来的量之一。判据写在
{ref}`fylite-analysis-gaps` 的 G-16。

# 缺口清单 (Gaps)

〔已确立〕编号按 `FYL-DESIGN-10` {ref}`fylite-pages-numbering` 的规矩不重排。

(fylite-analysis-g2)=
**G-2 发布不唤醒读者.** `publish` 不会叫醒 `take` 它的那条栏，页面自己维护一张
唤醒表来打补丁。实测症状：重新拟合剖面后等着，那句提示**逐字不变地留在原处，
永远**。判据：发布即通知，读者栏自报「我读的这一份是第几版」。

(fylite-analysis-g4)=
**G-4 装置卷宗缺两类几何.** Thomson `n_e` / `T_e` 不在随包卷宗里；MSE 与 SXR 层析的
**几何本身**不在任何一份随包装置卷宗里——内核有层析基与响应行，**缺的是装置数据
不是接线**（P-22 第 1 条要求界面把这句话写出来，今天已如此，不得倒退）。

(fylite-analysis-g5)=
**G-5 后验不抽自洽外环.** 自举—欧姆—拟合电流的闭环已经关上，但误差棒不含它
（P-9）。

**G-6 爬升段预设在随包那一炮上不收敛.** 只有磁通环时真空室涡流本来就定不出来
（特征投影后残存 5.6 %）——**这是判据成立，不是设定错了**。

**G-7 时间序列的卷宗只带一个时片.** 随包 EAST 卷宗只有一片，扫描档因此是合成的。
这是关于**卷宗**的事实，不是关于页面的。

**G-9 逐道残差表打不开卷宗自己不用的道.** 这是有意的职权划分（用一个复选框推翻
一次标定决定不是这张表的事），但它意味着重新标定必须回到卷宗去做。

**G-14 四档预算未实测（本篇新立）.** {numref}`tbl-fylite-analysis-tiers` 四行全是
`[TBD]`。判据：预算随能力目录机器可读发布；实测超预算按回归缺陷处理（同
NR-ENV-005）。

**G-15 非颜色通道未逐条落实（P-27 · P-29）.** {numref}`fig-fylite-analysis-vocab`
的十二行今天多数只有颜色：后验带不写它包了什么，缺席的诊断留空而不写「无此炮」，
折起的控件不显示「仍在生效」。判据：每种状态带一个可断言的非颜色标记，闸子逐行
核对并**断言清点非空**。

**G-16 位形截面未保证等比例.** 一幅拉伸过的 poloidal 截面会让读者把拉长比读错，
而拉长比是这一页解出来的量之一。判据：截面画布的每单位像素在 R 与 Z 上相等，
闸子按画布的实测宽高与数据域范围之比断言（容差 1 %）。

**G-17 首屏达标无闸子（P-26）.** 本页今天满足首屏判据，但靠的是两个可被一次改动
破坏的条件（引言长度、默认展开的是哪一条栏）。判据：P-26 的闸子对四页一视同仁地
跑，本页绿也照跑——**一条只在别处跑的闸子等于给这一页发了永久豁免**。
